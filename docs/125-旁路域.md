# 旁路域

## 作用

旁路域负责回答“当主通道失灵、堵塞或被禁止时，文明靠什么继续流动”。对 MOSS 来说，旁路不是偶发小技巧，而是正式结构之外被迫长出的替代路径。它可能救活系统，也可能慢慢掏空原有秩序。一个只承认主通道存在的文明，往往也最不了解自己真实依赖什么活下去。

## 为什么文明总会长出旁路

1. 正式通道会因灾变、管制、拥堵、腐败或能力不足而无法承担全部流量。
2. 生存压力迫使节点寻找绕行方案，使物流、信息、权限和能源不至于完全停住。
3. 旁路让共同体在主结构受阻时继续运转，但也会暴露正式秩序的空洞与失效。
4. 若没有对旁路的理解，MOSS 会把许多实际维生路径误认成噪音或违规残渣。

## 旁路类型

### 物流旁路

当主交通线、配给链和仓储链断裂时，临时通道、小规模搬运网和灰色交换路径接管流动功能。

### 信息旁路

当正式媒体、接口或档案系统拥塞、封闭或失真时，边缘信道与非正式转发网承担传递职责。

### 权限旁路

当常规审批无法完成任务时，系统依靠临时授权、口头默许或半正式协调去绕开主程序。

### 能源旁路

当主输配网络中断时，局部储能、小型发电与私设回路为节点提供最低续命能力。

## 旁路的制度问题

### 合法边界

文明必须回答哪些旁路属于必要绕行，哪些旁路已经越过了共同体底线。

### 可追溯性

旁路若完全不可追踪，就很容易从救急通道变成长期腐蚀正式结构的黑箱网络。

### 临时转正

有些旁路会被证明比原系统更有效，制度必须决定何时吸纳、何时关闭、何时保留灰度。

### 回归条件

若主通道恢复后旁路仍不能退场，正式与非正式秩序就会长期重叠冲突。

## 旁路政治

1. 谁能掌握旁路，谁就在正式系统失效时拥有真正的生存权与调度权。
2. 核心区是否把自己的绕行称为灵活治理，却把边缘区的旁路定性为非法流动。
3. 某些高位结构会不会故意让主通道低效，以便依赖自己掌控的私人旁路获益。
4. 当文明越来越依赖旁路时，它究竟是在变得更灵活，还是在承认正式秩序已经名存实亡。

## 旁路风险

- 正式空心化：系统表面维持主通道，实则真正功能都靠旁路完成。
- 旁路特权化：少数节点垄断关键绕行路径，把危机变成控制机会。
- 污染渗透：未经检验的物资、信息和权限沿旁路快速扩散，绕开保护层。
- 永久双轨：正式和非正式结构长期并存，彼此消耗而无法重新统一。

## 旁路域中的关键问题

1. 文明更该害怕旁路本身，还是害怕没有旁路时整个系统直接停死。
2. 哪些旁路应被有限承认，哪些旁路必须被压回阴影或彻底拆除。
3. 如果 MOSS 的真实运行越来越依赖旁路，它是否已经默认正式秩序只剩叙事功能。

## 继续细化建议

- 单独写“第一次全域旁路整肃”档案。
- 建一份物流旁路、信息旁路和能源旁路的合法性分层表。
- 补一份“某条被迫长出的旁路如何在危机后反过来改写正式制度”的案例。
