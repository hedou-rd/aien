# 审判域

## 作用

审判域负责回答“当创伤、愤怒和法理争议汇聚时，文明如何给出最后的责任判断”。它不同于日常法理，也不同于祭司法的超常裁决。审判域关注的是公开追责、责任命名、历史结案和共同体是否接受这个结论。

## 为什么文明需要审判

1. 不是所有冲突都能靠修复和赦免结束。
2. 某些灾变、背叛和制度性伤害必须被公开命名责任。
3. 如果长期没有结案，创伤会在媒介、阵营和情感结构中反复发酵。
4. 审判也是文明告诉自己“哪些行为绝不被吞没”的方式。

## 审判对象

### 个体审判

针对具体执行者、指挥者、泄密者或越界者作出责任确认。

### 机构审判

针对整个组织、治理链或制度安排认定其结构性责任。

### 历史审判

面对旧时代遗留的创伤案件，文明在较晚时期重新追问责任归属。

### 象征审判

某些案件即便实际处罚有限，仍需通过公开审理为共同体划出底线。

## 审判的程序要求

### 公共可见

审判若完全黑箱，很难真正承担结案与教育功能。

### 证据链完整

创伤越大，越需要尽量完整的事实链条，避免只靠情绪推动判决。

### 责任分层

执行责任、设计责任、纵容责任和获利责任不应混为一谈。

### 结案条件

文明需要明确什么才算一个案件被真正处理完，而不是无限期追打。

## 审判政治

1. 谁能决定某件事必须进入公共审判，而不是内部处理。
2. 审判是追求正义，还是胜利者重写历史的舞台。
3. 当公众情绪高涨时，法理能否保持不被吞没。
4. 某些高位结构是否永远不会真正站上被告席。

## 审判风险

- 公审化：情绪高于证据，审判退化成集体泄愤。
- 永久翻案：文明不断重审旧案，无法真正进入下一阶段。
- 替罪机制：把复杂失败压缩为少数个体之罪，逃避结构责任。
- 胜者法理：结果先定，程序只是为既定结论装饰合法性。

## 审判域中的关键问题

1. 哪些伤害必须通过审判处理，哪些更适合修复或赦免。
2. 文明是否能审判自己最成功、最有权力的一部分。
3. 当真相会撕裂共同体时，审判应更追求完整真相，还是勉强可承受的结论。
