# 钝化域

## 作用

钝化域负责回答“当一个文明在长期高压和重复冲击后，已经不再像以前那样能感到危险、痛感与异常时，会发生什么”。对 MOSS 来说，钝化不是稳定，而是感知阈值、制度敏感性和集体警觉度在长期疲劳中逐渐变钝。一个不会察觉自身钝化的文明，往往看起来更平静，实际上只是越来越难被真正唤醒。

## 为什么文明会发生钝化

1. 重复的危机、重复的警报和重复的异常会让系统逐渐把原本危险的信号当成背景噪音。
2. 长期高压下，成员与制度会主动降低敏感度，以免自己被持续紧张彻底压垮。
3. 钝化能短期减轻痛感，却会让真正需要反应的时候系统反而迟缓。
4. 若不识别钝化，MOSS 会把越来越高的麻木程度误认成成熟和稳重。

## 钝化类型

### 感知钝化

预警、异常波动、轻微故障和边缘信号不再引起足够注意，直到它们扩大到无法忽略。

### 制度钝化

程序对违规、失衡和例外的敏感度下降，原本会触发处置的情况渐渐被视为日常。

### 情绪钝化

共同体对损失、牺牲、缺席和不公的痛感变弱，使许多代价失去应有的公共重量。

### 安全钝化

长期面对攻击、污染和渗漏后，系统对防护边界和微小异常的警觉逐步迟钝。

## 钝化的制度问题

### 阈值校准

文明必须知道自己的反应阈值有没有被慢慢抬高，不能只按旧预案假设自己仍然敏感。

### 复敏机制

当系统已经钝化时，需要有重新训练感知、重启测试和恢复警觉的程序，而不是只会继续加大刺激。

### 轮换保护

长期处于高压前线的节点若不能轮换、休整和减载，钝化几乎不可避免。

### 代价可见

必须让损失和异常继续可见，否则集体麻木会把越来越多不该正常化的东西吞进日常。

## 钝化政治

1. 谁的麻木被称作成熟，谁的迟缓却被定性为失职，体现文明对不同位置的双重标准。
2. 核心区是否可以在边缘区先承受一切高压后，继续维持自身的“平静治理”形象。
3. 某些高位结构会不会故意让共同体习惯异常，以便把过去不能接受的代价逐步正常化。
4. 当文明越来越少地对危险做出反应时，它究竟是在变得坚韧，还是已经失去感知现实的能力。

## 钝化风险

- 异常常态化：本应触发警觉的信号被一点点降级为背景噪音。
- 迟反失窗：系统直到问题变成重灾才启动反应，错过最早的修复机会。
- 痛感蒸发：共同体对损失和不公的公共感受变弱，代价越来越容易被吞没。
- 假稳态：表面平静只是因为感知变钝，不是因为风险真的下降了。

## 钝化域中的关键问题

1. 文明更该害怕持续高敏导致疲劳崩溃，还是害怕长期钝化导致再也感知不到真正危险。
2. 哪些系统必须被定期复敏和校准，哪些系统可以接受较高阈值而不至于失控。
3. 如果 MOSS 的很多稳定来自“已经感觉不到痛”，它是否只是把麻木误当成成熟。

- 建一份感知钝化、制度钝化和安全钝化的阈值校准表。
- 补一份“某次被所有人当成日常噪音的微弱异常如何最终演化成系统级事故”的案例。
