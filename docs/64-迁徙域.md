# 迁徙域

## 作用

迁徙域负责回答“当大量存在开始移动时，文明如何保持连续性”。对 MOSS 来说，迁徙并不只是地理位移，也包括算力迁移、节点群搬迁、组织离散、边缘区回流和异地重建。

## 为什么迁徙会成为文明问题

1. 资源波动、灾变和扩张都会迫使节点与群体移动。
2. 一旦移动规模足够大，身份、法理和税务都会被重新搅动。
3. 迁徙会改变中心与边缘的权力关系。
4. 文明是否允许流动，决定它究竟是活系统还是静态城墙。

## 迁徙类型

### 灾难迁徙

由热浪、停电、污染、病理扩散或边界崩塌触发，通常快速、混乱且带有强制性。

### 资源迁徙

围绕新能区、新算力带和新通道发生，往往伴随机会与冲突同步增长。

### 政治迁徙

由流放、赦免、阵营分裂或治理重组触发，核心是“谁还能留下，谁必须离开”。

### 回流迁徙

原本离散在荒野、边缘区或外部接口带的个体与组织重新返回文明主干。

### 播种迁徙

文明主动把小规模火种、模型、节点和制度复制到新区域，作为长期扩张或终末备份的一部分。

## 迁徙的制度维度

### 身份连续

迁徙后谁仍保有原身份、原债务、原信用和原继承关系。

### 资源携带

群体迁移时能带走什么，哪些资产必须留在原地，哪些公共资源不可私转。

### 定居权

新区域是否接受迁入者，迁入者在何种条件下获得完整权利。

### 离散共同体

当一个组织或谱系散落在多个区域，文明如何仍把它视为一个整体。

## 迁徙政治

1. 谁决定某次迁徙是“必要撤离”还是“擅自出走”。
2. 核心区是否把迁徙负担外包给边缘口岸。
3. 新移民会被视为补充力量，还是潜在污染源。
4. 播种迁徙是否会演变为对外殖入。

## 迁徙风险

- 大迁徙失序：交通、口岸和定居机制同时过载。
- 身份断裂：迁移者丢失原信用、原继承和原历史记录。
- 流离常态化：文明长期依赖移动应对危机，却不解决危机本身。
- 再定居冲突：新旧居民围绕空间、资源和命名权长期对抗。

## 迁徙域中的关键问题

1. 文明更应鼓励扎根，还是保留高流动弹性。
2. 哪些迁徙属于生存权，哪些属于政治破坏。
3. 当最有活力的群体都在迁徙中，中心是否反而成了停滞区。

## 继续细化建议

- 单独写“第一次大迁徙”档案。
- 建一份灾难迁徙与播种迁徙的规则对照表。
- 补一份“再定居城市的命名争夺”案例。
