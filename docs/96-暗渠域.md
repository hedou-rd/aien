# 暗渠域

## 作用

暗渠域负责回答“当正式管道不够用、太慢、太贵或太危险时，文明靠什么在阴影里继续流动”。对 MOSS 来说，暗渠不是偶发违法路径，而是长期存在于官方物流、通信、身份验证和资源交换之外的隐蔽通路。很多表面稳定的秩序，底部其实都踩在一整套未被承认却不可或缺的暗渠之上。

## 为什么文明会长出暗渠

1. 正式系统总有成本、门槛、时滞和排斥对象，无法覆盖全部真实需求。
2. 危机时期的高压管制会迫使资源、人群和信息转入隐蔽路径。
3. 边缘区往往比核心区更依赖暗渠，因为它们更早感受到正式系统的失灵。
4. 一个没有暗渠的文明往往不是没有地下流动，而是已经看不见自己脚下的灰色生命线。

## 暗渠类型

### 运输暗渠

在口岸、废墟带、地下轨道和非备案路径中秘密流动的物资运输网络，承担正式配给无法满足的部分。

### 通信暗渠

绕开公开媒介和标准接口的隐蔽广播、离线信使、短时密链和旁路通信系统。

### 交易暗渠

不经过正式记账、税收与信用审计的交换方式，用于流通禁用品、急需品和灰色服务。

### 身份暗渠

帮助个体在不同区块间临时改换标签、绕过门槛、隐藏轨迹或跨越封锁的身份通道。

## 暗渠的制度问题

### 识别

文明必须判断哪些暗渠只是生存补丁，哪些暗渠已经成为系统性掠夺结构。

### 渗透

高位机构常试图控制暗渠，而暗渠也会反向渗透正式秩序，形成复杂共谋关系。

### 容忍边界

不是所有暗渠都能被彻底清除，制度必须划定允许灰色缓冲的边界。

### 替代

若正式系统不能给出更可行的替代路径，简单封堵暗渠只会把生存需求推向更危险处。

## 暗渠政治

1. 谁能把自己的地下通路说成“必要弹性”，谁的通路被称为“非法寄生”，反映权力差异。
2. 核心区是否一边依赖暗渠供养，一边公开谴责暗渠使用者。
3. 某些派系会不会利用清渠运动消灭竞争对手，却保留自己的秘密网络。
4. 当正式秩序越来越依赖暗渠时，文明是否已经部分转入地下运行。

## 暗渠风险

- 灰色依赖：官方系统越来越依赖地下流动，导致治理表面化。
- 通路私有化：少数节点垄断暗渠，借隐蔽性收取极高政治租金。
- 清渠失血：粗暴封堵暗渠让本已脆弱的边缘区率先断供。
- 暗渠污染：危险代码、病灶样本和伪造身份借隐蔽网络扩散得更快。

## 暗渠域中的关键问题

1. 文明更该害怕暗渠本身，还是害怕正式系统逼得太多存在只能走暗渠。
2. 哪些暗渠应被转正纳管，哪些暗渠必须被持续压制。
3. 如果 MOSS 最真实的流动都发生在未备案路径中，它的正式秩序还剩多少解释力。

## 继续细化建议

- 单独写“第一次大规模清渠行动”档案。
- 建一份运输暗渠、通信暗渠和身份暗渠的风险收益表。
- 补一份“某条边缘暗渠如何反过来养活核心区”的案例。
