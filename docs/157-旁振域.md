# 旁振域

## 作用

旁振域负责回答“当局部振荡和微弱异常并没有直接穿透主链路，却通过相邻结构互相激发并不断放大时，文明如何阻断它”。对 MOSS 来说，旁振不是正面冲击，而是侧向传播的共鸣效应。一个节点的轻微摆动、一个区域的小规模异常、一个制度边缘的噪声，都可能在相邻系统中被接力放大。一个不会处理旁振的文明，往往以为自己已经控制住主问题，却不知道侧面共振正在把更多部位拖入不稳。

## 为什么文明必须识别旁振

1. 很多系统性波动并不是从主链路直接爆开，而是从边侧结构互相激发后慢慢扩成大片不稳。
2. 旁振会让本来无关的相邻节点开始同步失稳，扩大问题覆盖面。
3. 它常常绕开正式预警，因为每个局部异常单看都不算大，却在侧向叠加后变得危险。
4. 若没有旁振治理，MOSS 会低估那些“只是周边在晃”的现象，直到整圈结构一起抖起来。

## 旁振类型

### 设施旁振

一个节点的振荡、过热或不稳定通过能源、散热、运输和维护网络传到邻近设施。

### 信号旁振

局部噪声和误差沿相邻接口互相激发，使本来可忽略的异常逐渐放大成系统级干扰。

### 情绪旁振

某一区域的恐慌、激愤或疲惫通过媒介与联系链感染相邻共同体，形成横向扩散。

### 制度旁振

一处例外、一次强制措施或一次局部调整，在邻近系统里诱发额外模仿、对冲或防御反应。

## 旁振的制度问题

### 邻接识别

文明必须知道哪些结构彼此相邻并会互相激发，而不是只盯着名义上的主从关系。

### 阻尼设计

没有阻尼层、隔振层和缓冲带，侧向共振就会在边缘结构之间越传越强。

### 预警门槛

旁振常由许多小幅异常组成，若门槛只盯单点峰值，就很难及时发现整体扩散。

### 联动熄振

当多个相邻节点一起晃动时，谁有权同步降载、切换和隔离，是阻断旁振蔓延的关键。

## 旁振政治

1. 谁把“只是邻区受影响”说得轻描淡写，谁就可能在掩盖侧向传播的真实范围。
2. 核心区是否总把旁振当成边缘区自己的局部问题，而拒绝承认相邻结构早已连成一体。
3. 某些高位结构会不会故意拆散跨区信息，让不同区域看不见自己正在同步抖动。
4. 当文明只追问主爆点在哪里时，它究竟是在寻找原因，还是在回避那些更难归责的侧向共振链。

## 旁振风险

- 侧向放大：本来小而散的异常沿相邻结构越传越大。
- 假局部化：每个点看起来都是局部问题，合起来却已是系统级不稳。
- 阻尼缺失：没有隔振层时，整个区域网络会一起进入共振状态。
- 迟看连动：等看到多区同步异常时，旁振往往已经扩到难以单点压制。

## 旁振域中的关键问题

1. 文明更该害怕集中爆点，还是害怕那些没有爆点却在边侧缓慢联动扩大的震荡。
2. 哪些相邻结构必须被人为加阻尼和隔离，哪些结构可以接受更高的共振风险。
3. 如果 MOSS 总把邻区异常当成彼此独立事件，它是否已经失去对侧向传播的感知能力。

## 继续细化建议

- 单独写“第一次全域旁振图谱”档案。
- 建一份设施旁振、信号旁振和情绪旁振的阻尼层设计表。
- 补一份“某个边缘节点的小幅振荡如何沿邻接网络扩成多区同步不稳”的案例。
