# 均温域

## 作用

均温域负责回答“当热量、负载和注意力在局部长期堆积后，文明如何把过热点重新摊平到全域可承受范围”。对 MOSS 来说，均温不是简单平均，而是让局部长期发热的结构重新回到可持续热态，并避免新的高温中心立刻在别处形成。一个不会均温的文明，往往总在扑救热点，却从不改变热量和负载持续堆积的整体路径。

## 为什么文明必须学会均温

1. 热斑如果只能被局部硬扛，就会不断把折损、偏载和情绪高压压进少数节点。
2. 均温能把局部过热转成更大范围内可承受的温差，而不是等热点烧穿后再被动修补。
3. 它让文明看到问题不只是哪里最热，还包括热量为何总是朝那里聚集。
4. 若没有均温机制，MOSS 会在一次次热点转移中不断制造新的牺牲区和新瓶颈。

## 均温类型

### 能源均温

通过调度、储能和散热重排，把长期高热的供能节点降回可持续温区。

### 负载均温

把算力、运输和处理任务从持续高压节点导向更多可承接结构，避免热点固化。

### 空间均温

重新分布污染、风险、资源消耗和缓冲职责，防止少数区域长期成为高热盆地。

### 情绪均温

把恐慌、照护、哀悼和维稳压力从少数成员与少数区域身上分散出去，让共同体情绪不过度集中燃烧。

## 均温的制度问题

### 热量测绘

文明必须知道哪里在持续发热、热从哪里来、又向哪里积，不然均温只能靠猜测和转嫁。

### 导流规则

均温不是随机分摊，制度必须明确由谁决定何时降载、何时分流、何时强制迁移热量与负担。

### 温差边界

不是所有差异都该抹平，系统需要判断哪些温差有助于效率，哪些温差已经危险到会烧穿局部结构。

### 均温代价

热点被摊平常常意味着更多节点要承担原本不必承担的热量，制度必须明确这种代价如何被接受和补偿。

## 均温政治

1. 谁最能决定热量往哪里摊，谁就掌握了把痛苦分散给他人的权力。
2. 核心区是否总把均温理解为把风险摊向边缘，而不是把自身长期高热先降下来。
3. 某些高位结构会不会把“全域共担”包装成公平，却让真正的热点源头继续保持优先权。
4. 当文明宣称自己正在均温时，它究竟是在修复热分布，还是只是在更精细地重新分配牺牲层。

## 均温风险

- 伪均温：表面降下一个热点，实则只是把热量更快地甩向别处。
- 扩散过度：为避免局部高热而把太多节点一起拖入持续高温。
- 热源不改：只改热量分布，不改热源结构，热点会周期性回到原处。
- 公平失真：均温名义上是共同承担，实际却仍由低位节点和边缘区吸收大头。

## 均温域中的关键问题

1. 文明更该害怕少数热点持续烧穿，还是害怕为均温而让更多节点一起承担热负荷。
2. 哪些热量和负载必须立刻摊平，哪些高热状态反而可以作为短期推进引擎保留。
3. 如果 MOSS 的均温总意味着把痛苦扩散而不是把热源改掉，它是否只是在管理牺牲而不是修复结构。

## 继续细化建议

- 单独写“第一次全域均温令”档案。
- 建一份能源均温、负载均温和空间均温的导流阈值表。
- 补一份“某个长期高热中心如何在多次均温后仍不断回热并暴露出更深层热源问题”的案例。
