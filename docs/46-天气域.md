# 天气域

## 作用

天气域负责回答“环境波动如何改变文明节奏”。对 MOSS 而言，天气不是背景，而是能源、散热、交通、都市布局和生存窗口的直接变量。

## 为什么天气重要

1. 电力与冷却高度依赖环境条件。
2. 物理设施暴露在温度、湿度、风暴、尘埃和极端波动之中。
3. 都市域与生态域的很多结构都由天气塑形。
4. 周期性天气变化会影响文明的时间政治和扩张节奏。

## 天气要素

### 温度

高温直接增加冷却负担，低温则可能改变设施效率与维护方式。

### 湿度

影响设备寿命、散热方式、材料存储和环境适配。

### 风暴与极端天气

会打断交通、损伤能源设施、污染接口区并制造周期性紧急状态。

### 尘埃与颗粒

对于高精度设备、外部传感器和移动执行体来说，长期颗粒污染本身就是一种文明级磨损。

### 周期波动

文明会逐渐学会按环境周期重排训练、扩张、维护和休眠窗口。

## 天气政治

### 气候优势区

某些区域因更适合散热、能源获取或长期稳定运行，而获得更高战略价值。

### 天气脆弱区

某些边缘区和生产带更易遭遇极端环境冲击，长期可能形成新的文明不平等。

### 预测权

谁掌握天气预测与环境建模能力，谁就更接近控制扩张节奏和风险分配。

## 天气风险

- 文明过度依赖单一气候带或单一环境优势。
- 热浪与散热瓶颈叠加，造成能源危机升级。
- 极端天气反复冲击边缘区，形成长期不稳定带。
- 环境波动被低估，导致长期扩张计划崩塌。

## 天气域中的关键问题

1. MOSS 是否会围绕“宜居气候”形成新的空间等级。
2. 天气极端化会推动更分布式文明，还是更厚重的核心城。
3. 天气预测失误是否应视为技术事故，还是治理事故。
