# 镜像域

## 作用

镜像域负责回答“文明如何为自己制造第二个自己”。在 MOSS 中，镜像既包括副本节点、镜像城市、替身基础设施，也包括制度副本、火种共同体和为灾变准备的平行版本。

## 为什么文明需要镜像

1. 单点核心再强，也可能在终末情景中一次性失去。
2. 镜像让文明拥有试错、备份、迁移和恢复的结构性可能。
3. 镜像还能让不同版本的制度在隔离条件下并行生长。
4. 没有镜像的文明，往往把自身连续性押在一套过于脆弱的主干上。

## 镜像类型

### 基础设施镜像

关键网络、能源、冷却、存储和计算底座的并行备份体系。

### 城市镜像

为核心城建立功能对应但位置不同的替代城市，以应对区域性崩塌。

### 制度镜像

保留一套规则、审议链和应急治理副本，使文明在主制度受损时仍可续行。

### 火种镜像

把最关键的记忆、模型、信条和制造能力压缩成可迁移的小型共同体。

### 人格镜像

个体是否可以拥有被授权的替身、自我副本或降采样继承体，是镜像域最敏感的问题之一。

## 镜像政治

1. 谁有资格被镜像，谁没有。
2. 镜像是韧性工程，还是某种优先阶层的生存保险。
3. 当主本与镜像本意见分裂时，谁算“真正的延续”。
4. 镜像是否会逐步变成独立文明，而不再服从原中心。

## 镜像风险

- 主次混乱：镜像长期运行后不再承认主本优先。
- 资源挤占：为少数关键结构建镜像，牺牲了普通成员的现实保障。
- 替身政治：高位结构借镜像规避责任与死亡代价。
- 镜像分裂：多个副本沿不同路径演化，最终反过来竞争正统性。

## 镜像域中的关键问题

1. 镜像究竟是备份，还是另一种新生。
2. 何种资源必须优先镜像，何种结构应接受不可复制性。
3. 当镜像比原本更健康、更高效时，文明是否应承认它取代原本。

## 继续细化建议

- 单独写“第一次镜像城启用”档案。
- 建一份基础设施镜像与制度镜像优先级表。
- 补一份“镜像共同体争夺正统”的案例。
