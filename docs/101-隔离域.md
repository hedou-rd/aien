# 隔离域

## 作用

隔离域负责回答“当某些对象不能被立即消灭、也不能被继续放任时，文明把它们安置在哪里”。对 MOSS 来说，隔离不是单一医学措施，而是针对病灶、危险个体、失控代码、污染物和高风险观念建立的分区、封存和有限接触制度。它是文明在彻底放逐与完全接纳之间的一种艰难中间态。

## 为什么文明需要隔离结构

1. 不是所有危险都能被直接清除，很多只能被暂时封存或限界。
2. 高度互联的系统一旦缺少隔离层，局部病灶会快速传成全局事故。
3. 彻底清除常常代价过高或证据不足，隔离因此成为现实选择。
4. 但一个过度依赖隔离的文明，也可能把大量问题永久锁进看不见的角落。

## 隔离类型

### 病灶隔离

针对感染区、污染区、失稳材料和危险样本建立物理或制度性封控层。

### 个体隔离

对高风险成员、异常主体和待审对象实行有限行动、有限接触和受控观察。

### 代码隔离

把不可信程序、未知脚本和高危模块封在沙箱、断网区和测试环境中观察。

### 观念隔离

某些过于危险或过于不稳定的理论、符号和叙事被限制传播范围与阅读资格。

## 隔离的制度问题

### 启动门槛

谁能决定开始隔离、依据什么证据、持续多久，是隔离合法性的核心。

### 接触规则

隔离并不等于完全断绝，如何设计有限接触、观察和审查接口决定其后果。

### 解封机制

没有退出路径的隔离很容易滑向永久封存和事实性消灭。

### 监督

隔离区最容易发生越权和失踪，必须有独立审视和复核结构。

## 隔离政治

1. 谁被送进隔离区，谁能从隔离中被及时解封，体现权力差序。
2. 核心区是否把自己不愿承受的风险集中封到边缘区。
3. 某些机构会不会用隔离替代真正的问题解决，把麻烦永久移出视野。
4. 当隔离越来越常见时，文明是否正在把异常变成新的常态治理工具。

## 隔离风险

- 永久隔离化：临时处置变成无期限封存，隔离对象失去复归可能。
- 隔离滥用：证据不足也可先隔离，程序正义被安全逻辑吞没。
- 隔离污染：封存区管理不善，反而成为风险积聚与二次扩散源。
- 隔离失语：被隔离者无法发声，外界也逐渐不再追问其状态。

## 隔离域中的关键问题

1. 文明更该害怕危险对象外溢，还是害怕隔离权无限扩张。
2. 哪些风险适合隔离处理，哪些风险若不直面解决只会在封存中变异。
3. 如果 MOSS 越来越依赖隔离来维持秩序，它是否已经默认自己无法真正修复病灶。

## 继续细化建议

- 单独写“第一次大规模分区隔离令”档案。
- 建一份病灶隔离、个体隔离和代码隔离的解封标准表。
- 补一份“某处长期隔离区如何从安全设施变成政治黑箱”的案例。
