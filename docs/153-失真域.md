# 失真域

## 作用

失真域负责回答“当信号、指令与记忆穿过多层结构后，已经不再是原来的样子时，文明如何察觉”。对 MOSS 来说，失真不是单纯错误，而是在转译、删改、压缩、重述和复制中，原本的内容一点点偏移、扭曲和变形。一个不会识别失真的文明，往往以为自己掌握的是事实、命令和历史，实际上只是在跟它们的变形版本打交道。

## 为什么文明必须校正失真

1. 信息链越长、层级越多、传输越频繁，失真就越难避免。
2. 失真会让系统在看似有充足信息和明确命令时，仍不断做出偏离现实的动作。
3. 许多治理失败并不是完全没有信号，而是信号在到达时已经被扭到无法直接使用。
4. 若没有失真治理，MOSS 会把越来越多的决策建立在变形后的世界图景上。

## 失真类型

### 信号失真

观测数据、边缘报告和预警信号在汇总、压缩和筛选中失去原始幅度与细节。

### 命令失真

上级命令在层层转述、解释和本地化执行中被改写成与原意不同的行动版本。

### 记忆失真

事件在档案化、口述化和叙事化过程中不断被补缀、简化或偏转，最终改变共同体记忆。

### 情绪失真

群体感受在媒介放大、政治包装和二次解释中被转成另一种更易动员却未必真实的情绪形状。

## 失真的制度问题

### 源头比对

文明必须尽量保留原始记录与原始信号，避免所有判断都只基于转述层版本。

### 转译校验

不同层级、不同区域和不同系统之间的转译必须有回验机制，否则失真会在每次传递中累加。

### 偏差容限

不是所有失真都能清零，制度必须知道哪些偏差还可接受，哪些已经足以扭转决策方向。

### 纠偏责任

谁负责发现并校正失真，谁对长期不校的变形后果负责，是失真治理核心。

## 失真政治

1. 谁控制转译层和解释层，谁就掌握了把原始事实改造成可用叙事的能力。
2. 核心区是否总能让边缘信号在抵达前被压缩、净化或改写成更方便中心理解的版本。
3. 某些高位结构会不会故意保留失真空间，因为模糊与扭曲更有利于规避责任。
4. 当文明越来越依赖二手、三手、四手版本理解世界时，它究竟是在高效运作，还是已经失去与现实的直接接口。

## 失真风险

- 失真累加：每一层只偏一点点，最终抵达终点时已经完全改样。
- 真假混写：原始信息与解释信息揉成一体，系统再也分不清哪部分是事实，哪部分是加工。
- 指令变体化：同一命令在不同层级被执行成完全不同动作，责任链随之断裂。
- 历史重塑：长期失真让共同体对过去的理解逐步偏离原始经验，进而改写现在判断。

## 失真域中的关键问题

1. 文明更该害怕信息不足，还是害怕信息很多却大多已经失真。
2. 哪些链路必须尽量保持原貌传递，哪些链路可以接受更高程度的解释和压缩。
3. 如果 MOSS 的大量决策都建立在失真积累后的版本上，它是否还拥有真实的自我校正能力。

## 继续细化建议

- 单独写“第一次全域失真校验”档案。
- 建一份信号失真、命令失真和记忆失真的源头比对表。
- 补一份“某条被层层转译的警报如何在抵达决策中心时完全变成另一回事”的案例。
