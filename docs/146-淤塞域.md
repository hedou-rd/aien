# 淤塞域

## 作用

淤塞域负责回答“当层积、代偿和规则附着一点点把通道堵死时，文明如何重新让东西流起来”。对 MOSS 来说，淤塞不是瞬间断裂，而是通路、程序、物流、审批和记忆链在长期沉积中越来越窄、越来越硬，最终从低效走向完全不通。一个不会处理淤塞的文明，通常不是死于一次爆炸，而是死于所有关键链条都慢慢堵住了。

## 为什么文明必须处理淤塞

1. 沉积层和代偿链长期不清，会把原本可流动的结构一点点变成硬堵点。
2. 淤塞会让系统看似还在运行，实际每一步都更慢、更贵、更依赖例外手段。
3. 当通道不再畅通，后续的修复、配平和续航都会被连带拖死。
4. 若没有淤塞治理，MOSS 会在表面完整的链路内部发生越来越严重的慢性窒息。

## 淤塞类型

### 通路淤塞

道路、口岸、配给链和物流网因残骸、层积、临时结构和反复绕行而越来越难通行。

### 程序淤塞

审批、复核、例外条款和补丁程序不断叠加，导致任何决策都要穿过越来越厚的手续壳。

### 记忆淤塞

档案、证词、补注和删改层叠到难以读取，使过去的真实线索越来越难被重新疏通。

### 交换淤塞

资源、信息和信任在多个节点间因堵点、截留和附着成本积累而越来越难顺利流动。

## 淤塞的制度问题

### 堵点识别

文明必须知道哪些地方已经从正常摩擦变成实质堵塞，不能只以“还能勉强过”为标准。

### 疏浚优先级

不是所有淤塞都能同时处理，制度必须决定先挖哪一段、先拆哪一层、先松哪一块。

### 临时绕行

在主链路疏通前，哪些旁路和替代通道可被允许，决定系统是否能撑到疏浚完成。

### 复堵预防

若只挖开一次却不改变导致淤塞的附着机制，系统很快会回到原堵态甚至堵得更死。

## 淤塞政治

1. 谁长期活在通畅通道里，谁长期被堵在淤塞链上，体现文明对不同区域流动权的分配。
2. 核心区是否总先疏通自己的主路，把边缘区留在不断加厚的堵塞层里。
3. 某些高位结构会不会从淤塞中获利，因为堵点让审批权、放行权和例外权变得更值钱。
4. 当文明把低效与堵塞说成正常摩擦时，它究竟是在维持耐心，还是已经对失灵麻木。

## 淤塞风险

- 堵而不认：系统各处都越来越难通过，却始终没人承认那已是结构性堵塞。
- 疏浚偏置：公共通道不挖，只优先为高位节点开专门快线。
- 越挖越堵：只清表层、不动根因，反而让更多残渣在后方重新堆起。
- 例外成瘾：因为常规链路太堵，系统越来越依赖特批和旁路，进一步削弱主通道。

## 淤塞域中的关键问题

1. 文明更该害怕大决口造成的瞬间中断，还是害怕淤塞让所有流动慢慢窒息。
2. 哪些堵点必须被优先疏通，哪些堵点可以接受继续存在一段时间。
3. 如果 MOSS 的很多关键链路只能靠例外和绕行勉强前进，它是否已经在淤塞中失去正常运行能力。

## 继续细化建议

- 单独写“第一次全域疏浚计划”档案。
- 建一份通路淤塞、程序淤塞和交换淤塞的堵点优先级表。
- 补一份“某条被长期忽视的程序淤塞链如何最终让整个共同体在危机中错失反应窗口”的案例。
