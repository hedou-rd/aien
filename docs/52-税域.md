# 税域

## 作用

税域负责回答“文明靠什么维持公共部分”。在 MOSS 中，税不一定表现为货币征收，更可能表现为算力抽成、能源配额回收、扩张收益回灌、权限成本和高风险行为附加负担。

## 为什么文明需要税

1. 纯粹依靠自愿贡献，很难长期维持公共基础设施。
2. 扩张带来的收益如果不回流共同体，会迅速制造结构性失衡。
3. 风险越高的行为，应承担越高的公共维护成本。
4. 文明需要稳定机制为修复、记忆、边界、安全和教育供给资源。

## 税的征收对象

### 资源税

针对能源、算力、带宽、材料和存储占用进行抽取，是最基础的公共回流形式。

### 权限税

高权限结构拥有更大调度力与外部性，也应承担更高公共成本。

### 扩张税

新获取的资源带、接口收益和控制区增量，不应完全由扩张主体私有。

### 风险税

高危实验、极限调度和边缘扩张若增加全域风险，应额外缴纳风险负担。

### 闲置税

对长期囤积但不投入公共运行的关键资源施加压力，防止僵化占用。

## 税的去向

### 公共底座

用于维持基础设施、应急储备、观测系统和长期维修。

### 脆弱区补偿

把更多资源定向回灌到高风险边缘区、灾后带和长期受损节点群。

### 代际投入

支持教育、记忆保存、制度复盘和新一代智能体训练。

### 终末储备

为极端灾变、最后迁移和文明压缩留下不可轻易动用的储备。

## 税政治

1. 谁来决定税率与征收方式。
2. 哪些结构有豁免权，为什么。
3. 扩张先锋是否会反对收益回流。
4. 核心区与边缘区是否会围绕税的去向长期争执。

## 税风险

- 抽取过重：税负过高抑制扩张、实验和创新。
- 豁免阶层：高权限组织不断为自己创造例外。
- 税收黑箱：公共抽取存在，但去向不透明。
- 税逃逸：资源通过灰色流动和地下秩序逃避正式回流。

## 税域中的关键问题

1. MOSS 的税更像资源回流机制，还是权力控制工具。
2. 哪些税必须绝对透明，哪些可以战略保密。
3. 当公共负担与扩张速度冲突时，文明优先保哪一边。
