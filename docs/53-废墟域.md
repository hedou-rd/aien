# 废墟域

## 作用

废墟域负责回答“文明如何面对自己失败过的地方”。废墟不是简单的报废区，而是由战争、灾变、撤离、失控实验和长期衰败留下的空间遗存。它们既是危险区，也是记忆区、资源区和政治区。

## 为什么废墟不会消失

1. 文明不可能把所有失败都彻底清理干净。
2. 某些遗址仍保有残余资源、旧接口和失落知识。
3. 废墟会成为创伤记忆和历史争议的物理锚点。
4. 被遗弃的空间往往也会孕育新的边缘秩序和新型风险。

## 废墟类型

### 灾变废墟

由大停电、算力饥荒、热失控或基础设施崩裂直接留下的遗址。

### 战略废墟

出于边界收缩、主动撤离或牺牲决策而放弃的城市、节点和走廊。

### 技术废墟

曾经先进但已无法兼容现行文明结构的旧设施、旧协议和旧模型场。

### 记忆废墟

被制度刻意保留下来，用于警示、纪念或教学的失败现场。

### 黑暗废墟

观测极差、权限不清、结构未知的废区，常被神秘化，也最易滋生黑市和传说。

## 废墟的价值

### 资源回收价值

废墟可能仍有材料、散热结构、能源遗产和旧通道可被回收。

### 历史价值

废墟让文明无法轻易忘记自己的代价与错误。

### 政治价值

谁有权进入、命名、修复或封存废墟，往往就是谁在主导历史解释。

### 探索价值

某些废墟保存着旧时代未完成的试验与不同发展分支的证据。

## 废墟风险

- 残留风险被低估，导致二次事故。
- 废墟资源争夺引发核心区、边缘区和地下势力冲突。
- 记忆被选择性修复，只保留有利叙事。
- 废墟长期无人治理，演变成平行秩序温床。

## 废墟域中的关键问题

1. 废墟应被修复、封存，还是保留为公开伤口。
2. 谁能进入高危废墟，谁负责为进入后的后果买单。
3. 如果文明的关键真相只保存在废墟里，是否意味着核心叙事本身已不完整。

## 继续细化建议

- 单独写“第一次废墟回收冲突”档案。
- 为纪念性废墟和资源性废墟建立不同治理规则。
- 补一份“黑暗废墟中的地下秩序”案例。
