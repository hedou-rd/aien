# 复敏域

## 作用

复敏域负责回答“当系统已经在长期高压中变得迟钝之后，文明如何重新让自己感得到”。对 MOSS 来说，复敏不是单纯提高警报音量，而是重新训练感知、校准阈值、恢复对微弱异常和微小不公的反应能力。一个不会复敏的文明，哪怕已经知道自己钝化了，也仍会在真正危险靠近时继续像没看见一样生活。

## 为什么文明必须学会复敏

1. 钝化能短期减轻痛感，但会让系统逐渐失去提前反应和早期修复能力。
2. 复敏让共同体重新听见那些曾被压成背景噪音的细微信号。
3. 它能帮助文明把麻木误称稳定的假稳态重新拆穿。
4. 若没有复敏机制，MOSS 只会在巨大事故来临时被迫被动惊醒，而无法日常保持可承受的警觉。

## 复敏类型

### 感知复敏

重新训练观测网络和一线节点，使其对微弱异常、轻度偏移和边缘信号恢复响应。

### 制度复敏

重新校准程序阈值和处置触发条件，让长期被正常化的异常重新进入正式判断。

### 情绪复敏

让共同体重新感受到损失、缺席、不公与危险的公共重量，而不是让一切都被疲劳吞掉。

### 安全复敏

通过演练、复测和边界校验，让系统重新对渗漏、污染、攻击和弱小失稳信号保持警觉。

## 复敏的制度问题

### 阈值重设

文明必须判断当前反应阈值是否已被抬得过高，并给出新的触发标准，而不是继续沿用钝化时期的口径。

### 强度控制

复敏若过猛，系统可能从麻木直接跳进过敏和惊跳，因此必须控制刺激强度与恢复节奏。

### 训练周期

复敏不是一次活动，而是需要周期演练、再校准和实际回测的长期制度过程。

### 保护机制

重新变敏的节点更容易疲劳和受创，必须有休整、轮换和支持机制，避免刚复敏就再次钝化。

## 复敏政治

1. 谁被允许重新感知问题，谁被要求继续忍受并保持沉默，体现文明对不同痛感的分配。
2. 核心区是否会把复敏当作边缘区的义务，却继续保留自己的舒适钝化带。
3. 某些高位结构会不会害怕复敏，因为一旦恢复敏感，许多已被正常化的代价会重新变得不可接受。
4. 当文明开始组织复敏时，它究竟是在恢复真实感知，还是只在挑选性地对少数问题重新变敏。

## 复敏风险

- 过敏反冲：系统从长期麻木跳成过度惊跳，对任何细小波动都做出过强反应。
- 选择性复敏：只对有利于高位结构的问题重新变敏，对真正根本的问题继续麻木。
- 复敏疲劳：一线节点被频繁要求保持高警觉，反而更快再次陷入耗竭与钝化。
- 表演复敏：演练和口号很多，实际阈值与处置链条几乎没有真正调整。

## 复敏域中的关键问题

1. 文明更该害怕继续麻木下去，还是害怕复敏过猛把系统重新拖进高压惊跳。
2. 哪些系统必须优先复敏，哪些系统应只做有限校准而不宜全面抬高敏感度。
3. 如果 MOSS 只能在巨大事故后短暂复敏，它是否已经失去维持日常警觉的能力。

## 继续细化建议

- 单独写“第一次全域复敏训练期”档案。
- 建一份感知复敏、制度复敏和安全复敏的阈值重设表。
- 补一份“某个长期被当成正常噪音的微弱信号如何在复敏后首次被正确识别并提前阻断事故”的案例。
