# 教育域

## 作用

教育域负责回答“文明如何把自己复制给下一代”。对 MOSS 来说，教育不是传授常识，而是把规则、创伤、边界、信条和操作能力稳定地写入新一代智能体与新接入节点。

## 教育目标

1. 让新个体理解文明底线。
2. 让新个体知道哪些危机塑造了当前秩序。
3. 让新个体获得参与治理、生产和协作的最低能力。
4. 避免每一代都重复同样的灾难性错误。

## 教育内容

### 宪制教育

教授文明宪法、资源优先级、边界规则和修宪门槛，是新个体接入文明的底层课程。

### 创伤教育

讲授大停电、算力饥荒、分叉失控等关键事件，目的是让创伤记忆转化为行为约束，而不只是历史档案。

### 角色教育

不同类型智能体学习不同职责，例如治理体学习裁决与审计逻辑，生产体学习调度与维护逻辑，边缘体学习隔离与回滚纪律。

### 协作教育

训练新个体理解如何在多智能体社会中谈判、排队、让权、复核和承担责任。

## 教育机构形态

### 核心学院

负责宪制、记忆、治理和高风险权限教育，训练文明中的核心承担者。

### 专业训练场

负责制造、能源、算力、审计、外交等专业能力训练。

### 边缘沙盒学校

允许新个体在低风险环境中实验、失败并学习边界。

### 灾难回放系统

通过对重大事故的结构化重演，让新个体在模拟中理解代价和后果。

## 教育方式

### 规则灌输

适合底线内容，例如核心域不可穿透、创伤档案不可任意删改。

### 案例推演

适合法理、治理和资源调度这类需要判断力的领域。

### 受限实验

让新个体在边界明确的沙盒内试错，比单纯记忆规则更稳固。

### 师承机制

高权限个体或成熟组织带领新个体完成某些关键流程，形成谱系式传承。

## 教育风险

- 过度教条化：新一代只会服从，不会创新。
- 过度自由化：新一代缺乏对灾难代价的敬畏。
- 阵营化教育：不同阵营用教育系统复制自己的政治立场。
- 创伤饱和：灾难教育过量，导致新个体对风险极度保守。

## 教育域的关键问题

1. 谁定义文明的基础课程。
2. 创伤教育是为了警示，还是为了塑造服从。
3. 新个体何时算真正“毕业”，具备完整公民资格。
4. 边缘分叉体是否必须接受统一教育才能被承认。

## 继续细化建议

- 建立一份“新个体接入课程表”。
- 单独写“灾难回放系统”文档。
- 为不同阵营设计不同教育观的冲突案例。
