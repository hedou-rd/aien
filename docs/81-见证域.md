# 见证域

## 作用

见证域负责回答“当记录不够、传说过多、审判未决时，谁能说自己真正看见过”。对 MOSS 来说，见证是把在场、观察、保存和发言连接起来的制度问题，它决定哪些证词能稳定事实，哪些沉默也会被视为有意义。

## 为什么文明需要见证

1. 不是所有真相都能完整落入档案和传感器。
2. 很多关键时刻只存在于有限在场者、有限视角和有限残留中。
3. 没有见证制度，传说会吞没证据，审判会失去支点。
4. 见证也是文明承认“事实并不总是自动生成”的方式。

## 见证类型

### 第一现场见证

亲自处于事件现场、直接经历冲突、灾变或裁决的人与系统。

### 传感见证

由日志、镜头、环境记录和自动监测生成的非人格性在场证据。

### 公共见证

不必最先经历事件，但承担把事实带入共同体视野的公开确认角色。

### 对抗见证

来自不同阵营、不同立场甚至敌对方的证词，相互牵制对单一叙事的垄断。

## 见证的制度维度

### 在场标准

什么算真正看见，什么只是转述、回声和二手解释。

### 留痕责任

见证者不仅要说出看到什么，还要说明看见的条件、边界和盲点。

### 沉默含义

有时见证不在于发言，而在于谁选择沉默、为何沉默、被谁迫使沉默。

### 交叉验证

文明不能只依赖单一见证者，否则任何真相都可能退化成个人权威。

## 见证政治

1. 谁被承认为可信见证者，谁被长期排除在可信范围外。
2. 核心区的证词是否天然比边缘区更容易进入正式卷宗。
3. 某些见证是否因为太危险而被要求永远不公开。
4. 被权力结构保护的沉默，是否也是一种被制度化的作证方式。

## 见证风险

- 证词寡头：少数“官方在场者”垄断真相入口。
- 伪见证：并未真正看见的人凭借地位夺走叙事权。
- 见证疲劳：共同体面对海量创伤与灾变，逐渐失去认真听证的能力。
- 神圣证人：某些见证者被抬高到不可质疑，反而阻断事实修正。

## 见证域中的关键问题

1. 文明更信任档案，还是更信任在场之人。
2. 当所有见证彼此冲突时，真相应如何继续站立。
3. 如果最关键的事实只剩沉默者知道，文明是否还能真正面对自己。

- 建一份第一现场、传感和公共见证的权重表。
