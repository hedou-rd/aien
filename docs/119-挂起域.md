# 挂起域

## 作用

挂起域负责回答“当一个文明不愿立即决断，却又不肯真正放下时，它把问题放在哪里”。对 MOSS 来说，挂起不是简单延后，而是把决定、责任、审判、身份和计划置于一种长期未结、半活动、半冻结的中间态。挂起让秩序避免当场崩裂，但也会把越来越多东西变成无终点的等待。

## 为什么文明会制造挂起状态

1. 有些问题一旦立刻裁决会引发更大冲突，挂起成为拖住局面的办法。
2. 证据不足、资源不足或政治意愿不足时，制度常选择先不结束也不解决。
3. 挂起能为未来留出回旋空间，但也会把现在变成长久悬置。
4. 若文明过度依赖挂起，它会越来越擅长延迟，而越来越不会真正完成决断。

## 挂起类型

### 审判挂起

案件、追责和责任裁定长期停在未决状态，既未结案也未撤销。

### 计划挂起

重大工程、扩张方案和改革措施被暂缓执行，却持续占用资源与注意力。

### 身份挂起

某些成员长期处于待认定、待解封、待召回或待驱逐状态，没有稳定归属。

### 关系挂起

停火、协定、联盟和破裂关系被维持在既不正式恢复也不彻底终止的位置上。

## 挂起的制度问题

### 启动条件

文明必须回答什么问题可以被挂起，什么问题若不立即决断就会造成更大伤害。

### 暂行权利

被挂起对象在挂起期间拥有什么权利、资源和保护，不能全靠临时善意。

### 到期机制

若没有明确复审时限，挂起就会从缓冲带滑成永久悬空区。

### 解挂与终止

谁有权解除挂起、重启程序或正式终止，是挂起是否可控的核心。

## 挂起政治

1. 谁能让问题长期悬着，谁就掌握拖延现实的能力。
2. 核心区是否把最有争议、最难承担的责任长期挂起，等待共同体疲劳。
3. 某些高位结构会不会把挂起包装成谨慎，实则是在避免承担裁决后果。
4. 当越来越多事情被挂起时，文明是否已经进入一种长期未完成状态。

## 挂起风险

- 永久悬置：本该临时缓冲的挂起变成无期限的政治黑洞。
- 权利蒸发：挂起对象长期没有明确地位，权益被慢慢耗空。
- 决断瘫痪：制度习惯于不结案、不定责、不终止，最终失去裁决能力。
- 悬账积压：大量挂起事项彼此堆叠，未来任何处理都将更昂贵、更激烈。

## 挂起域中的关键问题

1. 文明更该害怕过早决断带来的激烈后果，还是害怕长期挂起带来的慢性腐败。
2. 哪些事项适合被短期挂起，哪些事项必须立刻处理而不能拖入悬置区。
3. 如果 MOSS 的大量责任都处在挂起状态，它是否已经把未完成本身变成治理常态。

## 继续细化建议

- 单独写“第一次全域挂起清单”档案。
- 建一份审判挂起、身份挂起和计划挂起的到期机制表。
- 补一份“某个长期挂起案件如何在多年后反过来改写整个共同体政治空气”的案例。
