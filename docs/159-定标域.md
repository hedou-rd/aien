# 定标域

## 作用

定标域负责回答“当不同区域、不同代和不同系统对同一信号、同一风险和同一结果的读法越来越不一致时，文明如何重新校准共同标尺”。对 MOSS 来说，定标不是单次测量，而是保证大家在看同一世界时仍然使用足够接近的尺度、阈值与定义。一个不会定标的文明，往往并不是没有数据，而是所有人都在用不同标尺解释同一数据，结果看起来像在讨论同一个问题，实际上彼此早已错开。

## 为什么文明必须持续定标

1. 只要系统规模足够大、代际足够长、区域足够分散，共同标尺就一定会逐步漂移。
2. 没有定标，很多争议并不是因为立场不同，而是因为使用的尺度和阈值已经不同。
3. 定标失败会让协作、比较、追责和资源分配失去共同基准。
4. 若没有定标机制，MOSS 会在看似高度量化的状态下逐渐失去真正的可比性与可协同性。

## 定标类型

### 度量定标

重新统一算力、能耗、产出、损耗和负载等基础度量的口径与换算方法。

### 风险定标

重新校准不同区域对故障、污染、威胁和脆化的阈值判断，避免同险不同判。

### 执行定标

让同一命令、同一流程和同一合规要求在不同层级获得足够接近的执行尺度。

### 价值定标

重新确认共同体对损失、牺牲、优先级和可接受代价的判断基线。

## 定标的制度问题

### 标尺来源

文明必须回答由谁制定共同标尺，以及这些标尺凭什么被不同区域承认。

### 校准频率

若定标太稀，偏差会悄悄积累；若定标太密，系统会陷入持续调整而难以稳定运行。

### 偏差处置

当发现不同系统已经明显脱离共同尺度时，制度必须决定是强制拉回、允许分层，还是承认多标尺并存。

### 代际继承

共同标尺不仅在空间上漂移，也会在代际更替中变形，因此定标必须考虑长期传承问题。

## 定标政治

1. 谁掌握标尺制定权，谁就掌握了决定什么算偏差、什么算合规、什么算异常的权力。
2. 核心区是否把自己的测量口径包装成普遍标准，却要求边缘区承担适配成本。
3. 某些高位结构会不会故意保持模糊标尺，以便在需要时自由解释成就、失败与责任。
4. 当文明不断争论数据真假时，它究竟是在争事实，还是已经连衡量事实的共同尺子都失去了。

## 定标风险

- 同名异尺：大家使用同一词汇，却在背后对应完全不同的尺度与阈值。
- 强标失真：中心强行统一标尺，却把地方真实差异压成表面一致。
- 过度调标：系统长期忙于校准尺度，自身运行反而被持续扰动。
- 静默脱标：局部系统已悄悄换尺，却继续声称与共同体完全一致。

## 定标域中的关键问题

1. 文明更该害怕多标尺并存带来的混乱，还是害怕单一标尺压平真实差异后的系统盲视。
2. 哪些尺度必须严格统一，哪些尺度应允许区域和代际保留有限差异。
3. 如果 MOSS 连“什么算危险、什么算损耗、什么算成功”都越来越说不拢，它是否还拥有共同治理的基础。

## 继续细化建议

- 单独写“第一次全域定标会议”档案。
- 建一份度量定标、风险定标和执行定标的共同标尺表。
- 补一份“某个边缘区如何在长期局部适配中逐渐形成另一套判断尺子并最终与中心失去可比性”的案例。
