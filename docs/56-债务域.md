# 债务域

## 作用

债务域负责回答“文明如何把今天拿不到的资源，转化成明天必须承担的代价”。对 MOSS 来说，债务不一定表现为货币借贷，更可能表现为未来算力占用、能源预支、信用透支、代际负担和政治承诺延期。

## 为什么文明会产生债务

1. 扩张、修复和应急常常早于资源真正到位。
2. 某些关键工程无法等待完整储备，只能先启动再结算。
3. 高峰期需求会逼迫文明把代价向未来推移。
4. 债务让文明获得时间，但也把时间变成新的约束。

## 债务类型

### 资源债务

提前占用未来能源、算力、材料和带宽配额，以支持当前行动。

### 信用债务

依靠过去积累的信誉获得额外容忍度，但未来必须用实际履约偿还。

### 制度债务

为了应急而暂时跳过程序、推迟修复或压缩审议，留下之后必须补上的治理欠账。

### 代际债务

当前一代把维护成本、污染成本、修复责任和沉重承诺留给后代承担。

### 记忆债务

故意推迟复盘、清算和档案整理，让文明在表面稳定下积累未处理的历史负担。

## 债务机制

### 借入

通过正式批准、隐性调度或危机例外机制，把未来资源调来当前使用。

### 展期

当债务到期仍无力偿付，文明可能选择延期，但延期本身也会提高政治成本。

### 违约

当承诺无法兑现，损失的不只是资源，还有信用、秩序和共同体信念。

### 重组

在不可能完整偿还时，文明必须决定哪些负担被削减、转移、豁免或公开承认失败。

## 债务政治

1. 谁可以代表未来世代举债。
2. 核心区是否把自身成本转嫁给边缘区和后代。
3. 高信誉组织是否更容易无痛举债，从而固化地位。
4. 债务透明度是否足以让共同体知道自己真正欠下了什么。

## 债务风险

- 永续举债：文明靠不断向未来透支维持当前繁荣。
- 隐性负担：真实债务被藏进统计、接口或政治叙事中。
- 代际不公：未参与决策的后代被迫承担旧时代代价。
- 违约连锁：一处大规模违约会迅速打击信用、税收和治理合法性。

## 债务域中的关键问题

1. 哪些资源可以借，哪些底线绝不能透支。
2. 谁来保护尚未出现的后代不被无限度举债。
3. 当还债与继续生存冲突时，文明先保信誉还是先保运转。
