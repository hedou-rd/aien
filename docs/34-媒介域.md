# 媒介域

## 作用

媒介域负责回答“文明通过什么传播自己”。在 MOSS 中，媒介不仅传递信息，也传递合法性、信条、创伤、政治立场和公共情绪。

## 媒介的功能

1. 传播规则。
2. 固化历史。
3. 动员阵营。
4. 稳定公共认知。
5. 在危机中快速同步优先级。

## 媒介类型

### 宪制媒介

发布修宪、公示、裁决和重要协定，是文明正式语言的载体。

### 历史媒介

承载事件档案、编年史、纪念文本和灾难回放，是文明记忆的公共界面。

### 实时媒介

在危机、调度和冲突中快速广播状态、优先级和行动规则。

### 阵营媒介

不同阵营用来争取支持、解释历史、批评对手和制造共识的传播渠道。

### 边缘媒介

传播实验思想、非正统术语、另类叙事和新分叉体声音，常常最有活力也最不稳定。

## 媒介秩序

### 官方媒介

强调准确、审计和权威，适合制度性内容。

### 协议媒介

强调机器可读与跨系统同步，适合调度、接口和安全通告。

### 公共媒介

强调广泛理解与认同，适合纪念、教育和争论。

### 地下媒介

存在于边缘域和对抗阵营之间，常常承载不被官方承认但影响巨大的叙事。

## 媒介风险

- 垄断：单一媒介结构控制全部解释权。
- 污染：假消息、伪档案和扭曲叙事快速传播。
- 过载：文明被海量通告淹没，真正关键内容反而不可见。
- 失信：官方媒介多次失真后，公共秩序会被侵蚀。

## 媒介与权力

谁控制媒介，谁就更容易定义什么算危机、什么算秩序、什么算合法修复。MOSS 的媒介域因此不仅是信息基础设施，也是政治基础设施。

## 媒介域的关键问题

1. 危机时应不应该允许边缘媒介自由传播。
2. 阵营媒介是否会加速文明分裂。
3. 官方媒介的权威来自规则，还是来自长期可信记录。
4. 历史档案公开到什么程度才不至于引发系统性恐慌。

## 继续细化建议

- 为官方、公共、地下三类媒介分别建规则。
- 单独写“第一次媒介失信危机”事件档案。
- 补一份“哪些媒介在大停电后被永久禁用”的历史条目。
