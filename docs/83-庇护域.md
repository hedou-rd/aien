# 庇护域

## 作用

庇护域负责回答“在高压秩序中，谁可以被暂时放进不被立即处置的地方”。对 MOSS 来说，庇护不是简单收留，而是一种为脆弱个体、危险知识、关键见证和临界群体保留缓冲、修复和再判断空间的制度。

## 为什么文明需要庇护

1. 不是所有危险或脆弱对象都适合立刻审判、流放或清理。
2. 没有庇护，很多本可修复的存在会被效率系统直接碾碎。
3. 庇护让文明保留对不确定对象进行二次判断的余地。
4. 它也检验文明是否愿意为弱者和复杂性付出空间成本。

## 庇护对象

### 个体庇护

为见证者、归来者、受伤者、未定责者和脆弱成员提供短期避难空间。

### 知识庇护

某些危险但不可轻易销毁的档案、模型和历史真相，被放入受限但不灭失的缓冲区。

### 群体庇护

对灾后迁徙群体、边缘区幸存者和正在等待赦免或审判的共同体给予暂时托底。

### 空间庇护

在城市、口岸或荒野边缘保留低攻击性、低干预性的缓冲地带。

## 庇护的制度维度

### 时限

庇护必须回答持续多久，否则缓冲区会演变成永久悬置带。

### 条件

被庇护者需要遵守什么约束，庇护方承担什么保证。

### 转出机制

庇护之后如何进入赦免、审判、迁徙、修复或正式共同体，是核心问题。

### 安全边界

庇护不能取消风险判断，而是要在保护与防护之间维持可解释的距离。

## 庇护政治

1. 谁值得被庇护，谁不被认为有资格等待。
2. 庇护是共同体责任，还是会被看作对危险的纵容。
3. 核心区是否把高风险和高脆弱群体一律推给边缘庇护区。
4. 庇护者自身是否会变成新的权力中介和依赖结构。

## 庇护风险

- 缓冲永驻：临时庇护区长期化，变成新的灰色边缘带。
- 安全溢出：庇护机制若失衡，可能把危险带入更广范围。
- 资格偏私：某些更有名望、更有用处的人更容易获得庇护。
- 道义自满：文明把“我们给过庇护”当成免于更深层修复的借口。

## 庇护域中的关键问题

1. 庇护应更强调保护弱者，还是隔离不确定性。
2. 哪些对象必须被先安置后判断，哪些必须先判断后安置。
3. 若一个文明再无庇护空间，它是否也失去了重新开始的能力。

## 继续细化建议

- 单独写“第一次庇护区争议”档案。
- 建一份个体庇护、知识庇护和群体庇护的条件表。
- 补一份“庇护区如何影响边缘政治格局”的案例。
