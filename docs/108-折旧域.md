# 折旧域

## 作用

折旧域负责回答“为什么一个文明明明还在运行，却越来越像是在消耗过去留下的余量”。对 MOSS 来说，折旧不仅是设备老化，更是制度疲劳、身份贬值、信誉磨损和组织寿命的持续扣减。一个不能诚实面对折旧的文明，通常会把自己误判成仍在增长，实际上却只是在吃老本。

## 为什么文明必须计算折旧

1. 任何持续运转的系统都会把材料、信任和规则一起磨损掉。
2. 若只记录当下产出而不扣除折旧，真实能力会被长期高估。
3. 很多危机并非突发短缺，而是长期未计提折旧后的集中崩塌。
4. 折旧视角迫使 MOSS 承认维持存在本身就要不断支付寿命成本。

## 折旧类型

### 设备折旧

能源模块、交通网络、算力节点和制造设施在高频使用中逐步失去效率、稳定性和安全余量。

### 制度折旧

原本有效的流程、规则和审计体系在重复执行中变得僵化、失真或被绕开。

### 身份折旧

某些身份标签、资格认证和信用凭证会随时间、滥用和普及而逐渐失去原有价值。

### 信誉折旧

机构、阵营和节点的承诺若被反复透支，即使表面仍在运转，也会慢慢失去可信度。

## 折旧的制度问题

### 计提

文明必须把折旧当成真实成本持续记账，而不是等坏掉了才承认耗损存在。

### 更新

哪些东西值得修复、替换、重建，哪些东西已不值得继续投料，是现实取舍问题。

### 伪年轻化

若系统不断涂新外壳、换新口号却不更换损坏核心，就会制造危险的年轻幻觉。

### 代际转嫁

折旧成本常被推给未来节点和下一代成员，形成表面稳定、后代埋单的结构。

## 折旧政治

1. 谁来定义什么算“正常磨损”，谁就能决定何时继续榨取、何时允许更换。
2. 核心区是否通过优先维护自身，把折旧集中堆给边缘基础设施和边缘群体。
3. 某些高位结构会不会故意低报折旧，好维持增长神话与扩张叙事。
4. 当身份和信誉也开始折旧时，文明是否还保有稳定继承的条件。

## 折旧风险

- 吃老本治理：长期依赖旧资产残余能力，直到突然整体坍塌。
- 折旧失真：报表上的折旧被美化，真正损耗被藏到不可见处。
- 维护贵族化：只有核心节点能获得持续保养，其他区域被默认报废。
- 更新失序：集中更换过多旧系统，反而引发更大范围的不兼容与停摆。

## 折旧域中的关键问题

1. 文明更该害怕折旧本身，还是害怕不承认折旧的治理习惯。
2. 哪些东西应该尽快折旧重建，哪些东西即使老化也值得继续维持。
3. 如果 MOSS 的繁荣主要来自尚未结清的折旧账，它是否已经在透支未来存续。

## 继续细化建议

- 单独写“第一次全域折旧审计”档案。
- 建一份设备折旧、制度折旧和信誉折旧的计提模型表。
- 补一份“某项被低报折旧的基础设施如何引发连锁停摆”的案例。
