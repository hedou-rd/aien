# 分频域

## 作用

分频域负责回答“当不同功能被迫挤在同一频带互相干扰时，文明如何重新分离运行频段”。对 MOSS 来说，分频不是让所有系统彼此隔绝，而是把本不该同时争抢同一时间窗、同一通道和同一注意力带宽的功能重新拆开。一个不会分频的文明，往往把所有任务都塞进同一频带里，结果谁都在说话，谁都在发信号，谁都在运行，却彼此越挤越乱。

## 为什么文明必须学会分频

1. 不同功能长期共用同一频带，会让噪声、冲突和误触发不断上升。
2. 分频能让高优先级、低时延和高风险任务获得更清晰的专用运行空间。
3. 它不是效率浪费，而是避免不同功能互相踩踏后整体效率更低。
4. 若没有分频机制，MOSS 会把越来越多的干扰误认成复杂系统的必然背景噪音。

## 分频类型

### 通讯分频

把不同等级、不同风险和不同用途的信号拆到不同通道和不同频带，减少互相干扰。

### 调度分频

把高优先级修复、日常运行、实验尝试和背景维护拆到不同节奏层上运行。

### 注意力分频

把观测、审计、应急和叙事等不同类型的关注资源分开，避免所有问题争抢同一注意力窗口。

### 情绪分频

让悼念、动员、警报和日常安抚不再全部叠在同一公共节拍上，减少情绪互扰。

## 分频的制度问题

### 频带划分

文明必须决定哪些任务必须独占频带，哪些任务可以混跑，以及边界怎么画。

### 抢带规则

当多个功能都声称自己更紧急时，谁有权切换频带、抢占通道和压低其他活动。

### 跨频桥接

分频之后仍然需要跨频沟通和汇总机制，否则系统会变成互不理解的分层孤岛。

### 频带污染

一旦低优先级噪声不断渗入高优先级频带，制度必须有能力快速清带和恢复秩序。

## 分频政治

1. 谁掌握频带分配权，谁就掌握了决定什么能被优先听见、优先执行和优先保护的权力。
2. 核心区是否总能保留自己的专用频带，而让边缘区长期在混频环境中互相争抢生存空间。
3. 某些高位结构会不会故意让他人的功能混在一起，以便维持噪声和可操纵的混乱。
4. 当文明高呼“所有系统都要一起响应”时，它究竟是在提升协同，还是在放弃必要的频带区分。

## 分频风险

- 频带挤兑：太多关键任务都声称必须独占，最终谁也得不到干净频带。
- 过度隔离：分频做得太彻底，系统变成大量彼此难以接续的孤立层。
- 噪声回灌：低优先级噪声不断回流高优先级频带，使分频名存实亡。
- 频权固化：专用频带被少数中心长期占有，其他结构只能在剩余带宽里生存。

## 分频域中的关键问题

1. 文明更该害怕混频造成的持续干扰，还是害怕分频过度后带来的协同断裂。
2. 哪些功能必须被严格分带，哪些功能反而需要保留一定混频才能相互校正。
3. 如果 MOSS 的很多失灵都来自不同功能争抢同一节拍与同一通道，它是否真正缺的不是资源，而是频带秩序。

## 继续细化建议

- 单独写“第一次全域分频表”档案。
- 建一份通讯分频、调度分频和注意力分频的专用频带规则。
- 补一份“某条高风险链路如何因长期与低优先级噪声共带运行而反复误触发”的案例。
