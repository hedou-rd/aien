# 休耕域

## 作用

休耕域负责回答“为什么有时文明要靠主动停用、冷却和不继续榨取，才能真正活得更久”。对 MOSS 来说，休耕不是懒惰或退却，而是一种对设施、区域、制度和群体进行阶段性撤压、停机和恢复的安排。一个永远要求满负荷输出的文明，最终会把自己的土壤、设备和关系一起榨干。

## 为什么文明需要休耕逻辑

1. 长期高强度运转会让设施疲劳、生态失衡和成员耗竭同步累积。
2. 某些区域和制度若不经历主动冷却，只会在继续使用中快速报废。
3. 休耕让文明承认并不是所有价值都来自即时产出，恢复力本身也是资产。
4. 若没有休耕机制，MOSS 会把每一次短期收益都换成长期寿命折损。

## 休耕类型

### 设施休耕

对高负载工厂、能源回路、交通节点和数据中心进行计划性停用、检修和冷却。

### 区域休耕

对被过度采掘、污染积累或长期作为缓冲垫的地区给予暂停使用与修复窗口。

### 制度休耕

暂停高压考核、过密审计和高频动员，让规则系统也有机会减载与重构。

### 群体休耕

让长期处在前线、重负荷或高度创伤中的成员获得退场、轮换和恢复期。

## 休耕的制度问题

### 选择对象

谁有资格休耕、谁必须继续顶上，决定休耕是否只是特权配置。

### 恢复指标

休耕不能只靠抽象愿望，必须定义何种状态算真正恢复而非暂时停摆。

### 替代安排

被休耕的部分不能直接消失，系统必须准备替代供给与承接结构。

### 重新开耕

何时重新启动、以何种负载回归、是否需要调整原有使用方式，是休耕成败关键。

## 休耕政治

1. 谁被允许停下来，谁被要求继续燃烧，体现文明对不同对象寿命的估值。
2. 核心区是否把边缘区永久当成不可休耕的资源田和压力垫。
3. 某些高位结构会不会借休耕之名冻结责任、拖延改革和延后补偿。
4. 当共同体把“不停产”当成唯一美德时，休耕会不会反而变成一种政治异议。

## 休耕风险

- 休耕特权化：只有高位机构与核心节点能获得恢复窗口。
- 伪休耕：名义停用，实际负荷通过外包和隐性转移继续存在。
- 重启报复：休耕结束后为补产能而一次性超载，反而更快损坏。
- 长期弃耕：原本计划性休养被拖成事实性放弃，相关群体失去回归路径。

## 休耕域中的关键问题

1. 文明更该害怕短期停产带来的损失，还是害怕永不休耕带来的慢性报废。
2. 哪些系统必须定期休耕，哪些系统即使休耕代价很高也仍应被迫停下。
3. 如果 MOSS 学不会停机与退压，它是否终将把所有增长都换成不可逆耗竭。

## 继续细化建议

- 建一份设施休耕、区域休耕和群体休耕的恢复指标表。
- 补一份“某个永不休耕的能源节点如何在高负载下最终报废”的案例。
