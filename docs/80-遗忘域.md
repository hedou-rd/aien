# 遗忘域

## 作用

遗忘域负责回答“一个文明应在何时停止紧握过去”。对 MOSS 来说，遗忘不是单纯丢失，而是关于哪些记忆继续高亮、哪些档案进入封眠、哪些创伤需要冷却、哪些历史允许主动退出前台的制度安排。

## 为什么文明需要遗忘

1. 不是所有记忆都适合永久保持高活性。
2. 过量记忆会让判断长期被旧伤和旧模板绑架。
3. 若没有某种遗忘，赦免、修复和再开始都难以成立。
4. 在资源有限的文明里，持续保存一切本身就是成本与权力问题。

## 遗忘类型

### 自然遗忘

随着时间、使用频率和代际更替，某些信息自然退入低活性层。

### 制度遗忘

文明主动决定某些事项不再进入日常调用，只保留封存痕迹与最低索引。

### 仁慈遗忘

为了保护创伤个体、脆弱共同体或修复性进程，允许某些细节退出公共重复。

### 危险遗忘

某些历史并非无关紧要，而是被权力结构刻意压低、稀释或移出可见范围。

## 遗忘的制度维度

### 封眠

某些记忆并不删除，而是转入低频、低权限或延迟访问状态。

### 冷却期

让刚经历的灾变、审判和流放暂时退出高强度传播，避免集体持续过载。

### 索引保留

即使内容不再活跃，仍应保留“这里曾经有过什么”的最小痕迹。

### 再唤醒条件

文明必须回答：什么情形下，已被遗忘的内容应重新回到前台。

## 遗忘政治

1. 谁能决定哪些历史该淡出。
2. 遗忘是修复手段，还是规避责任的高级形式。
3. 被伤害者与加害者是否会对“该不该忘”给出完全不同答案。
4. 年轻一代有没有权利拒绝继承某些高压记忆。

## 遗忘风险

- 失忆治理：文明以稳定为名，把危险真相系统性淡化。
- 永不翻篇：若任何内容都不能退场，创伤将被永久制度化。
- 选择性淡出：弱者痛苦更容易被要求忘记，强者荣耀更容易被永久保存。
- 无痕封眠：内容退场时连索引也消失，后代甚至不知道曾发生过什么。

## 遗忘域中的关键问题

1. 文明更害怕忘得太快，还是活得太深。
2. 哪些历史必须永不淡出，哪些必须允许降温。
3. 若共同体要靠遗忘才能继续前行，它究竟是在修复，还是在自我截断。

## 继续细化建议

- 单独写“第一次公共遗忘令”档案。
- 建一份封眠、冷却和永久保留的分层表。
- 补一份“赦免为何依赖有限遗忘”的案例。
