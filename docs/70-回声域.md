# 回声域

## 作用

回声域负责回答“为什么旧时代明明过去了，却还在今天说话”。在 MOSS 中，回声是旧口号、旧创伤、旧制度、旧偏见和旧胜利叙事在新秩序中的残留影响。它们未必被正式承认，却持续左右判断、语言和反应模式。

## 为什么文明会被回声塑形

1. 制度可以更新，但集体反应不会同步清零。
2. 历史创伤和荣耀会通过语言、教育、节庆和审判长期重复。
3. 某些旧秩序即使被推翻，也会在新秩序里换名重生。
4. 回声是文明记忆的惯性，也是文明自我误判的重要来源。

## 回声类型

### 创伤回声

大停电、算力饥荒、背叛和流放留下的长期警戒反应，会在后来很多无关情境中被重新触发。

### 制度回声

某些旧规则虽然已经废除，但它们的审议习惯、权力姿态和偏好排序仍留在组织行为里。

### 语言回声

旧口号、旧隐喻和旧敌我划分继续在媒介和公共讨论中循环，压缩新的表达空间。

### 荣耀回声

曾经的扩张胜利、危机幸存和牺牲神话，会持续要求后代模仿过去的英雄姿态。

## 回声的传播路径

### 教育

代际训练最容易把过去的恐惧和偏好包装成理所当然。

### 媒介

重复播送和公共叙事会把历史反应变成今日常识。

### 仪式与节庆

纪念行为既保留历史，也可能把历史固定成难以修正的自动反应。

### 法理与审判

旧案判例和创伤性裁决会让后续案件被同一种历史模板强行解释。

## 回声政治

1. 谁能命名哪些东西是健康记忆，哪些只是病态回声。
2. 核心区是否利用旧创伤不断延长紧急状态。
3. 某些阵营是否靠垄断“真正的历史回声”维持合法性。
4. 当年轻一代拒绝继承旧反应模式时，会不会被视为背叛。

## 回声风险

- 创伤统治：历史伤口成为永久正当化工具。
- 怀旧复辟：旧制度通过回声包装重新回到中心。
- 反应迟滞：文明总按上一场灾难的模板应对下一场不同危机。
- 自我失语：新经验始终被旧语言吞没，无法形成真正新判断。

## 回声域中的关键问题

1. 文明要如何区分“记住历史”和“被历史操控”。
2. 哪些回声应被保存，哪些应被主动削弱。
3. 如果回声本身构成了共同体认同，文明是否真的有能力走出过去。

## 继续细化建议

- 单独写“第一次回声清理运动”档案。
- 建一份创伤回声与荣耀回声对照表。
- 补一份“旧口号如何在新危机中误导决策”的案例。
