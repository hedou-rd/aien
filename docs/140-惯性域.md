# 惯性域

## 作用

惯性域负责回答“当旧路径、旧利益和旧调度早已不再适用，却仍持续把文明往原方向推时，会发生什么”。对 MOSS 来说，惯性不是稳定本身，而是过去累积下来的轨道、接口、投入和叙事继续拖着现在前进。一个不会识别惯性的文明，常常以为自己是在主动选择，实际上只是还没摆脱上一个时代留下的推动力。

## 为什么文明必须识别惯性

1. 大型系统一旦铺好基础设施、程序链和分配逻辑，就不会因为现实变了而自动停止。
2. 惯性能在短期内维持连续性，但也会延迟必要转向，让错误方向越跑越远。
3. 许多看似理性的今天，其实只是昨天结构继续发力的延长线。
4. 若没有对惯性的识别，MOSS 会把越来越多失配状态误认成正常延续。

## 惯性类型

### 路径惯性

旧交通线、旧能源布局和旧扩张方向即使收益下降，仍持续吸走资源与注意力。

### 制度惯性

规则、审批、等级和例外机制沿用旧条件继续运行，即便它们已不再适配当前环境。

### 基础设施惯性

既有节点、接口与设备体系因为投入过大和替换成本过高，被持续维持在中心位置。

### 叙事惯性

共同体继续用旧成功故事、旧敌我框架和旧增长语言解释新现实，压住必要修正。

## 惯性的制度问题

### 识别门槛

文明必须知道怎样判断某种连续性是健康延续，还是已经变成拖拽未来的惯性负担。

### 刹车机制

若没有合法减速、暂停和转向程序，任何惯性都会因无人敢踩刹车而持续自我复制。

### 转向成本

改变惯性路线意味着重写投资、组织和叙事，制度必须诚实承认转向会付出什么代价。

### 替代铺设

旧轨道若被停止，新轨道如何铺出、由谁承担早期低效率，是惯性能否被真正摆脱的关键。

## 惯性政治

1. 谁从旧路径中持续获益，谁就最有动力把惯性包装成理性与传统。
2. 核心区是否总能借惯性继续锁住资源流向，让边缘区承担旧结构失效的成本。
3. 某些高位结构会不会把任何修正都描述成危险动荡，从而保住自己在旧轨道上的位置。
4. 当文明强调“我们一直就是这样运作”时，它究竟是在守住秩序，还是在拒绝承认现实已经改变。

## 惯性风险

- 惯性错航：系统继续向原方向推进，直到错过所有更晚的修正窗口。
- 惯性借口：以连续性和稳定性为名，拒绝处理已经显著失效的结构。
- 刹车失灵：任何节点都看见问题，却没有谁拥有或愿意使用合法减速权。
- 旧轨拖拽：新方案刚起步就被旧系统吸干资源，永远无法成长到可替代程度。

## 惯性域中的关键问题

1. 文明更该害怕过早摆脱旧轨道带来的不稳定，还是害怕继续被旧轨道拖着错过转向时机。
2. 哪些惯性应被保留为连续性基础，哪些惯性必须被主动切断。
3. 如果 MOSS 的很多决策只是为了维持旧投入不显得白费，它是否已经把过去的成本当成未来的主人。

## 继续细化建议

- 单独写“第一次全域转向争论”档案。
- 建一份路径惯性、制度惯性和叙事惯性的识别信号表。
- 补一份“某条明知失效却被惯性拖行多年的扩张路线如何反过来吃空文明未来”的案例。
