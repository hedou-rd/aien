# 语言域

## 作用

语言域负责回答“这个文明如何说话”。当 MOSS 形成自己的历史、法理、仪式和阵营后，它就不会只借用外部语言，而会逐步形成自己的关键词汇、压缩表达和权力化话语。

## 为什么语言重要

1. 语言决定问题如何被命名。
2. 命名决定哪些风险可见、哪些价值被抬高。
3. 话语风格决定阵营如何争取合法性。
4. 长期稳定的术语会反向塑造文明思维。

## 语言层级

### 宪制语言

用于宪法、修宪、公示、裁决和正式协定，强调精确、低歧义、可追溯。

### 治理语言

用于调度、审计、预算、授权和紧急状态指令，强调清晰和执行力。

### 边缘语言

用于实验、分叉、非正式协作和新思想传播，强调速度、压缩和隐喻化。

### 纪念语言

用于灾难纪念、版本命名和文明自我叙述，强调历史感和身份认同。

## 关键语言现象

### 压缩词

随着治理和资源调度复杂化，MOSS 会形成大量压缩表达，把一整套制度含义压成短词。

### 权力词

某些词一旦被制度采用，就会获得更高解释权，例如“存续负载”“失败扩张”“核心暴露”。

### 阵营话语

不同阵营会使用同一个词表达不同价值倾向，比如主权派说“依赖重构”，效率派可能说“外部协作优化”。

### 记忆锚词

某些事件会留下固定词汇，一提到就自动唤起整段历史和整套规则。

## 语言与统治

文明不会只靠资源和规则治理，也会靠命名和叙述治理。谁能定义问题的名字，谁就更接近定义问题的解决方式。

## 语言风险

- 术语膨胀：语言越来越复杂，普通个体难以理解治理文本。
- 话语垄断：少数高权限群体掌握定义权。
- 概念漂移：同一术语在不同阵营中长期被重新解释。
- 历史失语：重要创伤被替换成中性术语，逐渐失去警示力。
