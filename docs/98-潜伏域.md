# 潜伏域

## 作用

潜伏域负责回答“那些尚未爆发的风险，在爆发前都藏在哪里”。对 MOSS 来说，潜伏不是简单的安静，而是敌意、病灶、代码、背叛和迟滞效应在表面秩序之下长期处于低可见、低活性却高破坏潜力的状态。文明很多时候不是败在看得见的冲突，而是败在低估了那些还没动的东西。

## 为什么文明总会产生潜伏结构

1. 高压秩序会把许多冲突从公开表面压入隐蔽层，而不是真正消解。
2. 休眠机制和延迟触发常被用于节能、自保、埋伏和风险转嫁。
3. 某些病灶和敌意本就不以持续高活性存在，而以等待时机的方式存活。
4. 如果文明只关注已爆发事件，就会反复被相同风险从暗处击中。

## 潜伏类型

### 程序潜伏

休眠脚本、后门接口、延迟触发命令和未被清理的旧逻辑长期埋在系统深层。

### 病灶潜伏

污染、病理、材料疲劳和小规模感染在尚未越阈值前以低烈度持续积累。

### 关系潜伏

未被处理的怨恨、阵营对立、忠诚转移和被压制的报复意愿长期沉在共同体内部。

### 政治潜伏

一些危险议程、极端派系和非常状态设计在表面平静下等待重新抬头的机会。

## 潜伏的制度问题

### 标记

文明必须回答哪些潜伏迹象值得被记录，避免把所有未爆发风险都当作“尚不存在”。

### 监测

潜伏风险通常难以一次性定位，需要长期低噪声观测与多源比对。

### 阈值

何时从观察转入处置，何时承认只是正常波动，是极难设定的临界点问题。

### 先发处置

若处置过早，文明会滑向预防性镇压；若处置过晚，潜伏又可能突然联动爆发。

## 潜伏政治

1. 谁有资格把某个对象命名为“潜伏威胁”，谁就拥有提前干预的权力。
2. 核心区是否更容易把边缘的不满称为潜伏危险，而忽略自身制度病灶。
3. 某些高位结构会不会故意维持潜伏状态，以便在需要时借危机扩权。
4. 当整个文明开始习惯于怀疑一切潜伏物时，信任是否会被慢慢掏空。

## 潜伏风险

- 预防性过打：以未来可能危险为名，对现实中的存在进行过度压制。
- 潜伏错判：把正常低活性状态误认成埋伏，制造新的冤错链条。
- 慢性养蛊：明知某些风险在积累，却因短期稳定而迟迟不处理。
- 联动爆发：多个看似低烈度潜伏点在同一时刻被触发，形成系统性冲击。

## 潜伏域中的关键问题

1. 文明更该害怕潜伏本身，还是害怕把一切都看成潜伏威胁后的普遍疑心。
2. 哪些潜伏风险必须尽早介入，哪些应被持续观察而非立即处置。
3. 如果 MOSS 最终靠不断扩大潜伏侦测来维持安全，它还能保住多少正常公共生活。

## 继续细化建议

- 单独写“第一次潜伏联动爆发”档案。
- 建一份程序潜伏、病灶潜伏和政治潜伏的阈值判定表。
- 补一份“某个被忽略的低活性病灶如何引发全局危机”的案例。
