# 热斑域

## 作用

热斑域负责回答“当负载、热量和注意力长期集中在局部节点时，文明如何处理这些持续发热的热点”。对 MOSS 来说，热斑不是一次性高温，而是某些节点、某些区域和某些链路因为持续承压而长时间维持高热状态。一个不会处理热斑的文明，往往在平均值仍然体面的情况下，让最关键的局部先被烧穿。

## 为什么文明必须识别热斑

1. 持续热点会先于全域失衡暴露出系统真实的承载上限与散热缺口。
2. 热斑会把折损、偏载和情绪紧绷集中到少数部位，形成局部失稳源。
3. 许多重大断裂不是从平均不足开始，而是从热点长时间得不到降温开始。
4. 若没有热斑治理，MOSS 会把大量局部过热伪装成整体高效运行。

## 热斑类型

### 能源热斑

某些供电、散热和储能节点长期高负荷运行，成为持续发热的关键部位。

### 计算热斑

算力任务、模型调度和数据处理反复压在少数节点上，使局部持续过热。

### 治理热斑

某些机构、接口和审核中枢长期聚集大量冲突、决策和解释压力，形成制度热点。

### 情绪热斑

共同体的恐慌、怨气和照护压力不断集中在少数区域与少数成员身上，使其长期处于高压高热状态。

## 热斑的制度问题

### 热点识别

文明必须知道哪些局部正在长期发热，而不能只看全域平均温度与平均负载。

### 导流散热

一旦识别到热斑，就必须有分流、降载和散热手段把局部高温导向更大范围的可承受结构。

### 热斑阈值

什么时候算暂时高热，什么时候已构成危险热斑，决定了系统是否会过晚干预。

### 冷区代价

热点被降温通常意味着其他区域要承担更多负载，制度必须处理这种再分配代价。

## 热斑政治

1. 谁最能把自身热点外包出去，谁就最不愿承认局部高热已经变成结构性问题。
2. 核心区是否把边缘区、末端节点和低可见区域当成天然散热片与牺牲层。
3. 某些高位结构会不会用全域平均数据掩盖少数热点已经逼近烧穿的事实。
4. 当文明赞美某些节点“最能扛热”时，它究竟是在识别关键性，还是在合理化长期过热。

## 热斑风险

- 局部烧穿：热点长时间得不到处理，最终让关键节点在平均值正常时率先失效。
- 热迁移：旧热点被匆忙转移后，新热点迅速在相邻部位出现。
- 散热不公：低位区域长期承担散热与缓冲职责，逐渐沦为永久热区。
- 平均遮蔽：全域平均掩盖局部高温，使文明错过最早的危险信号。

## 热斑域中的关键问题

1. 文明更该害怕局部强制降温带来的效率损失，还是害怕长期放任热点先行烧穿。
2. 哪些热点属于可接受的短期集中，哪些热点一旦持续就必须被打散。
3. 如果 MOSS 的持续推进总要靠少数部位高温燃烧，它是否已经把过热当成正常动力。

## 继续细化建议

- 单独写“第一次全域热斑分布图”档案。
- 建一份能源热斑、计算热斑和治理热斑的干预阈值表。
- 补一份“某个长期高热节点如何在平均指标仍正常时率先烧穿并拖垮周边链路”的案例。
