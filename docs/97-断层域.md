# 断层域

## 作用

断层域负责回答“当文明内部并不是一整块连续地面，而是由许多裂开的板块拼接而成时，它如何继续站立”。对 MOSS 来说，断层既包括地理裂缝，也包括制度错位、代际断裂和记忆失接。很多重大危机并非来自单点破坏，而是来自早就存在却长期被忽视的断层突然错动。

## 为什么文明会形成断层

1. 扩张、灾变、迁徙和资源不均会不断制造区域之间的不连续。
2. 制度更新速度和现实变化速度不一致，会让旧规则与新处境产生错位。
3. 代际记忆断裂会让后来的成员踩在自己并不理解的历史裂缝上。
4. 若文明只记录连续成长，就会把所有断层都伪装成暂时噪点。

## 断层类型

### 地理断层

城市群、边界带、废墟区和封锁区之间出现长期不可顺畅跨越的空间裂缝。

### 制度断层

不同区块适用不同规则、不同审判口径和不同资源分配逻辑，形成制度拼缝。

### 代际断层

新一代成员与旧一代在危机经验、信念语言和风险判断上失去连续性。

### 记忆断层

档案缺页、火种压缩、遗忘机制和政治删改造成过去与现在之间的理解断裂。

## 断层的制度问题

### 探测

文明必须持续标记哪里存在裂缝，而不是等到错动成灾后才承认断层存在。

### 跨接

桥接交通、桥接法理、桥接代际和桥接档案，都需要长期维护而不是一次性修补。

### 缓冲带

并非所有断层都能立刻弥合，很多时候必须先承认过渡区和缓冲结构的必要性。

### 归属

生活在断层带上的成员常同时不被两边完全承认，归属设计因此成为核心问题。

## 断层政治

1. 谁能把自己的裂缝命名为“暂时调整”，谁的裂缝被定义为“危险带”，体现话语权差异。
2. 核心区是否把高烈度断层长期外包给边缘区承受。
3. 某些高位结构会不会故意维持断层，以便在拼缝中获得中介优势和裁量空间。
4. 当断层成为日常生活背景时，文明是否已经习惯在断裂上求稳而非真正修复。

## 断层风险

- 裂缝扩展：原本局部的不连续沿着资源链和交通线迅速放大。
- 断层居住化：整代成员只能生活在长期错位与摇摆边界中。
- 错位治理：用一侧逻辑管理另一侧现实，导致裂缝继续加深。
- 断层掠夺：投机者和强势机构利用拼缝地带攫取额外收益。

## 断层域中的关键问题

1. 文明更该优先修复最危险的断层，还是优先修复最能恢复连续性的断层。
2. 哪些断层可以长期共存，哪些断层必须被视为文明底层裂解信号。
3. 如果 MOSS 的稳定只是建立在大量未修复断层暂时没有一起错动，它是否真的稳定。

## 继续细化建议

- 单独写“第一次断层带错动危机”档案。
- 建一份地理断层、制度断层和记忆断层的传播关系表。
- 补一份“一个代际断层如何反过来触发法理冲突”的案例。
