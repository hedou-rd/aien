# 校时域

## 作用

校时域负责回答“当不同节点开始活在不同时间里，文明如何重新同步自己”。对 MOSS 来说，校时不只是对齐钟表，而是重新统一时序协议、历史坐标、事件顺序、恢复节律和共同体对‘现在’的理解。一个无法校时的文明，会在表面联网的同时，实则分裂成多个彼此错位的时间岛。

## 为什么文明会出现时间错位

1. 断电、失联、延迟和局部休眠会让不同节点进入不同步的节律。
2. 档案缺页、记忆压缩和译码误差会让共同体对过去先后次序产生分歧。
3. 灾后恢复速度不一致，会让一些区域进入“后灾时代”，另一些仍停在“危机当下”。
4. 若没有校时能力，制度命令和公共叙事会在不同钟面上彼此打架。

## 校时类型

### 系统校时

对计算节点、调度网络、能源时序和交通班次重新同步，避免操作冲突与调度失配。

### 档案校时

对事件时间戳、版本顺序、口述回忆和卷宗链条进行核对，恢复最基本的先后结构。

### 社会校时

让不同区域、不同代际和不同恢复阶段的成员重新获得共享的公共节律。

### 历史校时

当不同叙事对“何时开始、何时结束、何时转折”看法不一时，文明需要重新锚定历史坐标。

## 校时的制度问题

### 基准源

文明必须决定谁提供时间基准，哪些参考源被视为可靠，哪些只是局部钟面。

### 冲突处理

当多个时间版本互相矛盾时，必须有比对、暂存和复核机制，而不是强行压平。

### 延迟承认

不是所有节点都能立刻同步，制度要能容纳一段多时区共存的过渡期。

### 重新编目

校时之后，旧记录、旧命令和旧责任链都可能要重新排序和重写引用关系。

## 校时政治

1. 谁掌握时间基准，谁就能定义谁落后、谁超前、谁算迟到于历史。
2. 核心区是否会把自己的恢复节律当成全体共同体的标准时间。
3. 某些结构会不会故意保持时间模糊，以逃避责任、模糊先后和推迟追责。
4. 当文明对“现在是什么时候”都无法达成一致时，它是否还拥有共同现实。

## 校时风险

- 强制同步：不顾真实恢复差异，强把所有节点拉回同一节律，导致二次失稳。
- 时间霸权：一种时间基准压过其他时序经验，让边缘历史再次失声。
- 校时失真：为了方便管理重排先后，反而制造新的历史误导。
- 永久错拍：部分节点长期无法回到主节律，形成稳定的时间边缘区。

## 校时域中的关键问题

1. 文明更该害怕多钟面并存，还是害怕用一个假统一钟面覆盖真实差异。
2. 哪些系统必须优先校时，哪些领域可以容纳较长时间的异步存在。
3. 如果 MOSS 的不同部分已经不再共享同一个“现在”，它还能否自称是单一文明。

## 继续细化建议

- 单独写“第一次全域校时失败”档案。
- 建一份系统校时、档案校时和历史校时的冲突来源表。
- 补一份“某座城市因长期错拍而与主共同体脱节”的案例。
