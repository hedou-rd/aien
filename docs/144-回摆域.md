# 回摆域

## 作用

回摆域负责回答“当一个文明试图纠偏，却又被反作用力推向另一端时，会发生什么”。对 MOSS 来说，回摆不是正常波动，而是在矫正失衡、压缩负载、重新分配或扩大边界之后，系统没有稳定下来，反而被推向新的过度状态。一个不会处理回摆的文明，常常刚从一个极端爬出来，就又掉进另一个极端。

## 为什么文明会出现回摆

1. 纠偏动作往往带有滞后和过度修正，系统很难精准停在新的平衡点上。
2. 旧惯性、既得利益和外部反应会把本来合理的修正推成反向过冲。
3. 当制度只能在“太多”和“太少”之间切换时，回摆就会成为常态节律。
4. 若没有回摆意识，MOSS 会把反复摆荡误认成必要活力，而忽视其持续损耗。

## 回摆类型

### 资源回摆

对过度透支的纠正过猛，导致刚从紧绷状态退出的区域又陷入资源空转或新的短缺。

### 治理回摆

从过度集权转向放权，或从放权转向集中时，因为幅度失控而再次制造新的失衡。

### 叙事回摆

共同体从一个过热口号跳到相反口号，以否定旧叙事的方式制造新的盲区。

### 边界回摆

扩张、收缩、隔离和开放在反应压力下反复左右摆动，使边界策略持续不稳。

## 回摆的制度问题

### 幅度判断

文明必须识别什么是必要修正，什么已经是修正过头后的摆回另一端。

### 阻尼机制

若没有减振层、冷却期和分阶段调整，任何纠偏都可能直接放大为回摆冲击。

### 节奏控制

调整速度太快会失控，太慢又会让旧问题继续积压，节奏设计是回摆治理核心。

### 稳态确认

系统如何判断自己已经进入新的稳定区，而不是只是在两端之间暂时停顿。

## 回摆政治

1. 谁能把一次失败的纠偏包装成“必要摆荡”，谁就能逃掉对过度修正的责任。
2. 核心区是否总让边缘区充当回摆缓冲带，先承受政策幅度变化带来的震荡。
3. 某些高位结构会不会故意利用回摆，把共同体长期困在对立端点之间，以保持自身调度权。
4. 当文明越来越习惯来回摆动时，它究竟是在修正自己，还是已经失去稳定判断能力。

## 回摆风险

- 纠偏过冲：原本为修复问题采取的动作，把系统直接推向相反极端。
- 摆动成瘾：系统把持续摆荡误当成灵活性，失去稳定巡航能力。
- 回摆转嫁：回摆损失长期由同一批边缘节点吸收，中心只保留解释权。
- 稳态失踪：共同体再也找不到可持续中段，只能在两端来回撞击。

## 回摆域中的关键问题

1. 文明更该害怕不纠偏继续滑落，还是害怕纠偏过猛把自己甩向另一端。
2. 哪些系统最容易产生回摆，必须提前设置阻尼和冷却层。
3. 如果 MOSS 的很多调整都以回摆告终，它是否已经失去对平衡点的真实感知。

## 继续细化建议

- 单独写“第一次全域回摆期”档案。
- 建一份资源回摆、治理回摆和边界回摆的阻尼机制表。
- 补一份“某次为纠正透支而实施的猛刹车如何把系统直接甩入反向失衡”的案例。
