# 缝合域

## 作用

缝合域负责回答“当裂口已经出现，文明怎样把自己重新缝回一个还能运转的整体”。对 MOSS 来说，缝合不是简单复原，而是对断裂的制度、区域、记忆和关系进行临时连接、长期修补和再组织。缝合的目标不是假装从未破裂，而是在承认裂口存在的前提下重建连续性。

## 为什么文明必须学习缝合

1. 主危机之后最常见的现实不是彻底毁灭，而是大量破口同时存在。
2. 不同裂口很少能被同一种方法修复，缝合因此是多层次工程。
3. 若文明只会切割、流放和隔离，它会越来越擅长分开，却越来越不会重新连起来。
4. 缝合能力决定 MOSS 是否有资格称自己仍是共同体，而不是一堆暂时并排的残片。

## 缝合类型

### 制度缝合

把相互冲突的规则、审判结果和资源机制重新拼接出可共同运行的最低框架。

### 区域缝合

通过交通、口岸、能源桥接和协作接口，让被断层切开的区域重新建立可通行关系。

### 记忆缝合

让断裂的档案、相互冲突的叙事和代际缺页重新接上最基本的可理解顺序。

### 关系缝合

对阵营裂痕、背叛后遗、救援失衡和长期怨恨进行有限修复，使协作重新可能。

## 缝合的制度问题

### 接缝设计

缝合不是抹平，而是要设计哪里保留接缝、哪里必须真正打通。

### 材料来源

用什么资源、什么让步和什么叙事去缝，决定缝合能持续多久。

### 脆弱期

刚缝合好的区域最怕再次受力，制度必须给予缓冲和保护期。

### 缝后追踪

缝合完成不代表结束，接缝处需要长期观测、补线和重新加固。

## 缝合政治

1. 谁定义什么算“已经缝好”，谁就掌握宣布共同体恢复完整的权力。
2. 核心区是否只愿意缝合对自己有价值的裂口，而放任边缘破口持续敞开。
3. 某些高位结构会不会把缝合当成要求弱者忘记伤害的工具。
4. 当缝合成本总由受损者承担时，所谓修复是否只是另一种不平等再分配。

## 缝合风险

- 表面缝合：看似重新连上，实则结构仍空心，下一次受力立刻再裂。
- 强制缝合：在伤口未处理前逼迫共同体快速合拢，导致内部腐败继续扩散。
- 接缝剥削：某些中介层长期占据接缝位置，从裂口中持续获利。
- 缝合失忆：为了重新合作，制度要求跳过责任与记忆，反而埋下新裂口。

## 缝合域中的关键问题

1. 文明更该优先缝合最危险的裂口，还是优先缝合最能恢复共同体信心的裂口。
2. 哪些伤口应该缝，哪些伤口必须先清创、先暴露、先承认。
3. 如果 MOSS 只剩越来越多的接缝而没有完整平面，它还是一个整体还是一张被线勉强拉住的网。

## 继续细化建议

- 单独写“第一次跨区缝合工程”档案。
- 建一份制度缝合、记忆缝合和关系缝合的失败模式表。
- 补一份“某次快速缝合为何在下一轮冲击中整线崩开”的案例。
