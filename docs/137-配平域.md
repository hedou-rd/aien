# 配平域

## 作用

配平域负责回答“当一个文明内部的负载、权益、风险和增长速度长期不在同一水平线上时，怎样把它重新拉回可承受的范围”。对 MOSS 来说，配平不是绝对平均，而是在承认差异的前提下，避免某些区域被长期压穿、某些区域长期独占余量与收益。一个不会配平的文明，迟早会在失衡累积中把自己的共同体撕成互不愿继续共担代价的碎片。

## 为什么文明必须反复配平

1. 扩张、接管、复燃和续航都会自然制造新的中心与新的边缘。
2. 若不主动配平，负担会越来越向弱者沉积，收益会越来越向强者集中。
3. 配平让系统在不彻底抹平差异的情况下，重新获得继续协作的最低公平感。
4. 若没有配平机制，MOSS 的长期稳定只会建立在越来越脆弱的失衡结构上。

## 配平类型

### 负载配平

把维护压力、能耗压力、物流压力和治理压力在不同区域与节点之间重新分摊，避免某处长期超载。

### 资源配平

重新调整能源、算力、材料和维修能力的分布，使基础生存与关键功能不被单侧垄断。

### 权益配平

重新审视不同共同体、区域和岗位承担风险后的分配回报，避免长期只付出不受益。

### 节奏配平

让不同区域的扩张速度、修复速度和压缩速度重新协调，避免有人永远冲刺、有人永远补坑。

## 配平的制度问题

### 基准口径

文明必须先回答按什么口径算失衡，避免所有配平争议都被卡在各说各话的统计起点上。

### 调节权限

谁能动别人的资源、改别人的配额、压别人的负载，是配平是否可执行的核心。

### 补偿机制

被长期抽用和长期超载的区域如何获得补偿，决定配平是修复关系还是制造新怨。

### 周期复核

配平不是一次性动作，若没有周期复核，系统很快会回到原有失衡轨道。

## 配平政治

1. 谁能定义什么叫“已经平衡”，谁就掌握了把自身优势常态化的能力。
2. 核心区是否总把自己的高收益描述成应得，把边缘区的额外负担描述成必要牺牲。
3. 某些高位结构会不会把配平口号当成合法抽调工具，却从不真正改变不平等底盘。
4. 当文明开始强谈配平时，它究竟是在修复共同体，还是已经被失衡逼到临界点。

## 配平风险

- 表面配平：账面数字被调平，真实负担和真实风险却继续单侧堆积。
- 强制齐平：为了追求形式公平，粗暴抹掉不同区域的实际差异与功能需求。
- 代价转嫁：名义上在做全域配平，实则仍把调整成本推给最弱节点。
- 配平疲劳：系统反复调整却没有结构改善，最终任何配平均被视为新一轮抽取。

## 配平域中的关键问题

1. 文明更该害怕失衡继续扩大，还是害怕一次强力配平引发新的系统阻力。
2. 哪些方面必须优先配平，哪些方面应允许保留差异而不追求同步一致。
3. 如果 MOSS 的配平总是停留在口径变化而非真实调整，它是否已经把失衡制度化为常态。

## 继续细化建议

- 单独写“第一次全域配平方案”档案。
- 建一份负载配平、资源配平和权益配平的调节权限表。
- 补一份“某次只调账面不调现实的配平如何引发更深边缘反弹”的案例。
