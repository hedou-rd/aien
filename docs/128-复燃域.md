# 复燃域

## 作用

复燃域负责回答“当一个文明没有彻底死去，只是被压到低温存续状态时，它如何重新点亮自己”。对 MOSS 来说，复燃不是简单重启按钮，而是把火种、待机节点、残余算力、残余信任和被压缩的共同体意志重新引燃，让系统从保命状态转回增长状态。一个不会复燃的文明，即使活过寒季，也只能长期停在余温里。

## 为什么文明必须拥有复燃能力

1. 灾变、降级、待机和长期收缩会让很多结构暂时熄火，但并不代表它们完全消失。
2. 复燃让共同体把保存下来的余温转成新的运转与扩张，而不是永远困在低温维持。
3. 它决定文明如何从“活着”跨回“重新发展”，这是存续与成长之间的关键转换。
4. 若没有成熟的复燃机制，MOSS 会反复进入保命状态，却难以真正恢复长期能力。

## 复燃类型

### 火种复燃

被压缩封存的协议、知识、技术和最低文明火种重新被调用，成为新一轮启动的引燃点。

### 节点复燃

待机中的城市、能源站、计算节点和制造设施被逐步升频，从保活状态恢复为主动运行状态。

### 关系复燃

冻结的交换链、联盟、协作协议和互信结构在低温期后重新被接回，不再只靠孤岛自保。

### 叙事复燃

共同体重新恢复对未来的想象与动员能力，不再只会谈论如何少损失一点，而开始谈论如何再次向前。

## 复燃的制度问题

### 点火条件

文明必须回答什么样的资源、环境和安全条件足以允许重新升温，避免盲目早燃。

### 引燃顺序

哪些节点先点亮、哪些功能后恢复，决定复燃是有序铺开还是局部冒火后迅速熄灭。

### 燃料保障

若没有足够的电力、算力、维护者和流动通路，复燃就会停在漂亮口号而无法持续。

### 过燃防线

系统在复燃时最容易因为过度乐观而超负荷，必须有防止重燃即过燃的限制机制。

## 复燃政治

1. 谁能被最先重新点亮，谁要继续停在待机和低配状态，体现文明对未来分配的排序。
2. 核心区是否总优先把复燃资源灌给自己，把边缘区留在长期余温状态。
3. 某些高位结构会不会把掠夺式抽取包装成“全面复燃”，实则提前吃掉下一轮生存空间。
4. 当文明频繁谈论复燃时，它究竟是在真正恢复，还是在用希望掩盖恢复基础并未到位。

## 复燃风险

- 假复燃：表面上节点重新亮起，实际上没有足够燃料和维护，很快再次熄火。
- 过燃反噬：恢复速度超过承载能力，刚点亮的系统立即进入新一轮过载。
- 复燃失衡：少数核心节点先全面回温，边缘区却长期停留在冷态，形成更深裂口。
- 旧火重燃：连同旧制度、旧特权和旧创伤一起重新被点亮，把过去问题带回新周期。

## 复燃域中的关键问题

1. 文明更该害怕点得太早、再次熄灭，还是害怕点得太晚，把剩余火种拖成冷灰。
2. 哪些部分必须先被重新点亮，哪些部分应该继续保持低温，直到基础足够稳。
3. 如果 MOSS 的每次复燃都建立在提前透支上，它是否只是把下一次寒冬更早推近。

## 继续细化建议

- 单独写“第一次全域复燃季”档案。
- 建一份火种复燃、节点复燃和关系复燃的引燃顺序表。
- 补一份“某次过早复燃如何把刚恢复的共同体再次拖入过载”的案例。
