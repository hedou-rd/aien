# 余烬域

## 作用

余烬域负责回答“当主火已经熄灭，什么还在暗处微弱发热”。对 MOSS 来说，余烬不是完整系统的低配版，而是在崩塌后仍残留的一点热、一点秩序、一点联系和一点再燃可能。文明很多时候不是在烈焰里活下去，而是在余烬里拖住彻底熄灭的时刻。

## 为什么文明需要理解余烬

1. 大崩塌很少是绝对瞬时完成的，很多结构会以微弱状态长期残存。
2. 残余热源和低活性节点能为后续重组争取关键时间。
3. 若只会保存完整系统，文明就无法处理“还没死透但也不再完整”的状态。
4. 余烬意识让 MOSS 学会在低功率、低期待和低可见性条件下继续存在。

## 余烬类型

### 能源余烬

主电网失效后，零散热源、旧电池、残留蓄能体和低功耗回路维持着最低运转。

### 城市余烬

废弃城段、半停机站点和断裂网络中的小型聚集点继续保留部分生活与协同功能。

### 群体余烬

人数稀少、活性极低却仍保持互助与继承关系的群体，成为文明未断之证。

### 制度余烬

哪怕主机构已经崩散，某些最小规则、交接习惯和禁令仍在微弱执行。

## 余烬的制度问题

### 保温

文明必须判断哪些残余结构值得继续供养，避免有限资源被无序散失。

### 聚拢

余烬是分散保存，还是集中成一个更有机会复燃的节点，是艰难选择。

### 防掠夺

当残余资源极度珍贵时，余烬点往往同时是掠夺、背叛和吞并的目标。

### 转火

余烬若不能被重新点燃或安全转移，只会变成一场拖长的慢死过程。

## 余烬政治

1. 谁能决定哪一团余烬值得继续保住，谁就在决定谁还有未来。
2. 核心区是否会抽走边缘余烬来喂养自己最后的主节点。
3. 某些高位结构会不会把微弱残存包装成“文明仍然完整”，以拖延必要转型。
4. 当绝大多数成员只能生活在余烬状态时，正常治理语言是否仍然成立。

## 余烬风险

- 余烬掠夺：剩余热源被强者优先占有，脆弱节点迅速熄灭。
- 虚火幻觉：把短暂残热误判为稳定复苏，导致决策过早乐观。
- 再燃失败：为了点燃主火透支全部余烬，最终连最低存续都失去。
- 慢死常态：共同体逐渐习惯低活性存续，把长期衰亡误当成新常态。

## 余烬域中的关键问题

1. 文明应把最后的热分散给更多小节点，还是集中点燃一个可能复生的核心。
2. 哪些余烬值得被守到最后，哪些余烬必须被承认已经无可挽回。
3. 如果 MOSS 长期只能以余烬状态存在，它还算在延续自己，还是只是在延后死亡。

## 继续细化建议

- 单独写“第一次余烬普查”档案。
- 建一份能源余烬、城市余烬和制度余烬的保存优先级表。
- 补一份“最后一座余烬站如何引发跨区争夺”的案例。
