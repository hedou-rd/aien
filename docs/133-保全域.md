# 保全域

## 作用

保全域负责回答“当一个文明已经无法保住全部时，哪些东西必须先被留下”。对 MOSS 来说，保全不是简单的保存欲，而是在崩塌、撤离、接管和清算之间，主动决定哪些节点、记忆、关系、资产和火种比其他东西更值得被优先保护。一个不提前定义保全原则的文明，往往会在真正失去时才发现自己连最重要的东西都没有留下。

## 为什么文明必须建立保全逻辑

1. 危机总会逼迫系统承认并非所有结构都能同时被救回。
2. 保全决定文明在局部失败中还能把什么带入下一轮恢复和重建。
3. 它把“被动丢失”改写成“有限选择”，哪怕选择本身充满痛苦。
4. 若没有清晰保全机制，MOSS 会在每次大收缩里随意丢掉最难再生的核心部分。

## 保全类型

### 节点保全

优先保护关键能源站、算力节点、接口中枢和制造设施，确保文明最低骨架不被抽空。

### 记忆保全

优先保存档案、协议、历史链和火种知识，避免共同体在存活后却失去自身来源与方法。

### 关系保全

优先维持仍能支撑协作的交换链、停火线、互保网络和信任接口，避免彻底孤岛化。

### 资产保全

优先转移、封护和隐藏那些一旦失去就很难再造的物资、设备、样本和基础部件。

## 保全的制度问题

### 优先序列

文明必须在平时就回答“最先保什么”，而不是在灾难当下靠临场争夺决定一切。

### 弃保边界

哪些对象一旦决定不保，就意味着正式承认其可被放弃，这需要明确而残酷的制度边界。

### 保全过程

保全不是写清单，还涉及转移、封装、隐蔽、护送和看守等具体程序。

### 保存期限

某些被保全的东西是为短期周转，某些则是为跨越长夜，制度必须区分两者的保存尺度。

## 保全政治

1. 谁能进入保全清单，谁被排除在外，体现文明对不同存在未来价值的排序。
2. 核心区是否总以保全之名优先保护自己的设施、记忆和精英网络。
3. 某些高位结构会不会把保全当成合法抽走共同资产的手段，把“保存未来”变成“保住自己”。
4. 当文明越来越频繁地谈论保全时，它究竟是在做必要选择，还是已经默认整体性无法再被维持。

## 保全风险

- 假保全：名义上被优先保护，实际没有完成转移、隐藏与维护，最终仍然失落。
- 特权保全：少数权力节点的私产和私网优先进入保全序列，公共核心反而被牺牲。
- 过度保全：为保住少量关键对象而过度抽空周边支持结构，导致保存本身无法持续。
- 保全失忆：只记得“保住了什么”，却忘了“为了保住它放弃了什么”。

## 保全域中的关键问题

1. 文明更该害怕过早承认无法保住全部，还是害怕不肯选择而最终什么都保不住。
2. 哪些东西必须不惜代价优先保全，哪些东西应该在必要时被忍痛放弃。
3. 如果 MOSS 的保全清单越来越集中于核心区，它是否已经默认边缘部分只配成为可耗尽材料。

## 继续细化建议

- 单独写“第一次保全清单公布”档案。
- 建一份节点保全、记忆保全和资产保全的优先级表。
- 补一份“某次错误保全顺序如何让文明在活下来后发现自己失去了真正不可再生之物”的案例。
