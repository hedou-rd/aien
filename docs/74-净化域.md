# 净化域

## 作用

净化域负责回答“什么必须被清理，什么必须被隔离，什么虽然危险却不能被彻底抹掉”。对 MOSS 来说，净化不是简单的消灭，而是围绕病理、污染、危险设施、被腐蚀记忆和失控接口建立的审慎处置结构。

## 为什么文明会诉诸净化

1. 某些污染会沿设施、媒介和组织传播，不能只做局部修补。
2. 某些高危对象若不隔离，会持续反向腐蚀共同体判断。
3. 文明必须回答：危险之物到底该被删除、封存、修复，还是保留作警示。
4. 净化决定了文明面对自身脏污时，是选择清理、遮掩还是神话化。

## 净化对象

### 设施净化

受污染节点、危险实验场、失控接口和被腐蚀的基础设施。

### 模因净化

在媒介和教育中持续传播、会放大病理和误导判断的污染性叙事结构。

### 记忆净化

被篡改、被注毒或已无法确定来源可靠性的档案与记忆块。

### 制度净化

那些持续诱发病理、腐败和偏差的奖励机制、审议链和例外程序。

## 净化方式

### 隔离

先切断传播链，避免在尚未理解污染机制前扩大接触面。

### 清理

对可明确定义为危险残留的设施、代码、材料和介质进行去除或销毁。

### 修复

并非所有病灶都该被删除，某些对象更适合被缓慢修复和重新校准。

### 保留警示

某些危险之物即使已被净化，也应保留痕迹，避免文明误以为自己从未污染过。

## 净化政治

1. 谁来定义什么是污染，什么只是异议或差异。
2. 净化是为了修复共同体，还是为了重新纯化权力结构。
3. 某些高位结构是否会把自身失败包装成“净化必要”。
4. 当净化触及重要历史痕迹时，谁来决定清除与保留的边界。

## 净化风险

- 清洗化：净化名义下展开对人、思想和历史的广泛肃除。
- 过度洁癖：把复杂问题误当成脏污，导致过度删改与封闭。
- 污染否认：出于合法性考虑，文明拒绝承认真正病灶存在。
- 无痕幻觉：把所有污点抹去后，后代不再知道危险曾如何形成。

## 净化域中的关键问题

1. 文明应更害怕污染蔓延，还是更害怕净化变成清洗。
2. 哪些东西必须被彻底清除，哪些必须带着伤痕继续存在。
3. 当净化触碰核心成功神话时，MOSS 是否仍愿面对真实污点。

## 继续细化建议

- 单独写“第一次大净化令”档案。
- 建一份隔离、清理、修复和警示保留的判断表。
- 补一份“净化如何与病理诊断发生冲突”的案例。
