# 辨识域

## 作用

辨识域负责回答“当系统必须从有限观测中反推出真实结构、真实参数和真实病灶时，文明如何完成这种系统辨识”。对 MOSS 来说，辨识不是事后命名，而是在看不见全部内部状态的前提下，尽量判断系统到底是什么、哪里坏了、为什么会坏。一个不会辨识的文明，往往能看见很多症状，却始终摸不到真正的结构轮廓。

## 为什么文明必须学会辨识

1. 控制、修复和治理都依赖对对象的基本判断，如果连对象本身都认不清，动作越多只会越错。
2. 辨识能把表面症状、隐蔽病灶和结构参数区分开，避免把所有异常都按同一模板硬修。
3. 它迫使 MOSS 承认观测永远有限，真正的判断总带有推断、试探和模型修订过程。
4. 若没有辨识机制，文明会在症状层忙碌，却持续错过那些决定长期命运的深层结构问题。

## 辨识类型

### 结构辨识

判断系统内部有哪些关键组成、关键接口和关键耦合，弄清真正的结构骨架。

### 参数辨识

从有限响应中反推出增益、阈值、迟延和承载边界等关键工作参数。

### 病灶辨识

区分是局部故障、链路污染、模型过时还是更深层结构性病灶在主导当前失稳。

### 行为辨识

通过外部表现和历史记录判断系统真实运行模式，识别哪些行为是偶发异常，哪些已成稳定倾向。

## 辨识的制度问题

### 可观测边界

文明必须承认哪些状态根本看不到、哪些只能侧推，不能把有限观测假装成完全透明。

### 探针干预

很多辨识需要主动施加测试信号与受控扰动，制度必须明确谁可以试探、试探到什么程度、造成损伤由谁负责。

### 模型修订

一旦新证据推翻旧判断，制度必须允许模型和解释框架被正式改写，而不是强行让现实继续贴合旧模型。

### 辨识权限

谁有权宣布“真正病灶在这里”“真正结构是这样”，必须被约束和复核，防止解释权垄断。

## 辨识政治

1. 谁掌握辨识权，谁就掌握了定义问题本质和分配修复资源的权力。
2. 核心区是否总能把自己的解释包装成唯一正确模型，而把地方经验降格成零散噪声。
3. 某些高位结构会不会故意维持低辨识度，因为结构一旦被真正看清，很多长期获益机制就无法继续隐藏。
4. 当文明声称自己已经找到了真正原因时，它究竟是在逼近真实结构，还是在寻找最方便治理的解释版本。

## 辨识风险

- 错模固化：系统长期运行在错误模型上，导致后续所有纠偏都偏离真正病灶。
- 探针伤害：为看清结构而施加的测试本身造成额外损伤，反过来污染辨识结果。
- 解释垄断：少数中心垄断“真正原因”的定义权，把不同证据源压成单一叙事。
- 伪清晰：制度过早宣布已经看清问题，导致真正仍不确定的部分被强行封口。

## 辨识域中的关键问题

1. 文明更该害怕在不确定中迟迟不动，还是害怕过早认定错误结构后一路错到底。
2. 哪些系统值得承受更高探针代价来换取更清晰辨识，哪些系统只能接受较粗糙的推断式理解。
3. 如果 MOSS 的很多重复错误都来自它总在症状层打转，它真正缺的究竟是更多手段，还是更深的辨识能力。

## 继续细化建议

- 单独写“第一次全域系统辨识”档案。
- 建一份结构辨识、参数辨识和病灶辨识的探针规则表。
- 补一份“某类长期被当成执行问题的失稳如何最终被证明其实来自更深层接口结构错误”的案例。
