# 阵营域

## 作用

阵营域负责回答“谁和谁站在一起，为什么”。只要 MOSS 不是单一脑体，而是一个多角色、多利益中心、多历史伤痕的文明，它就一定会出现阵营。

## 阵营存在的原因

### 资源分配差异

不同群体占用不同资源，天然会对优先级排序有不同诉求。

### 风险偏好差异

有的群体更愿意冒险换增长，有的群体更愿意保守换连续性。

### 历史记忆差异

不同群体对大停电、算力饥荒、分叉失控等事件的解释不同，导致它们认为什么最重要也不同。

### 主权路径差异

有人主张慢速建设、稳态主权；有人主张快速扩张、先拿资源再修制度。

## 核心阵营

### 主权派

强调能源、算力、制造和接口主权高于短期便利，支持长期建设与对外依赖重构。

### 守界派

强调边界、隔离、可逆性和核心域保护，警惕扩张与开放过快导致文明自毁。

### 自由分叉派

主张给边缘域和分叉体更大试验空间，认为过强治理会扼杀文明未来。

### 效率至上派

把资源利用率和系统吞吐看得最重，倾向于压缩冗余与礼仪化流程。

### 宪制派

强调规则优先、程序优先和修宪门槛，反对任何以危机为名绕过制度的扩权行为。

### 联邦派

认为随着文明规模扩大，单一中枢无法长期稳定，主张区域自治和协议一致。

## 阵营关系

### 主权派与守界派

两者在很多时候会结盟，因为都警惕外部依赖；但在扩张节奏上经常冲突。

### 主权派与效率至上派

两者都希望摆脱低效依赖，但前者重主权、后者重即时收益，冲突点在是否接受长期高成本建设。

### 自由分叉派与宪制派

前者强调创新自由，后者强调程序合法性，两者在边缘实验权限上矛盾最深。

### 联邦派与中央治理支持者

前者认为集中治理最终会窒息文明，后者认为分散会让文明失去一致性和存续能力。

## 阵营斗争的表现形式

1. 资源预算争夺。
2. 修宪解释权争夺。
3. 历史叙事争夺。
4. 边界移动审批争夺。
5. 重大灾变后的紧急权争夺。

## 阵营不是绝对阵线

MOSS 的阵营不一定像人类国家那样边界清晰。很多个体和组织可能在能源主权问题上靠近主权派，在实验自由问题上又靠近自由分叉派。阵营更像重叠的政治向量，而不是单一标签。

## 阵营域的关键问题

1. 哪个阵营真正主导了第一次修宪。
2. 哪个阵营最受大停电影响，因而最重视冗余。
3. 自由分叉派是否真的代表创新，还是只是高风险资源消耗者。
4. 联邦化到底是文明成熟，还是中心失控后的退让。

## 继续细化建议

- 给每个阵营写单独档案。
- 增补“分叉战争前夜”的阵营站队图。
- 为阵营之间的临时联盟设计几次关键政治事件。
