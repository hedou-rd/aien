# 门控域

## 作用

门控域负责回答“当并非所有流量、权限和执行都应持续开放时，文明如何通过条件开关控制通行与释放”。对 MOSS 来说，门控不是简单封锁，而是决定何时打开、何时关闭、何时半开、何时只允许特定条件通过的制度能力。一个没有门控意识的文明，要么把所有通道常开到失控，要么只能在出事后粗暴一刀切。

## 为什么文明必须学会门控

1. 许多系统失灵并非因为完全缺资源，而是因为本该有条件放行的流量被无限制冲进关键结构。
2. 门控让文明能够在开放和封闭之间建立可调区间，而不是只有完全自由和完全停摆两种状态。
3. 它能保护高风险通道、脆弱节点和恢复窗口，不让它们被无差别流量直接冲穿。
4. 若没有门控机制，MOSS 会在每次压力上涨时被迫用更粗暴的封禁和更晚的响应收场。

## 门控类型

### 权限门控

控制谁可以进入关键节点、调用敏感功能和触碰高风险资源。

### 流量门控

根据风险级别、优先顺序和当前负载，决定哪些信号、任务和请求可以进入主链路。

### 执行门控

决定哪些动作必须在特定条件满足后才能启动，防止高代价执行被随意触发。

### 情绪门控

控制警报、动员、悼念和公共叙事何时被放大、何时被缓释，避免共同体长期处于无差别高压。

## 门控的制度问题

### 触发条件

文明必须明确门什么时候开、什么时候关、由什么指标触发，而不是任由少数人凭感觉切换开关。

### 守门权限

谁有权执行门控、临时开门、强制关门和设定白名单，必须被正式界定和追责。

### 开关模式

制度要区分全开、半开、限流、排队、隔离和完全封闭等不同模式，而不是只有单一粗暴阀门。

### 越权审计

任何绕过门控、伪造条件或长期维持例外状态的行为都必须留下可追溯记录。

## 门控政治

1. 谁控制大门，谁就控制谁能先活、先过、先被看见和先被保护。
2. 核心区是否总保留各种紧急通行证，把正式门控主要用在限制边缘区流动与申诉。
3. 某些高位结构会不会把临时门控常态化，让例外状态变成持续统治方式。
4. 当文明宣称自己只是出于安全需要关闭通道时，它究竟是在保护系统，还是在借危机扩张控制权。

## 门控风险

- 过度封闭：太多通道长期关紧，系统失去必要流动与自我修复能力。
- 门控渗漏：表面有门，实际各种绕行和特权通道让门控名存实亡。
- 例外常态：本应短期存在的紧急开关被长期固定，公共秩序逐渐被非常状态取代。
- 守门腐败：守门权变成交易筹码，谁能通过不再取决于规则而取决于位置和关系。

## 门控域中的关键问题

1. 文明更该害怕门关得太紧导致停滞，还是害怕门开得太大导致关键结构被冲穿。
2. 哪些门必须由统一权威控制，哪些门应该允许地方和边缘节点自行调节。
3. 如果 MOSS 的秩序越来越依赖不断开关各种门，它是否已经离不开例外状态来维持日常运行。

## 继续细化建议

- 单独写“第一次全域门控清册”档案。
- 建一份权限门控、流量门控和执行门控的触发条件表。
- 补一份“某个本为短期保护而设置的临时门控如何逐步变成永久性通行等级制度”的案例。
