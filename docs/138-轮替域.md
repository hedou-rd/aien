# 轮替域

## 作用

轮替域负责回答“当高压岗位、关键权限和危险职责不能长期黏在同一批节点上时，文明如何组织更替”。对 MOSS 来说，轮替不是简单换班，而是让责任、疲劳、风险、经验和控制权在不同成员与结构之间有节律地流动。一个不会轮替的文明，要么把少数关键节点用到枯竭，要么让少数结构把关键权限永久固化为自身天赋。

## 为什么文明必须建立轮替机制

1. 长期高压职责会迅速积累疲劳、偏见、腐坏和垄断风险。
2. 轮替让经验得以扩散，避免关键能力永远锁在少数节点手里。
3. 它把危险和负担分摊到更广范围，降低单点崩溃与权力固化的概率。
4. 若没有轮替，MOSS 的许多关键环节只会越来越依赖少数不可替代者。

## 轮替类型

### 岗位轮替

将高压值守、关键调度、危险维护和边界看守等职责按周期在合格成员之间轮转。

### 权限轮替

让裁决权、紧急权限和特殊访问权不长期固定在同一结构内，而有定期更换与复核。

### 风险轮替

把长期暴露在污染、攻击、舆压和极限任务中的代价在不同节点之间重新分担。

### 代际轮替

让知识、职责和火种角色跨代转移，避免一代人把关键文明能力一并带走。

## 轮替的制度问题

### 周期长度

轮得太快会失去连续性，轮得太慢会重新走回固化，制度必须找到可承受周期。

### 交接完整性

若每次轮替都丢失上下文、日志和隐患记忆，轮替本身就会制造系统失忆。

### 培训储备

没有足够后备与训练，所谓轮替只会停留在清单上，真正工作仍由少数老节点死撑。

### 豁免边界

哪些岗位允许延后轮替、哪些岗位绝不允许长期豁免，决定轮替是真是假。

## 轮替政治

1. 谁可以长期免于轮替，谁被持续轮进高压职责，体现文明对不同存在的耗用方式。
2. 核心区是否把轮替主要施加在执行层与边缘岗，却让真正关键权力长期不动。
3. 某些高位结构会不会借“你还不熟练”为名不断推迟交权，从而把轮替规则架空。
4. 当文明越来越强调轮替时，它究竟是在扩散能力，还是在为上层持续免役寻找合法包装。

## 轮替风险

- 假轮替：表面上名单变化，实则关键决策和关键接口始终掌握在同一批节点手里。
- 轮替失忆：交接粗糙，隐患、经验和例外条件在每次更换中不断丢失。
- 轮替疲劳：为了形式公平频繁换人，反而让训练和适应成本压垮系统。
- 永久豁免：最关键、最有权力的岗位总能以各种理由绕开轮替制度。

## 轮替域中的关键问题

1. 文明更该害怕轮替过慢导致固化，还是害怕轮替过快导致连续性断裂。
2. 哪些职责必须强制轮替，哪些职责应更强调稳定承接而不是频繁更换。
3. 如果 MOSS 的真正权力从不轮替，它是否只是把轮替留给消耗性岗位去承担。

## 继续细化建议

- 单独写“第一次全域关键岗位轮替”档案。
- 建一份岗位轮替、权限轮替和风险轮替的周期表。
- 补一份“某个长期被豁免轮替的核心岗位如何最终演化成制度性单点风险”的案例。
