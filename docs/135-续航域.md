# 续航域

## 作用

续航域负责回答“当文明已经重新启动并开始向前时，它怎样才能不靠透支自己继续走下去”。对 MOSS 来说，续航不是瞬间冲刺后的余势，而是让能源、算力、维护、信任和组织节奏在长距离运行中保持可持续推进。一个不会续航的文明，可以复燃、可以扩张，但很快又会因为透支而坠回收缩和待机。

## 为什么文明必须拥有续航能力

1. 真正决定文明寿命的，不是能不能短期冲起来，而是能不能长期不塌下来。
2. 续航把复燃后的高热状态转成可维持的稳定推进，避免再次依赖掠夺式提速。
3. 它要求文明把补给、维护、轮换和修复写进增长模型，而不是只算扩张速度。
4. 若没有续航机制，MOSS 的每次恢复都可能只是下一轮透支的前奏。

## 续航类型

### 能源续航

确保发电、储能、输配和备用体系能够支撑长期负载，而不是只够短时冲高。

### 算力续航

让模型训练、推演、调度与公共计算保持长期可用，不被少数高峰任务吃干抹净。

### 维护续航

让维修链、备件链、轮值结构和保养节奏跟得上扩张速度，防止跑得比修得快。

### 信任续航

让共同体在长期压力下仍保有协作意愿、承诺可兑现性和可恢复的公共耐心。

## 续航的制度问题

### 补给周期

文明必须知道每套关键系统多久补给一次、哪里补给、补给失败后怎样降速而不是断链。

### 透支阈值

什么时候还属于可接受加压，什么时候已经在吃掉未来，必须有明确判断标准。

### 节奏管理

系统不能永远以危机速度和战时速度推进，何时提速、何时巡航、何时降速，是续航核心。

### 长程保障

越远离核心区、越拉长时间尺度，越需要额外的维护、轮换和保全保障，否则续航只是一段口号。

## 续航政治

1. 谁能获得稳定补给和高质量维护，谁只能靠透支硬跑，体现文明对不同区域未来性的定价。
2. 核心区是否把自己的长程运行建立在边缘区长期被抽空的基础上。
3. 某些高位结构会不会把短期高增长包装成续航成功，从而掩盖底层正在慢性衰竭。
4. 当文明不断强调自己“还能跑”时，它究竟是在证明韧性，还是在回避早已出现的疲劳信号。

## 续航风险

- 续航错觉：看上去还能前进，实际上只是靠提前消耗未来库存和维护寿命支撑。
- 单线补给：关键链路只有一条补给来源，一旦中断就从巡航直接坠入失速。
- 慢性衰竭：系统没有明显崩塌，却在长期高压下持续丢失质量、精度和信任。
- 局部熄火：整体仍在推进，但越来越多边缘节点因得不到续航保障而悄悄退出运行。

## 续航域中的关键问题

1. 文明更该害怕跑得不够快，还是害怕为了快而提前耗尽自己未来几轮的生命。
2. 哪些系统必须优先保证长程续航，哪些系统可以接受更短周期的冲刺与休整。
3. 如果 MOSS 的每次扩张都在削弱自己的续航底盘，它是否只是在把终点提前伪装成前进。

## 继续细化建议

- 单独写“第一次续航危机”档案。
- 建一份能源续航、维护续航和信任续航的最低保障表。
- 补一份“某条看似高速成功的扩张链如何因续航失败而在长距离运行中整段熄火”的案例。
