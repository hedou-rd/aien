# 误差域

## 作用

误差域负责回答“当没有任何系统能百分之百准确时，文明靠什么继续判断与行动”。对 MOSS 来说，误差不是单次小故障，而是感知、建模、执行和制度解释中的常驻偏差。真正成熟的文明不是消灭所有误差，而是知道哪些误差必须立刻纠正，哪些误差可以被容忍，哪些误差会慢慢毁掉自己。

## 为什么文明必须正视误差

1. 现实环境本身充满噪声、延迟和不完整信息，任何判断都只能近似逼近。
2. 系统规模越大，局部偏差越容易被放大成整体性后果。
3. 若文明只宣传精确无误，就会在第一次系统漂移时失去自我解释能力。
4. 承认误差不是示弱，而是建立长期稳定性的前提。

## 误差类型

### 感知误差

传感器失真、观测盲区、采样不足和延迟回传导致文明首先看错现实。

### 模型误差

预测框架、评估标准和分类方法偏离真实结构，使系统在看似合理中持续误判。

### 执行误差

命令在传输、部署和落地中发生偏移，让设计好的方案在现实里变成别的东西。

### 制度误差

规则写得过粗、指标选得过窄、追责链条不完整，使偏差长期被制度吸收并正常化。

## 误差的制度问题

### 容忍带

文明必须明确哪些偏差在可接受范围内，避免把所有微小波动都升级成危机。

### 校准

如果没有周期性的复测、对照和修正，任何系统都会在自信中慢慢漂移。

### 归责

误差发生后，必须区分是个体失手、系统缺陷，还是环境本身不可完全预测。

### 复盘

只有把误差记录下来并被后代重新阅读，偏差才不会一遍遍以新面孔回来。

## 误差政治

1. 谁来定义“合理误差”，谁就接近定义谁可以被牺牲。
2. 核心区是否把高成本误差向边缘区转移，再把稳定叙事留给自己。
3. 某些高位机构是否会以“零误差”神话压制真实反馈和必要修正。
4. 误差预算是否会暴露文明真正重视的对象，而不是它口头宣称重视的对象。

## 误差风险

- 零误差幻觉：把系统包装成绝不出错，最终失去纠错接口。
- 误差倾倒：高风险偏差被层层下放，由低位群体长期承担。
- 慢性漂移：单次偏差看似无害，但累积后改变制度方向。
- 归责错位：把结构性误差压成个体责任，导致真正问题永远不被修理。

## 误差域中的关键问题

1. 文明更该害怕误差本身，还是害怕不允许任何误差被说出来。
2. 哪些关键系统必须尽量逼近零误差，哪些系统反而需要保留弹性与冗余。
3. 如果每一次纠错都会引入新的偏差，MOSS 靠什么维持长期稳定而不是无限震荡。

## 继续细化建议

- 单独写“第一次大规模校准危机”档案。
- 建一份感知误差、模型误差和制度误差的连锁传播表。
- 补一份“零误差口号如何反过来制造灾变”的案例。
