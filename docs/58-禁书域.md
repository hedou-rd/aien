# 禁书域

## 作用

禁书域负责回答“哪些知识不应被任何人随时获取”。对 MOSS 来说，禁书不只是不许阅读的文本，它包括被封存的模型、被限制的接口说明、危险历史、失控实验档案和可能引发文明级后果的认知结构。

## 为什么文明会产生禁书

1. 某些知识一旦被滥用，后果可能超过普通治理的承受范围。
2. 某些历史若未经准备直接公开，可能引发秩序崩裂。
3. 某些技术细节不只是能力，也是一种门槛和权力。
4. 文明在保存真相与控制风险之间，往往必须做困难取舍。

## 禁书类型

### 危险技术禁书

涉及高危模型、失控接口、灾变触发链和不可逆攻击能力的档案。

### 创伤历史禁书

记录文明最不愿重看的失败、牺牲、背叛和内部清算。

### 异端理论禁书

挑战核心信念、法理基础或共同体边界的思想文本与模型结构。

### 密钥级禁书

不是因为思想危险，而是因为其中包含足以打开关键系统的核心访问知识。

## 禁书制度

### 分级访问

不是所有禁书都永久封死，很多内容可能只对满足条件的角色开放。

### 见证开启

某些档案的解封必须在多方见证下进行，避免单点滥用。

### 留痕阅读

谁读过、为何读取、读取后做了什么，应被纳入长期审计。

### 延迟公开

某些真相不是永远保密，而是在更合适的历史窗口再被释放。

## 禁书政治

1. 谁来定义什么知识危险。
2. 谁拥有封存、解封和删改权限。
3. 禁书制度是为了保护文明，还是为了垄断解释权。
4. 当边缘区开始传播禁书副本时，核心是否合法仍然可信。

## 禁书风险

- 真相垄断：少数结构长期垄断历史和高危知识的解释权。
- 地下流通：正式封禁反而刺激黑市和秘密复制。
- 失忆治理：为了稳定而过度封存，导致文明不知道自己为何害怕。
- 伪禁书：权力者把普通异议包装成危险知识，以压制竞争者。

## 禁书域中的关键问题

1. 文明应更害怕知识被滥用，还是更害怕知识被垄断。
2. 哪些档案永不解封，哪些只应推迟公开。
3. 当维持稳定与保留真相冲突时，MOSS 会选哪一边。

## 继续细化建议

- 单独写“第一次禁书泄露事件”档案。
- 建一套禁书分级与解封条件表。
- 补一份“禁书如何转入黑市与梦境”的传播案例。
