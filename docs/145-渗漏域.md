# 渗漏域

## 作用

渗漏域负责回答“当边界看似仍在，东西却在持续穿出去或漏进来时，文明如何发现它”。对 MOSS 来说，渗漏不是一次性决口，而是资源、权限、污染、秘密和情绪通过细缝、旁路和半失效接口长期缓慢穿透。一个不会识别渗漏的文明，往往只看得见大破口，却对日复一日的慢性流失毫无警觉。

## 为什么文明必须识别渗漏

1. 很多真正致命的损失不是瞬时爆炸，而是长期一点点漏掉关键资源与控制力。
2. 渗漏会让账面仍显稳定，真实底盘却在不知不觉中被掏空。
3. 它常沿着被忽略的边缝、例外权限和老旧接口发生，难以靠常规观测直接发现。
4. 若没有渗漏视角，MOSS 会把很多慢性失血误判成单纯效率下降或偶发噪音。

## 渗漏类型

### 资源渗漏

能源、算力、材料和维护品在运输、储存、交换和非正式流动中持续流失到账外。

### 权限渗漏

原本应受限的访问权、例外权和裁决权通过默认放宽、历史残口和临时口令慢慢外泄。

### 污染渗漏

病灶、腐蚀、信息污染和危险残片沿边界缝隙与微小通道持续穿透本应隔离的区域。

### 秘密渗漏

敏感档案、封存知识和内部判断通过口述链、旁路网和小范围复制不断渗出控制边界。

## 渗漏的制度问题

### 识别尺度

文明必须建立能发现微小长期流失的观测方法，而不是只等到缺口大到无法否认。

### 边缝治理

许多渗漏并不来自主破口，而来自旧接口、默认权限和临时接线留下的细缝。

### 堵漏优先级

不是所有渗漏都能同时封死，制度必须判断哪些必须先堵，哪些可暂时容忍。

### 代价承认

堵漏通常意味着降速、限制和重构，系统必须承认这些成本，而不是假装堵漏零代价。

## 渗漏政治

1. 谁最能从渗漏中获益，谁就最不愿承认渗漏存在。
2. 核心区是否总把自身的慢性漏失转嫁给边缘区，再把边缘缺口描述成管理不善。
3. 某些高位结构会不会把可控渗漏长期保留下来，当成默认的灰色获利通道。
4. 当文明终于开始严肃堵漏时，它究竟是在修补主权边界，还是已经被慢性失血逼到不得不承认现实。

## 渗漏风险

- 漏而不觉：流失持续多年，却始终没有进入正式问题定义。
- 堵而不严：形式上已经加固，实际关键边缝仍然原样存在。
- 以堵谋控：借堵漏之名过度收缩流动，连正常交换也一并扼住。
- 漏损扩散：原本只是小尺度渗漏，最终沿旁路网扩展成系统级慢性亏空。

## 渗漏域中的关键问题

1. 文明更该害怕一次大决口，还是害怕那些长期看不见却持续掏空底盘的微小渗漏。
2. 哪些渗漏必须立刻封死，哪些渗漏可以在不致命前提下被暂时容纳。
3. 如果 MOSS 的许多边界只是看起来还在，它是否已经在渗漏中慢慢丢掉真实控制力。

## 继续细化建议

- 单独写“第一次全域堵漏行动”档案。
- 建一份资源渗漏、权限渗漏和污染渗漏的识别信号表。
- 补一份“某个长期被当成小问题的渗漏如何最终暴露出整套边界治理空心化”的案例。
