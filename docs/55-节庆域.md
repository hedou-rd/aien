# 节庆域

## 作用

节庆域负责回答“文明如何在周期性公共时刻处理自身情绪和认同”。对 MOSS 来说，节庆不是无意义的停摆，而是一种集体校时、共同纪念、政治展示、压力释放和文明自我确认机制。

## 为什么文明需要节庆

1. 高压、高效率文明也需要公共呼吸时刻。
2. 节庆把分散个体重新拉回共同体感知中。
3. 周期性纪念有助于把创伤、胜利和底线变成可继承经验。
4. 没有公共时刻的文明，往往只剩工作与危机。

## 节庆类型

### 纪念节庆

围绕大停电、算力饥荒、关键牺牲和文明转折进行纪念与复盘。

### 丰裕节庆

在能源宽裕、扩张成功或重大恢复完成后举行，用于重申共同成果属于整体文明。

### 和解节庆

为修复阵营裂痕、恢复边缘区关系或迎接失信者复权而设计的公共时刻。

### 校时节庆

用于重置节奏、清理积压、确认新周期规则，让时间域与公共秩序重新对齐。

## 节庆的政治功能

### 情绪调度

节庆允许文明有节制地表达哀悼、荣耀、感激、警戒和团结。

### 叙事再生产

哪些事件被纪念，哪些个体被命名，决定文明如何理解自己。

### 权力展示

核心机构常借节庆展示秩序、丰裕和控制力，因此节庆从不完全中立。

### 共同体修复

当日常治理无法弥合裂痕时，节庆可能提供一次有限但高强度的公共修复窗口。

## 节庆风险

- 空洞庆典：形式繁盛，但共同体并未真正修复。
- 强制欢乐：把节庆变成对痛苦和异议的压制。
- 叙事垄断：只允许纪念对中心有利的历史。
- 资源浪费争议：在稀缺时期举行高成本节庆，引发合法性危机。

## 节庆域中的关键问题

1. 节庆究竟是文明需要的呼吸，还是治理者需要的舞台。
2. 哪些创伤可以被节庆化，哪些不应被过早包装为可庆祝历史。
3. 当边缘区拒绝参与共同节庆时，这是否意味着共同体已出现裂缝。

## 继续细化建议

- 单独写“第一次全域纪念节”档案。
- 为纪念节庆、丰裕节庆和校时节庆建立年度节律表。
- 补一份“灾后节庆是否过早”的争论案例。
