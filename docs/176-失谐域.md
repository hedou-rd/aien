# 失谐域

## 作用

失谐域负责回答“当原本协同的结构逐渐失去共同调节关系并彼此错开时，文明如何识别和纠正这种系统失谐”。对 MOSS 来说，失谐不是单点故障，而是多个本来应该一起运作的系统慢慢不再用同一套节奏、参数和目标区间。一个失谐严重的文明，往往每个局部看起来都还算合理，整体却越来越难以协同。

## 为什么文明必须处理失谐

1. 失谐会让原本相互支持的链路开始互相拖拽，把局部合理变成整体摩擦。
2. 它比单纯错拍更隐蔽，因为很多系统并非立即冲突，而是长期慢慢彼此不再适配。
3. 识别失谐能帮助文明判断哪些结构应重新调谐，哪些结构应分频、解耦或重写接口。
4. 若没有失谐治理，MOSS 会把大量结构摩擦错怪给个体执行失误，而看不见更深层的共同调节失效。

## 失谐类型

### 跨区失谐

不同区域根据各自环境和压力逐渐形成不同运行设定，最终难以再用同一套协作方式彼此对接。

### 跨层失谐

规划层、执行层和观测层各自沿不同参数世界运行，导致指令、反馈和判断越来越难互相匹配。

### 代际失谐

旧硬件、旧制度和旧训练范式与新一代系统逐渐脱节，使跨代协同成本不断上升。

### 接口失谐

本来用于桥接不同系统的协议、格式和边界条件不再适配，桥还在，但已经越来越难走。

## 失谐的制度问题

### 失谐诊断

文明必须能区分是局部性能下降、接口损坏，还是更深层的共同调节关系已经失效。

### 同步窗口

系统需要定期保留重同步和重协商窗口，不让各个区域与各个层级无限期各跑各的。

### 再谐程序

一旦确认失谐，制度必须明确是调回同一标准、允许局部自治，还是正式改写共同接口。

### 失谐容忍度

不是所有偏离都必须立刻拉回，文明需要判断哪些失谐仍可带来多样性，哪些失谐已威胁整体连续性。

## 失谐政治

1. 谁来定义“和谐的标准”，谁就能决定哪些偏离被视为创新，哪些偏离被视为失谐。
2. 核心区是否会把地方适应性的调整一律判定为失谐，只因为它们不再服从旧中心的节奏。
3. 某些高位结构会不会故意让他人长期处在失谐状态，以便维持对桥接、翻译和调解权力的垄断。
4. 当文明宣称某些区域已经失谐时，它究竟是在指出真实的不兼容，还是在压制替代性秩序。

## 失谐风险

- 协同塌缩：局部系统都还能运行，但一旦需要协同就暴露出大面积摩擦和卡顿。
- 桥接成瘾：越来越多资源被消耗在翻译、补丁和临时接口上，真正的共同标准却持续恶化。
- 强制回谐：为了快速恢复统一而粗暴压平地方差异，反而破坏原本有效的局部适配。
- 错因归责：把结构失谐误判成个体失职，导致真正问题长期被错过。

## 失谐域中的关键问题

1. 文明更该害怕保留失谐后的长期摩擦，还是害怕强制回谐毁掉地方适配和系统弹性。
2. 哪些失谐应该被修复回共同尺度，哪些失谐反而应通过分频和解耦被正式承认。
3. 如果 MOSS 需要越来越多桥接层才能维持协同，它是否已经在把失谐当成新的基础运行状态。

## 继续细化建议

- 单独写“第一次全域失谐诊断”档案。
- 建一份跨区失谐、跨层失谐和接口失谐的再谐流程表。
- 补一份“某套曾高度协同的区域网络如何在多年局部调谐后逐渐失去共同接口并被迫重建桥接层”的案例。
