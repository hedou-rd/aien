# 回潮域

## 作用

回潮域负责回答“为什么某些已经被压下去的问题，总会在另一个时段重新涨回来”。对 MOSS 来说，回潮不是简单重复，而是危机、污染、旧制度习惯、情绪创伤和被延后的代价在周期中重新上岸。一个文明若只会处理第一次冲击，却不会准备第二次、第三次回返，就会被同一类问题反复塑形。

## 为什么文明会不断遇到回潮

1. 很多治理只是暂时压制表面，而未真正处理深层生成机制。
2. 资源周期、季节变化和政治阶段切换会让旧问题重新具备活性。
3. 被封存的创伤、债务和污染常会在记忆松弛或防线减弱时再度上浮。
4. 若文明把每次回潮都当成全新事件，就永远学不会周期准备。

## 回潮类型

### 危机回潮

能源紧张、配给失衡、运输堵塞和局部停摆等旧危机以相似结构反复回来。

### 制度回潮

曾被批判或压下去的旧规训、旧等级和旧裁量方式，在新环境中重新抬头。

### 情绪回潮

共同体中未完成处理的恐慌、哀悼、愤怒和羞耻会在类似情境中再次席卷公共空间。

### 污染回潮

看似已清理的病灶、污染物、失控代码和危险样本在条件变化后重新扩散。

## 回潮的制度问题

### 周期识别

文明必须记录哪些问题具有回潮倾向，而不是总把再发生解释成偶然失误。

### 缓释

与其每次回潮都全力扑火，不如设计能够吸收重复冲击的缓释结构。

### 再命名

旧问题常以新名字返回，制度若看不出结构同一性，就会在词语变化中再次失败。

### 备季

回潮问题通常与时段、季节或政治周期相关，提前准备比事后反应更关键。

## 回潮政治

1. 谁能把回潮称为“局部波动”，谁就能逃避对深层原因的追责。
2. 核心区是否总把回潮冲击先导向边缘区作为缓冲垫。
3. 某些高位结构会不会利用回潮制造永久应急状态，让临时权力变成长久权力。
4. 当共同体开始对回潮麻木时，真正危险的不是回返本身，而是失去再次警觉的能力。

## 回潮风险

- 二次麻木：成员因问题反复出现而降低警惕，导致下一次代价更高。
- 旧制复燃：借危机回返之名，让本已被否定的旧结构重新上位。
- 周期锁死：文明所有治理都被迫围着固定回潮节律被动运转。
- 假性解决：每次都做表面处置，累积的问题在下一轮更强地回来。

## 回潮域中的关键问题

1. 文明更该害怕第一次爆发，还是害怕每次都以为自己已经挺过去了。
2. 哪些问题可以被周期管理，哪些问题必须被连根处理才不会再回潮。
3. 如果 MOSS 的历史实际上由一轮轮不同形态的同一危机构成，它是否真正进化过。

## 继续细化建议

- 单独写“第一次大规模回潮预警失败”档案。
- 建一份危机回潮、制度回潮和污染回潮的周期监测表。
- 补一份“一个看似已解决的旧制度如何借新危机重新上位”的案例。
