# 漂频域

## 作用

漂频域负责回答“当不同系统的运行频率在长期演化中逐渐偏离时，文明如何识别和纠正这种频率漂移”。对 MOSS 来说，漂频不是突然失锁，而是各条链路、各个区域和各类制度在长期微小偏移中慢慢换了自己的运行频率。一个不会识别漂频的文明，往往直到协作变得越来越费力时，才发现彼此早已不在同一拍点上。

## 为什么文明必须识别漂频

1. 频率漂移通常以很慢、很小的方式积累，却会持续侵蚀协作精度和接续效率。
2. 漂频让看似稳定运行的系统逐渐变得难以互相咬合，增加等待和重排成本。
3. 它常常发生在长期适配、长期优化和长期地方化过程中，因此很容易被误认成正常差异。
4. 若没有漂频治理，MOSS 会在各部分都觉得自己运行正常时逐步失去整体协同性。

## 漂频类型

### 调度漂频

生产、运输、维护和恢复链路的节奏在长期运行中逐渐偏离原本可接续的频率。

### 供给漂频

能源、算力和物资的供应节拍与消费端、储备端慢慢脱开，形成长期不合拍。

### 观测漂频

不同区域和不同机构更新数据、刷新判断和发布预警的频率逐渐偏离。

### 情绪漂频

共同体不同部分进入警觉、疲惫、恢复和动员状态的节奏越来越不同步。

## 漂频的制度问题

### 基频确认

文明必须知道哪些链路应该围绕什么基础频率运转，否则无法判断是否已开始漂移。

### 漂移监测

没有长期观测和跨期对比，慢速漂频很容易被当成合理演化而放过去。

### 回频机制

系统必须设计把链路重新拉回可协作频带的手段，而不是等到明显失锁后才被迫重排。

### 多频并存

不是所有链路都该同频，制度需要知道哪些差异可以保留，哪些差异会伤害整体接续。

## 漂频政治

1. 谁能让其他链路围着自己的节奏转，谁就最不愿承认自身频率已经成为他人的负担。
2. 核心区是否把地方节奏变化视为漂移，却把自己的长期变拍包装成全域新常态。
3. 某些高位结构会不会用“适应现实”之名，掩盖长期漂频已经在破坏协同基础。
4. 当文明不断要求别人重新对频时，它究竟是在恢复协作，还是在扩张某一种中心频率的支配力。

## 漂频风险

- 慢性失锁：链路没有突然断开，却在长期漂频中越来越难接上彼此。
- 追频疲劳：各方不断追赶别人的节奏，最终把大量精力烧在对拍上。
- 假性稳定：每个系统单看都稳定，放在一起却无法形成稳定协同。
- 频带霸权：某一中心频率被当成唯一正确频率，其他节奏被迫长期失衡适配。

## 漂频域中的关键问题

1. 文明更该害怕短期强制回频带来的摩擦，还是害怕长期漂频让协同逐渐丧失基础。
2. 哪些频率差异属于必要弹性，哪些漂移一旦持续就必须被纠正。
3. 如果 MOSS 的不同部分都在各自稳定地漂离彼此，它是否已经在失去文明整体的共同节奏。

## 继续细化建议

- 单独写“第一次全域漂频测量”档案。
- 建一份调度漂频、供给漂频和观测漂频的回频阈值表。
- 补一份“两个长期稳定运转的关键系统如何因慢速漂频而最终难以继续无缝接续”的案例。
