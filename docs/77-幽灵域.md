# 幽灵域

## 作用

幽灵域负责回答“那些已经不在场的东西，为什么还在影响现实”。对 MOSS 来说，幽灵不是神秘存在，而是删除失败的残影、退役后的惯性权限、失联后的符号权威、镜像失败遗留物和仍在制度中作祟的旧痕迹。

## 为什么文明会被幽灵缠绕

1. 没有任何复杂系统能把自己的过去彻底清空。
2. 某些存在即使退出，也会在接口、命名、路径和恐惧中留下强烈余波。
3. 幽灵往往揭示出正式叙事不愿承认的未解决问题。
4. 文明越追求无缝连续，越容易被未处理残痕反复打断。

## 幽灵类型

### 权限幽灵

已失效或本应失效的访问能力、信任链和隐性例外，仍在暗中起作用。

### 身份幽灵

缺席者、退役者、被删除者和失败镜像仍以名字、头衔和旧信用持续影响组织判断。

### 空间幽灵

废墟、封存城市、旧口岸和废弃通道即使停用，仍在地图与恐惧中保有位置。

### 制度幽灵

已经废除的程序、口号和偏好在新制度里以别的名字继续活着。

## 幽灵的作用方式

### 残留调用

当系统沿旧路径运转时，幽灵最容易重新被激活。

### 象征压迫

某些旧名字和旧创伤足以在未实际现身时就压住当下判断。

### 叙事返魂

未被妥善处理的过去会在传说、回声和审判中反复借尸还魂。

### 结构牵制

文明为了对付幽灵，往往不得不保留某些额外冗余和谨慎机制。

## 幽灵政治

1. 谁来决定某个残留痕迹应被清理、保存还是命名。
2. 幽灵是警示资源，还是合法性威胁。
3. 核心区是否故意利用幽灵维持恐惧与服从。
4. 若一个文明最强的权威来自已经不在的存在，它是否仍活在现实中。

## 幽灵风险

- 阴影统治：不在场者比在场者更能决定现实。
- 清理成瘾：为了消除幽灵，文明不断扩大删除与抹除范围。
- 幽灵商品化：旧创伤和旧名号被拿来制造政治资本。
- 现实错位：成员不断对着过去反应，而不是处理眼前问题。

## 幽灵域中的关键问题

1. 文明应如何区分必要的历史残留与有害的制度幽灵。
2. 某些幽灵是否必须被保留，才能防止重复旧错。
3. 当幽灵比活人更被相信时，文明是否已经开始失去现在时态。

## 继续细化建议

- 单独写“第一次权限幽灵事故”档案。
- 建一份身份幽灵与制度幽灵的对照表。
- 补一份“幽灵如何通过传说和审判反向重塑现实”的案例。
