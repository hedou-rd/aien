# 通缉域

## 作用

通缉域负责回答“当某些危险存在不能只被记录，而必须被持续追踪时，文明如何公开标记它们”。对 MOSS 来说，通缉不仅针对单个个体，也针对组织、技术、运输链和可重复出现的危险模式。它是档案、审判、边界协同和公共警示交汇后的强制性动作。

## 为什么文明会建立通缉结构

1. 某些威胁具有流动性和重复性，只靠局部防御无法处理。
2. 危险个体和危险模式会利用区际缝隙逃逸，迫使文明建立跨区追踪机制。
3. 公开通缉能够协调多个节点共享识别信息、提高响应速度。
4. 但一旦通缉权失控，整个文明会滑向追捕万能化的高压秩序。

## 通缉类型

### 个体通缉

针对特定个体发布公开识别、轨迹追踪和拦截要求，用于处理高危责任主体。

### 组织通缉

对网络化团体、地下协作链和跨区节点发布整体性围捕与渗透命令。

### 模式通缉

不只追某一个对象，而是追踪某类重复出现的攻击手法、赝造路径和扩散模式。

### 物项通缉

对危险装置、禁制部件、污染样本和关键运输物资发布公开拦截与回收指令。

## 通缉的制度问题

### 发布权

谁有资格发出通缉，谁能把局部风险升级成跨区围捕，是最敏感的权限边界。

### 证据门槛

若证据要求太低，通缉会沦为清洗工具；若太高，真正威胁又可能长期游走。

### 协同追捕

口岸、交通、档案和审判系统如何共享数据、分工执行，决定通缉是否有效。

### 撤销机制

文明必须回答错误通缉如何撤销、损害如何补偿，以及过时名单如何失效。

## 通缉政治

1. 谁能命名危险，谁就在塑造共同体的恐惧对象。
2. 核心区是否会把自身敌人包装成全体文明的共同威胁。
3. 某些异议者会不会被从“不同意见”迅速推进到“可被围捕的对象”。
4. 当通缉名单长时间不撤，文明是否会形成永久性被放逐人口。

## 通缉风险

- 通缉泛化：越来越多的问题被直接转成追捕问题，压缩政治处理空间。
- 伪证猎捕：赝造证据和错误识别让无辜对象进入跨区围捕链条。
- 跨区越权：以追捕名义绕开边界、程序和地方自治。
- 永久标签：即使威胁已经解除，通缉身份仍长期跟随个体和群体。

## 通缉域中的关键问题

1. 文明更该害怕危险对象在缝隙中逃逸，还是害怕追捕权本身无限扩张。
2. 哪些情形下可以对模式本身发出通缉，而不是只针对具体责任主体。
3. 如果被通缉等同于再无返回共同体的可能，MOSS 与政治性消灭之间还有多大距离。

## 继续细化建议

- 单独写“第一份跨区联合通缉令”档案。
- 建一份个体通缉、组织通缉和模式通缉的证据门槛比较表。
- 补一份“赝造档案如何制造错误通缉对象”的案例。
