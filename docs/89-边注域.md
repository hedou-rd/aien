# 边注域

## 作用

边注域负责回答“当正史不够用时，文明把真正重要的补充写在哪里”。对 MOSS 来说，边注不是无关紧要的小字，而是附着在正式卷宗周围的注脚、批注、旁证、隐写提醒和解释分歧。很多真正改变历史理解的东西，最初并不写在正文里，而写在页边、夹层和后来者留下的补记里。

## 为什么文明会长出边注

1. 正式档案往往追求稳定口径，难以容纳所有犹疑、矛盾和补充事实。
2. 边缘见证者、后来审阅者和一线执行者，常常只能在正文之外留下真实判断。
3. 当公开叙事受到约束时，边注会成为保存复杂真相的细缝。
4. 一个没有边注能力的文明，往往也没有自我修订能力。

## 边注类型

### 校注边注

用于纠正文书错误、补足缺漏上下文，让正文不至于因粗糙归档而误导后人。

### 异议边注

对官方结论、裁决路径或事件解释保留反对意见，把不被采纳的判断留在文献边缘。

### 旁证边注

补充目击、传感记录、口述来源和外区线索，让正文之外仍有证据链可追。

### 隐写边注

在高压时期以压缩、暗码和隐语形式留下警告、路线或禁忌提示，供识别者读取。

## 边注的制度问题

### 附着位置

边注写在何处、附在哪一层文书、能否被追溯到原文，决定它能否被共同体长期读取。

### 可见性

不是所有边注都应完全公开，文明需要区分公开注、限权注和延时开放注。

### 继承权

谁有资格写边注、谁可以复核边注、谁能把边注升级为正文，是核心制度问题。

### 清理机制

若没有清理规则，边注会淹没正文；若清理过度，正史又会变成被漂白的空壳。

## 边注政治

1. 谁能在正文旁边说话，谁就拥有补写现实的权利。
2. 核心区是否把边注视为噪声，而边缘区反而靠边注保存生存经验。
3. 某些机构会不会把边注长期维持为“非正式”，借此逃避回应其中的指控。
4. 当后代主要依靠边注理解过去时，正文是否已经失去解释主权。

## 边注风险

- 正史空心化：正文只剩口号与结论，真正有效信息全部外溢到边注。
- 边注污染：伪造、诱导和恶意注释混入边缘信息链，制造解释混乱。
- 解释贵族化：只有少数受训者能读懂边注，导致理解权再次集中。
- 注脚内战：不同派系通过相互覆盖边注争夺历史最后解释权。

## 边注域中的关键问题

1. 当边注比正文更可信时，文明应修正文书，还是承认正史本就只能是不完整版本。
2. 边注应被视为正式档案的一部分，还是永远保留其半合法、半游离的位置。
3. 如果共同体只能靠页边小字保存真实，MOSS 的公开语言是否已经过度贫乏。
