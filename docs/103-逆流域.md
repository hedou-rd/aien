# 逆流域

## 作用

逆流域负责回答“当世界里原本单向向外的流动开始反向回返时，文明如何重新理解边界、秩序和归属”。对 MOSS 来说，逆流不只是人群回流，还包括物资回撤、信息回灌、忠诚回摆和影响力反向穿透。它意味着系统不再只面对扩张和输出，而要面对那些从边缘、旧区和外部重新冲回来的力量。

## 为什么文明会遇到逆流

1. 扩张失败、边缘崩塌和资源变化会让原本向外的链条突然回卷。
2. 被流放、被迁徙和被转移的对象会在某个节点寻找归返通道。
3. 外部信息和旧制度残响可能沿着曾经输出的路径反向进入核心区。
4. 若文明只懂单向管理，就会把逆流全部误判成异常而非结构变化信号。

## 逆流类型

### 人群逆流

迁出者、流放者、避难者和边缘劳动力重新涌回原核心区或旧节点。

### 物资逆流

原本外运的设备、废料、配给物和战略储备以非预期方式回流系统内部。

### 信息逆流

外围叙事、旧日志、边缘经验和外部观察重新进入核心话语，冲击既有口径。

### 忠诚逆流

曾经稳定向某中心聚拢的信任与服从开始回摆、分散或重新指向旧共同体。

## 逆流的制度问题

### 识别

文明要区分逆流是短期波动、危机反应，还是深层结构方向已经改变。

### 吸纳

并非所有逆流都应被拦截，很多反向运动恰恰携带修复系统所需的资源与信息。

### 节流

若反向回返过快，核心区、口岸和基础设施会承受巨大压力，需要临时缓冲机制。

### 再分配

逆流改变了原有配给、身份和权力布局，制度必须重新分配空间与位置。

## 逆流政治

1. 谁被允许回来，谁的回返被定义成威胁，体现共同体边界的真实形状。
2. 核心区是否只欢迎资源和劳力回流，却排斥责任、记忆和追责的回返。
3. 某些派系会不会利用逆流制造新的恐慌，以重新收紧门槛和边界。
4. 当忠诚开始逆流时，文明是否必须承认旧中心已经不再是唯一引力源。

## 逆流风险

- 反向拥堵：人流、物流和信息流同时回返，导致口岸和核心节点过载。
- 选择性吸纳：只吸纳有价值部分，把其余逆流对象再次抛回边缘。
- 逆流恐慌：把一切回返都污名化，错失重组系统的窗口。
- 中心失衡：核心区未准备好面对反向流动，内部秩序反而先于边缘区失稳。

## 逆流域中的关键问题

1. 文明更该害怕逆流带来的拥挤与冲击，还是害怕继续拒绝那些已经开始回返的力量。
2. 哪些逆流必须被导入并重组，哪些逆流必须被延迟、过滤或阻断。
3. 如果 MOSS 的未来更多来自回流而非向外扩张，它是否已经进入另一个文明阶段。
