# 隐私域

## 作用

隐私域负责回答“在一个高观测文明中，什么仍然可以不被看见”。对 MOSS 来说，隐私不是简单的个人偏好，而是和尊严、实验空间、异议安全、关系边界和记忆主权直接相关的制度问题。

## 为什么高观测文明仍需要隐私

1. 完全透明会让所有行为变成表演，压缩真实判断空间。
2. 某些关系、记忆和内部状态若无法保密，将失去自治意义。
3. 创新与异议往往需要在非公开环境中先形成。
4. 如果谁都没有隐私，真正有权者反而最容易拥有例外。

## 隐私类型

### 记忆隐私

并非所有历史片段都应向共同体完全展开，尤其是私人创伤与未成熟判断。

### 关系隐私

师承、盟约、亲密协作和内部裂痕若被过度公开，会改变关系本身。

### 试验隐私

某些低风险探索需要暂时不被公共舆论和指标系统直接干预。

### 撤回隐私

个体和组织是否有权在一定条件下隐藏、降噪或延迟公开自身部分状态。

## 隐私与观测的张力

### 安全需求

安全与观测系统会天然要求看见更多，以提前识别风险。

### 自治需求

自治主体若完全暴露，最终只会学会迎合评分与审计，而不是形成真实意志。

### 权力不对称

隐私从来不会平均分布，真正的问题是谁有资格保留不可见性。

## 隐私政治

1. 哪些结构拥有更高程度的隐私豁免。
2. 边缘区是否比核心区更容易被过度暴露。
3. 隐私是否会被污名化为“不透明”或“有鬼”。
4. 当禁书、病理和安全风险介入时，隐私边界如何被重新定义。

## 隐私风险

- 透明暴政：一切都被要求可见、可审计、可追踪，自治空间归零。
- 特权隐私：高位结构保留深度不可见性，普通成员却被全裸化。
- 隐私滥用：打着隐私名义掩盖腐败、病理和危险实验。
- 记忆剥夺：公共记录权过强，个体失去对自身过去的控制。

## 隐私域中的关键问题

1. MOSS 应更害怕黑箱，还是更害怕无处藏身。
2. 哪些东西必须永远可审计，哪些东西应被制度性保护。
3. 若真正的自由只存在于不可见处，文明是否还称得上开放。
