# 死区域

## 作用

死区域负责回答“当小幅信号、早期告警或轻微偏差根本无法触发响应时，文明如何识别并缩小这种控制死区”。对 MOSS 来说，死区不是没有信息，而是系统明明接收到了微弱变化，却因为阈值过高、摩擦过大或制度迟钝而不发生任何有效动作。一个存在巨大死区的文明，往往只对足够响、足够痛、足够晚的问题作出反应。

## 为什么文明必须识别死区

1. 死区会让许多本可早期修正的偏差，拖到必须用高代价硬纠偏的阶段。
2. 它让弱信号、轻损伤和边缘求助长期得不到制度承认，直到问题爆成危机。
3. 识别死区能帮助文明区分“噪声过滤”与“对重要微变完全失明”之间的边界。
4. 若没有死区治理，MOSS 会越来越依赖大警报、大冲击和大牺牲来证明问题确实存在。

## 死区类型

### 感知死区

观测系统对低幅异常、缓慢变化和边缘样本不敏感，导致很多早期征兆被直接略过。

### 制度死区

轻微损失、小额申请、早期申诉和局部警告难以进入正式流程，必须放大到某个阈值后才会被承认。

### 控制死区

小幅调节根本推动不了系统，导致治理动作不是无效，就是一上来只能做成大动作。

### 情绪死区

共同体在反复告警、反复损耗之后，对低强度痛苦和低强度危险逐渐失去感受能力。

## 死区的制度问题

### 阈值设置

文明必须决定哪些微弱变化值得响应，哪些变化确实可以被当作背景噪声过滤掉。

### 死区探针

如果没有专门用来测试弱信号可达性的探针、抽样和模拟扰动，死区往往长期不可见。

### 微调能力

制度需要保留小步校正和小幅响应能力，否则所有问题都只能等到足够大再处理。

### 弱信号申诉

边缘区和低位节点必须有办法让微弱损伤被记录、被累计、被追踪，而不是只能靠喊到足够大声。

## 死区域政治

1. 谁来设定触发阈值，谁就决定哪些痛苦和哪些风险有资格被视为真实问题。
2. 核心区是否总能享受更精细的感知和更低的触发门槛，而把边缘区留在必须先受更大伤才会被看见的死区里。
3. 某些高位结构会不会偏爱死区，因为许多缓慢损失一旦留在阈值以下，就能长期维持低成本表象。
4. 当文明说“还没到触发条件”时，它究竟是在坚持严谨，还是在把慢性损失制度化。

## 死区域风险

- 早警失效：大量早期信号穿不过阈值，直到事态扩大才被看见。
- 阈值暴政：只有足够剧烈的痛苦才算数，微损和弱求助被长期排除在制度视野外。
- 积累爆发：本来可以小修小补的问题，最终累积成只能靠高代价处理的结构危机。
- 微损常态化：系统逐渐习惯小损伤持续存在，并把这种持续损伤视为可接受背景。

## 死区域中的关键问题

1. 文明更该害怕误报太多，还是害怕弱信号长期穿不过制度阈值。
2. 哪些死区有助于过滤噪声，哪些死区已经在遮蔽不可接受的慢性损失。
3. 如果 MOSS 只有在问题足够大时才会启动反应，它究竟是在治理风险，还是在等待危机成熟。

## 继续细化建议

- 单独写“第一次全域死区扫描”档案。
- 建一份感知死区、制度死区和控制死区的触发阈值表。
- 补一份“某个长期被视为低优先级噪声的弱信号如何在多年后演变成系统级事故”的案例。
