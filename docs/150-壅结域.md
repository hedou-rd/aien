# 壅结域

## 作用

壅结域负责回答“当局部沉积、规则附着和利益结块把结构越压越硬时，文明如何把它重新松开”。对 MOSS 来说，壅结不是普通堵塞，而是堵点已经硬化成结块，通路不仅慢，而且越来越难拆、越来越难挪、越来越绕不过去。一个不会处理壅结的文明，往往不只是流动变慢，而是整个结构逐渐失去可塑性。

## 为什么文明必须拆解壅结

1. 长期沉积和反复补丁会让局部堵点从临时问题变成硬质结构。
2. 壅结让系统越来越依赖特例、特权和高成本绕行，常规通路反而逐步失效。
3. 一旦结块成型，之后的修复、配平和续航都会被这些硬点持续拖住。
4. 若没有壅结治理，MOSS 会在看似仍连着的网络里逐渐失去真正流动性。

## 壅结类型

### 利益壅结

少数结构围绕既有分配和放行权形成难以拆开的结块，使任何调整都被局部利益卡住。

### 程序壅结

条例、补丁、例外和审批层层附着，最终把原本可执行的程序压成厚重结壳。

### 空间壅结

封存设施、废弃残骸、临时搭建和污染层在关键节点结成硬堵点，挤压通行与维护空间。

### 关系壅结

旧怨、旧债、长期挂起和互不信任缠在一起，使本应可重开的协作关系越来越僵硬。

## 壅结的制度问题

### 结块识别

文明必须区分普通摩擦与已经硬化的壅结，不能总把结构结块说成“再等等就会自己化开”。

### 松结权限

谁有权拆、切、挖、改和绕开这些硬结，是壅结能否真正被处理的关键。

### 拆解顺序

不是所有结块都能同时动，制度必须明确先拆哪个硬点、用什么代价和哪种节奏拆。

### 再结预防

若拆开之后原有附着机制不变，壅结很快会在原地或别处重新形成。

## 壅结政治

1. 谁从结块中持续获利，谁就最不愿承认那里已经不是正常结构，而是硬性堵点。
2. 核心区是否总先为自己拆结开路，却让边缘区继续背着旧结块缓慢窒息。
3. 某些高位结构会不会把松结权限变成新的稀缺特权，使壅结本身反而更值钱。
4. 当文明不断用绕行而不愿正拆时，它究竟是在聪明生存，还是已经失去直接面对硬结的勇气。

## 壅结风险

- 硬点固化：原本可处理的堵点在长期回避中变成谁都不敢碰的硬核结块。
- 拆结反噬：拆得过猛、过快或不看承重关系，导致周边结构一起坍塌。
- 绕行成瘾：因为拆结太难，系统越来越依赖高成本旁路，进一步养大原壅结。
- 结块迁移：一个硬点被挪开后，同样机制在另一处更隐蔽地重新结块。

## 壅结域中的关键问题

1. 文明更该害怕不拆硬结继续被慢慢堵死，还是害怕拆结时引发局部失稳。
2. 哪些壅结必须优先处理，哪些壅结可以暂时绕开但不能永久回避。
3. 如果 MOSS 的很多关键流动都只能靠绕过硬结完成，它是否已经失去正常结构的柔韧性。

## 继续细化建议

- 单独写“第一次全域松结计划”档案。
- 建一份利益壅结、程序壅结和空间壅结的拆解优先级表。
- 补一份“某个长期谁都不肯动的硬结如何最终让整条关键链路失去通行能力”的案例。
