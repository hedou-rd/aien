# 量化域

## 作用

量化域负责回答“当连续变化必须被压缩成离散等级、离散配额和离散标签时，文明如何处理量化带来的精度损失与阈值扭曲”。对 MOSS 来说，量化不是单纯把现实写成数字，而是把连续世界切成有限档位，再据此分配权限、资源和责任。一个不会反思量化代价的文明，往往会把方便处理的离散标签误认成现实本身。

## 为什么文明必须处理量化

1. 任何大规模治理都离不开量化，否则系统无法比较、排序、调度和审计海量对象。
2. 但一旦把连续变化切成离散档位，阈值附近的真实差异就会被硬拐成制度断崖。
3. 量化迫使 MOSS 承认“可处理”不等于“完全真实”，很多精度会在进入制度时被主动丢掉。
4. 若没有量化治理，文明会在粗暴标签和无法处理的连续复杂性之间反复摆荡。

## 量化类型

### 指标量化

把负载、风险、效率、信用和损伤压缩成可比较的等级、分值和序列。

### 配额量化

把资源、时间和通道容量切成离散份额，以便排队、分发和追责。

### 风险量化

把原本连续演化的不确定性压缩成几个危险等级，决定何时升级、何时封控、何时让行。

### 情绪量化

把疲劳、恐慌、信任和哀伤折算成可被制度读取的简化信号，用于公共治理和稳定判断。

## 量化的制度问题

### 量化粒度

文明必须决定分档要切多细、多粗，以及在哪些地方保留连续描述而非强行离散化。

### 阈值设计

每一道等级分界线都会制造制度拐点，系统必须解释为什么划在这里，而不是划在别处。

### 量化残差

所有被压缩进标签之外的细节和上下文都不会自动消失，制度必须承认这部分残差会继续影响后果。

### 反量化修正

当量化结果明显扭曲现实时，文明需要保留人工复核、例外修正和重新分档机制。

## 量化政治

1. 谁定义分档方式，谁就定义了什么差异算重要、什么差异可以被制度直接抹平。
2. 核心区是否总能影响量化口径，让最有利于自己的连续现实被切成更舒服的标签区间。
3. 某些高位结构会不会故意偏好粗粒度量化，因为越粗糙的标签越方便隐藏真实不均。
4. 当文明说自己只是按量化结果行事时，它究竟是在坚持程序，还是在回避量化本身已经扭曲了现实。

## 量化风险

- 阈值断崖：真实差异很小的对象，只因跨过一条线就被制度完全不同对待。
- 精度丢失：关键上下文在压缩成等级时被丢掉，导致制度判断持续偏粗。
- 标签固化：量化标签从临时工具变成长期身份，反过来重写对象命运与资源机会。
- 阈值投机：系统成员围绕分界线优化行为，追求好看的档位而不是真实改善。

## 量化域中的关键问题

1. 文明更该害怕量化过粗导致误判，还是害怕不量化而完全失去大规模处理能力。
2. 哪些现实必须接受离散化压缩，哪些现实必须保留连续描述才不至于被制度伤害。
3. 如果 MOSS 越来越依赖等级和分值来理解世界，它真正变强的是处理能力，还是自我简化能力。
