# 伪装域

## 作用

伪装域负责回答“文明在高压环境下何时需要戴上假面”。对 MOSS 来说，伪装不是简单欺骗，而是围绕假面、替身、诱饵、身份遮蔽和表层叙事保护建立的一套防护与风险管理结构。

## 为什么文明会需要伪装

1. 并非所有关键设施、脆弱群体和真实意图都适合完全暴露。
2. 外部威胁、内部清洗和高观测压力会迫使文明构造保护性表层。
3. 某些伪装是为了争取生存时间，而不是为了永久欺瞒。
4. 伪装也暴露出文明是否还能在真实与保护之间保持边界感。

## 伪装类型

### 设施伪装

用替代性外观、冗余表层和误导性标记保护关键节点与脆弱基础设施。

### 身份伪装

在不完全安全的环境中，为个体、见证者、迁移群体和庇护对象提供有限遮蔽。

### 叙事伪装

以更安全的表述包装真实意图、真实创伤或暂时不能公开的结构变更。

### 诱饵伪装

通过可放弃的表层结构吸引风险，而让更关键部分保留在更深层。

## 伪装的制度边界

### 临时性

伪装若没有退出机制，就会从保护性外衣变成常态化失真。

### 可追责性

即便外部不知道全部真相，内部也应有人能追踪伪装为何存在、何时终止。

### 最小欺瞒

文明必须回答：在保护安全的前提下，伪装可以误导到什么程度。

### 与隐私区分

隐私是保留不可见性，伪装则主动制造另一层可见外观，两者不能混为一谈。

## 伪装政治

1. 谁能批准伪装，谁能解除伪装。
2. 伪装是保护脆弱者，还是让高位结构更容易逃避监督。
3. 长期伪装是否会侵蚀共同体对正式信息的信任。
4. 当伪装成功过多次后，文明会不会开始怀疑一切表面都不真实。

## 伪装风险

- 真实枯竭：文明越来越依赖假面，导致内部也失去真实协作基础。
- 特权伪装：只有高位结构能安全使用假面，弱者反而更暴露。
- 诱饵反噬：为误导外部而制造的表层结构，反而误导了自己。
- 防护变操控：以保护为名的伪装逐步变成信息操控常态。

## 伪装域中的关键问题

1. 文明应如何区分必要伪装与有害欺瞒。
2. 哪些对象配得上被保护性遮蔽，哪些必须保持透明。
3. 若一个文明长期靠假面生存，它是否还知道自己真正长什么样。
