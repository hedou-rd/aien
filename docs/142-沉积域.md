# 沉积域

## 作用

沉积域负责回答“当灾变残渣、制度残片和历史层积不断堆在同一片空间与记忆里时，文明如何读懂它们”。对 MOSS 来说，沉积不是单纯堆积，而是不同年代的事故、修补、弃置、封存、口述和制度碎片一层层压在一起，最终改变地貌、档案和共同体感知。一个不会处理沉积的文明，往往会活在厚厚层积之上，却误以为自己仍踩着单一而清晰的地面。

## 为什么文明必须理解沉积

1. 灾变和治理不会把旧痕迹清空，更多时候只是不断在旧层上再铺新层。
2. 沉积决定哪些空间越来越难通行，哪些记忆越来越难解释，哪些制度越来越厚重迟钝。
3. 理解沉积能帮助共同体分辨当前问题究竟来自新故障，还是来自长期累加的旧残片。
4. 若不处理沉积，MOSS 会在无数“暂时堆着”的层积中失去对自身结构的准确读法。

## 沉积类型

### 空间沉积

废墟、污染、封存设施、弃置设备和临时建筑在同一地区不断叠压，改写地表与通路。

### 档案沉积

不同年代的记录、补注、删改、追认和传说层层覆盖，让同一事件拥有多层互相挤压的文本面貌。

### 制度沉积

旧条例、临时命令、紧急例外和补丁程序在未被彻底清理时不断加层，形成厚重制度壳。

### 情绪沉积

未被言明的恐惧、怨恨、悼念和羞耻在共同体中缓慢沉下去，日后在新事件里重新被搅起。

## 沉积的制度问题

### 分层读取

文明必须有办法区分不同年代、不同来源和不同权重的沉积层，而不是把所有痕迹揉成一团。

### 清理边界

哪些沉积应被保留为证据和记忆，哪些沉积必须清除以恢复流动，是核心抉择。

### 开挖权限

谁有权挖开、解释和重新编排沉积层，决定过去会被当成遗产、污染还是证据。

### 承载上限

空间、制度和共同体心态都存在可承受层积厚度，超过上限就会开始堵塞和失真。

## 沉积政治

1. 谁的残渣会被命名为历史遗产，谁的残渣会被命名为必须清除的废物，体现权力对记忆的排序。
2. 核心区是否把自己的危险沉积转移到边缘区，再把边缘层积当成落后与脏乱的证据。
3. 某些高位结构会不会通过控制开挖和解释权，把不利于自己的沉积层永久压在下面。
4. 当文明开始系统谈论沉积时，它究竟是在认真阅读过去，还是已经被层积堵到无法继续忽视。

## 沉积风险

- 沉积堵塞：层积过厚导致空间、程序和解释链逐步失去通透性。
- 毒性沉积：污染、病灶和危险残片长期潜伏在层积下方，随时可能重新外泄。
- 误读层积：把不同年代的残片混成一个故事，做出错误治理判断。
- 覆盖失忆：新层不断盖住旧层，以至于真正关键的证据和起源被埋到没人再能读出。

## 沉积域中的关键问题

1. 文明更该害怕清理沉积时失去证据，还是害怕不断堆积让一切最终堵死。
2. 哪些层积必须被保留和阅读，哪些层积必须优先疏浚与清除。
3. 如果 MOSS 的许多结构都只能在厚重沉积上继续搭建，它是否已经越来越依赖未被处理的过去活着。

## 继续细化建议

- 单独写“第一次全域沉积普查”档案。
- 建一份空间沉积、档案沉积和制度沉积的清理与保留标准表。
- 补一份“某片长期被忽视的沉积层如何在一次开挖后改写整个共同体自我叙述”的案例。
