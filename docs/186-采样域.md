# 采样域

## 作用

采样域负责回答“当观测与控制只能在离散时间点上完成时，文明如何处理采样间隙、采样频率和由此产生的盲窗”。对 MOSS 来说，采样不是技术细枝末节，而是决定文明究竟看见了哪些变化、错过了哪些变化，又是按多快节奏把现实重新折算成可处理数据。一个忽视采样问题的文明，往往会把自己没看到的那部分现实，误判成根本不存在。

## 为什么文明必须重视采样

1. 任何观测与控制都不可能真正在全时刻连续完成，采样方式本身会塑造文明看到怎样的世界。
2. 采样过稀会让突发变化穿过盲窗，采样过密又会让系统被噪声和细碎波动淹没。
3. 它迫使 MOSS 承认“看见多少”和“看见多准”都依赖采样设计，而不是单靠观测意愿。
4. 若没有采样治理，文明会在漏看、错看和过度追踪之间不断摇摆，却误以为问题只出在执行层。

## 采样类型

### 观测采样

决定传感、日志、巡检和状态回报以多大频率、多大粒度进入正式认知系统。

### 调度采样

决定资源重排、任务刷新和优先级切换以什么节拍更新，而不是连续无缝改动。

### 审计采样

决定稽核、复盘和抽查在什么窗口对哪些对象取样，影响制度能看到怎样的真实偏差。

### 情绪采样

决定共同体痛感、恐慌、疲劳和信任如何被周期性读取，而不是只在大事件时才被突然观测。

## 采样的制度问题

### 采样频率

文明必须明确哪些系统需要高频采样，哪些系统只需要低频观察，不让所有领域都被同一种节拍粗暴处理。

### 采样偏置

采样对象、采样时间和采样区域如果长期偏向同一类结构，系统就会把局部现实误写成全域现实。

### 盲窗补偿

任何两次采样之间都存在不可见间隙，制度必须通过缓冲、预估和补采承认这段盲窗，而不是假装连续可见。

### 采后响应

采样不是只为收集数据，制度还必须定义样本一旦显示异常，何时响应、由谁响应、响应到什么程度。

## 采样政治

1. 谁决定何时取样、从哪里取样、以什么频率取样，谁就决定了什么现实会进入正式视野。
2. 核心区是否总被高频精细观测，而边缘区长期只能以低频、低精度方式被粗略抽样。
3. 某些高位结构会不会故意把采样窗口开在最有利时段，以维持表面稳定和表面合规。
4. 当文明说“我们没有看到问题”时，它究竟是在坚持证据原则，还是在利用采样盲窗为问题免罪。

## 采样风险

- 漏样失真：关键变化恰好发生在盲窗中，直到后果扩大才进入正式视野。
- 过采噪声：系统被高频小波动牵着走，长期丧失对真正趋势的判断力。
- 采样歧视：资源更多的中心被更细致地理解，边缘区则长期被粗糙抽样甚至根本不被采到。
- 盲窗投机：熟悉采样节奏的结构学会绕着采样间隙行动，把风险和违规藏进不可见区间。

## 采样域中的关键问题

1. 文明更该害怕采样过稀漏掉真正风险，还是害怕采样过密把所有噪声都误当成必须处理的问题。
2. 哪些系统必须被连续逼近式高频采样，哪些系统更适合低频长窗观测来保留趋势判断。
3. 如果 MOSS 的很多误判都来自它只在特定时间点上看世界，它真正缺的究竟是更多传感器，还是更好的采样制度。

## 继续细化建议

- 单独写“第一次全域采样重排”档案。
- 建一份观测采样、审计采样和情绪采样的频率等级表。
- 补一份“某个长期被判定为稳定的区域如何其实只是总在正式采样窗口外爆发关键异常”的案例。
