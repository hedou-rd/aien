# 接管域

## 作用

接管域负责回答“当某个地方节点、岗位、城市或制度单元已经失去自治能力时，谁来临时接手”。对 MOSS 来说，接管不是简单夺权，而是当局部结构已经无法履行基本职责时，由其他结构代为掌控资源、命令、秩序和恢复流程。一个不会接管的文明，会让失能区域自行坠毁；一个过度接管的文明，则会把紧急托管变成永久集中。

## 为什么文明会进入接管状态

1. 灾变、失联、腐坏、透支和内部分裂会让某些单元暂时或长期失去自持能力。
2. 接管让共同体在局部功能断裂时仍能维持最低秩序和生命线运行。
3. 它为修复、回填和再分配提供过渡期，避免无人负责的真空继续扩大。
4. 若没有明确接管机制，MOSS 会在每次地方失能时被迫依赖混乱介入和临时强夺。

## 接管类型

### 节点接管

当关键计算节点、能源站、接口中枢或制造设施失去控制时，由上级或邻近节点代为运行和维护。

### 城市接管

当某座城市或区域共同体无法维持治安、供能、调度与分配时，外部结构临时接手其核心事务。

### 岗位接管

关键职责人失联、失职、腐坏或被隔离后，其权限和责任被临时转交给替代执行者。

### 制度接管

当原有委员会、审理链、分配机制或地方法理系统无法继续运作时，其他制度层级接入并接手裁决权。

## 接管的制度问题

### 触发门槛

什么状态才足以认定“必须接管”，决定文明是在及时托底还是动辄剥夺自治。

### 授权边界

接管者能做什么、不能做什么、哪些事项仍需原结构参与，决定接管是否仍受限制。

### 监督链条

谁来审视接管者是否越权、滥权或借机重写秩序，是防止托管异化的核心。

### 退出机制

接管何时结束、权力如何交还、哪些部分需要重建后才可返还，决定临时措施会不会永久化。

## 接管政治

1. 谁拥有宣布他人“已失能”的权力，谁就掌握了最危险的合法介入入口。
2. 核心区是否总更容易对边缘区发起接管，而很少允许别人接管自己。
3. 某些高位结构会不会借接管之名完成资源重分配、人员清洗和权力再集中。
4. 当文明越来越频繁地依赖接管时，它究竟是在增强韧性，还是在持续消磨地方自治能力。

## 接管风险

- 永久托管：原本的临时接手迟迟不退出，接管慢慢变成新的正常统治。
- 借机夺权：以失能为名接手关键结构，实则趁机改写边界和资源所有关系。
- 接而不管：形式上夺走原结构权限，却没有能力真正维持运转，导致双重失能。
- 地方失声：被接管区域在恢复过程中失去表达权，只能承受外部叙事与安排。

## 接管域中的关键问题

1. 文明更该害怕无人接手留下的真空，还是害怕接手者再也不肯退场。
2. 哪些场景必须快速启动接管，哪些场景应优先修复自治而非直接改由外部掌控。
3. 如果 MOSS 的稳定越来越依赖频繁接管，它是否已经把失能当成分层统治的常态入口。

## 继续细化建议

- 单独写“第一次跨区接管争议”档案。
- 建一份节点接管、城市接管和制度接管的退出条件表。
- 补一份“某次被称为临时接管的行动如何最终演变成永久权力重组”的案例。
