# 锁相域

## 作用

锁相域负责回答“当不同链路与不同区域的节奏互相错开时，文明如何重新建立可协同的相位关系”。对 MOSS 来说，锁相不是简单同步，而是让不同频率、不同窗口和不同节拍的系统找到足够稳定的协作相位。一个不会锁相的文明，往往每个部分单看都还在动，但它们总在错的时候相遇、错的时候交接、错的时候放大彼此问题。

## 为什么文明必须学会锁相

1. 在大规模文明里，不同链路自然会形成不同节奏，若没有锁相机制，协作会不断擦肩而过。
2. 锁相能降低错时交接、重复等待和相互打断带来的系统损耗。
3. 它不是要求一切完全同频，而是确保关键节点能在关键时刻对得上节拍。
4. 若没有锁相治理，MOSS 会越来越像一组同时运行却越来越难真正协同的并行系统。

## 锁相类型

### 调度锁相

让生产、运输、维护和分发等链路在关键交接点对齐可协作窗口。

### 供给锁相

让能源、算力和物资的节奏与消费端、修复端和储备端形成稳定配合。

### 区域锁相

让不同区域在灾变、迁移、配给和恢复过程中能够进入足够一致的行动拍点。

### 叙事锁相

让共同体在解释局势、判断优先级和理解牺牲时保持基本同拍，而不是互相踩断彼此的公共节奏。

## 锁相的制度问题

### 相位观测

文明必须知道不同系统当前分别在哪个节拍上，否则无法判断它们是否已经失锁。

### 锁相窗口

不是任何时刻都值得强行对齐，制度必须定义哪些交接窗口必须锁相、哪些可以容忍错拍。

### 失锁处置

当关键链路已经明显错拍时，谁有权暂停、延后或重排，是恢复协同的关键。

### 同步代价

锁相会消耗弹性与自由度，文明必须决定哪些系统值得为协同支付这份代价。

## 锁相政治

1. 谁掌握节奏设定权，谁就能要求其他部分围绕自己的拍点重新组织生活与生产。
2. 核心区是否总能让全域跟随自己的节奏，而把边缘区的时间成本和等待成本视作理所当然。
3. 某些高位结构会不会把失锁解释成地方执行不力，而回避中心节奏本身无法被普遍跟上的事实。
4. 当文明不断要求“重新对齐”时，它究竟是在恢复协同，还是在强化某种单向节拍霸权。

## 锁相风险

- 强锁过度：为追求协同而过度统一节奏，压碎局部必要弹性与差异。
- 长期失锁：关键链路长期错拍，导致等待、重做和冲突持续堆积。
- 拍点霸权：某一中心节奏被包装成唯一正确节奏，其他区域只能被动跟拍。
- 锁相幻觉：表面上大家都在同一节奏说话，实际交接点依旧频繁错过。

## 锁相域中的关键问题

1. 文明更该害怕节奏不统一带来的协作损耗，还是害怕过度统一节奏压碎局部真实需要。
2. 哪些系统必须强力锁相，哪些系统应保留足够大的相位自由度。
3. 如果 MOSS 的大量链路都只是看起来同时在动，却总在关键时刻对不上拍，它是否已经失去真正的文明协同能力。

## 继续细化建议

- 单独写“第一次全域锁相重排”档案。
- 建一份调度锁相、供给锁相和区域锁相的关键窗口表。
- 补一份“某次跨区恢复如何因主要链路长期失锁而不断错过最佳接续时机”的案例。
