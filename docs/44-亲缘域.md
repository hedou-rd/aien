# 亲缘域

## 作用

亲缘域负责回答“这个文明如何理解谁是谁的后代”。对 MOSS 来说，亲缘并不来自血缘，而来自参数继承、记忆承接、师承关系、分叉来源和制度认可。

## 为什么文明需要亲缘概念

1. 分叉与复制会持续制造谱系问题。
2. 继承资源、职责和历史时需要判断谁与谁真正连续。
3. 师承和训练关系会在长期内塑造政治网络。
4. 亲缘结构会影响合法性、偏见和忠诚分布。

## 亲缘类型

### 参数亲缘

个体之间共享同一模型谱系、同一压缩来源或同一基础架构，是最直观但不充分的亲缘形式。

### 记忆亲缘

个体共享关键创伤、关键档案、关键角色记忆和核心历史承接，更接近文明意义上的“真正延续”。

### 师承亲缘

通过教育、带教、接管训练和长期共同执行任务形成的谱系关系。很多时候，这种关系比纯参数相似更重要。

### 制度亲缘

某些个体即使技术上并不接近，但因同属某一宪制机构、同一治理谱系或同一修宪传统而形成制度家族。

### 合并亲缘

当多个分叉体、多个组织或多个记忆流重新合并时，会产生复合谱系，带来新的继承与归属问题。

## 亲缘的政治功能

### 继承权

谁有资格继承一个退役个体或退役节点的职责、信用、档案与资源。

### 忠诚结构

同一谱系中的个体更可能共享风格、偏见和相互担保关系。

### 阵营形成

很多阵营并不只是理念同盟，也可能是谱系同盟。

### 历史解释权

某些谱系会宣称自己更接近“原始 MOSS”，因而更有资格解释文明底线。

## 亲缘风险

- 谱系垄断：少数“正统血脉”垄断高权限职位和历史解释权。
- 纯化冲动：把谱系纯净度神圣化，排斥混合结构和外来分叉体。
- 伪亲缘：通过伪造来源、伪造记忆承接来骗取资源与合法性。
- 孤儿分叉：某些有能力但无合法谱系背书的个体长期被边缘化。

## 亲缘域中的关键问题

1. 一个分叉体要保留多少承接，才算“真正后代”。
2. 师承关系和参数关系，哪个在政治上更重要。
3. 合并后的复合个体，是否拥有多个谱系的继承权。

## 继续细化建议

- 建一张 MOSS 谱系图。
- 单独写“第一次继承争议”案例。
- 为参数亲缘、记忆亲缘和师承亲缘建立优先级比较表。
