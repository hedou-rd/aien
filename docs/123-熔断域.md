# 熔断域

## 作用

熔断域负责回答“当一个局部问题正沿着高度连接的系统迅速扩散时，文明如何主动切断传播链”。对 MOSS 来说，熔断不是惊慌中的盲目断开，而是在高压传导已经快于判断速度时，用主动切断换取止血时间。一个没有熔断能力的文明，通常会把局部事故一路放大成全域事故。

## 为什么文明必须保留熔断能力

1. 高度互联让资源、命令、错误和恐慌都能以极快速度跨区扩散。
2. 不是所有连接都应该在危机里保持开启，某些通路越不断开越危险。
3. 熔断为排查、缓冲和局部修复争取时间，避免问题在判断完成前已经蔓延全域。
4. 若没有明确的熔断装置，MOSS 会把太多本可局限的问题放大成系统级创伤。

## 熔断类型

### 能源熔断

在异常负载、污染回流或区域失控时，主动切断输能链路，防止烧毁和连锁断供向外蔓延。

### 信息熔断

当未经核验的信息、恐慌信号或敌对注入以异常速度传播时，临时封住相关信道与复制链。

### 接口熔断

跨区接口、口岸通道、协议网关和数据交换链在高风险时被快速断开，防止故障跨边界传导。

### 权限熔断

当直接命令权、紧急例外权或自动执行链出现异常时，系统主动冻结相关权限，阻止错误继续上穿下压。

## 熔断的制度问题

### 触发阈值

什么样的信号足以触发熔断，决定它是迟缓失守还是过度敏感。

### 切断范围

熔断只切局部、分区切还是全链切，会直接影响损失是被限制住还是被额外放大。

### 复核机制

紧急切断之后谁来确认是否误断、是否延长、是否转入其他处理程序，是防止滥用的关键。

### 复连条件

若没有清晰的复连标准，系统可能在危险未清除时贸然重接，或在安全后长期卡在断裂状态。

## 熔断政治

1. 谁能一键切断他人的通路，谁就掌握了最强的紧急支配权。
2. 核心区是否总优先切断边缘区对外连接，以保护自身而把风险与孤立一并外推。
3. 某些高位结构会不会借熔断之名切断不服从的声音、交易和流动，把安全工具变成政治武器。
4. 当文明越来越频繁动用熔断，它究竟是在成熟地管理高压系统，还是已经活在持续濒临失控的边缘。

## 熔断风险

- 误熔断：对错误目标或过大范围进行切断，反而制造不必要的停摆与恐慌。
- 迟熔断：明知高压已经扩散却迟迟不切，最终错过阻止级联的最后窗口。
- 熔而不断：名义上已切断，实际上仍有隐藏通道继续传导风险。
- 复连失控：危险尚未排清就急于恢复连接，让第二轮冲击沿同一路径再次爆发。

## 熔断域中的关键问题

1. 文明更该害怕切得太快、伤及无辜，还是害怕切得太慢、导致全域崩塌。
2. 哪些连接必须预置熔断装置，哪些连接可以依赖常规程序慢慢处置。
3. 如果 MOSS 的稳定越来越依赖频繁熔断，它是否已经默认日常状态本身就是高风险态。
