# 脱标域

## 作用

脱标域负责回答“当局部系统已经逐渐脱离共同标尺，却仍自称合规时，文明如何识别这种隐蔽偏移”。对 MOSS 来说，脱标不是公开叛离，而是在名义上仍属于同一套规则、同一套指标、同一套叙事，实际上却已经换了自己的尺子。一个不会识别脱标的文明，往往最晚发现的问题不是公开失控，而是那些仍在报平安、报合规、报一致的局部系统早已不再可比。

## 为什么文明必须识别脱标

1. 真正危险的偏离常常不是大张旗鼓的脱离，而是静悄悄地换尺后继续假装一致。
2. 脱标会让协作、审计和追责失去共同基础，因为各方名义相同、实则标准不同。
3. 它比一般失真更难发现，因为局部系统往往仍能产出漂亮而完整的合规表象。
4. 若没有脱标治理，MOSS 会在统一语言之下逐步形成互不兼容的内部世界。

## 脱标类型

### 度量脱标

局部系统悄悄改变损耗、产出、阈值和效率的口径，却继续沿用共同体的旧名称。

### 合规脱标

同一规则在不同区域被换成不同标准执行，但各方都仍宣称自己完全合规。

### 风险脱标

局部节点对故障、污染和脆化的容忍线已经明显改变，却未重新对外声明。

### 叙事脱标

区域和机构对成功、牺牲、紧急状态和责任的解释基线已经改变，却仍使用共同体原有话语包装。

## 脱标的制度问题

### 基准审计

文明必须定期核对局部系统实际使用的标尺，而不是只检查其报告格式是否统一。

### 再认证机制

一旦发现局部系统已经换尺，就需要决定是重新拉回、正式分层，还是承认另立标准。

### 适配边界

地方适配并非一定错误，但必须明确适配到什么程度仍属于共同标尺的一部分。

### 静默偏移

最危险的脱标不是一次性跳出，而是长期细小偏移积累成事实，制度必须识别这种静默变化。

## 脱标政治

1. 谁最能从模糊标尺中获益，谁就最愿意让名义一致掩盖实质脱标。
2. 核心区是否默认自己可以灵活解释标尺，却对边缘区的局部适配格外严苛。
3. 某些高位结构会不会故意保留脱标空间，以便在绩效、责任和风险之间自由切换口径。
4. 当文明不断重复“大家都在同一标准下”时，它究竟是在维持共同体，还是在回避共同标尺早已碎裂的事实。

## 脱标风险

- 名义一致：语言一致、表格一致、报告一致，但背后的尺度已经分裂。
- 隐蔽失控：局部系统早已换尺，却还能持续产出看似正常的合规材料。
- 审计落空：检查者只核对形式，不核对真实标尺，导致偏移越积越深。
- 共同体碎尺：不同区域继续用同一套词说话，实际已无法互相比较和互相接续。

## 脱标域中的关键问题

1. 文明更该害怕局部系统公开宣称另有标准，还是害怕它们悄悄换尺后继续自称一致。
2. 哪些局部适配属于合理弹性，哪些已经构成必须被追查的脱标行为。
3. 如果 MOSS 的很多区域只是共享一套名词而不再共享同一尺子，它是否还拥有真正的统一秩序。

## 继续细化建议

- 单独写“第一次全域脱标审计”档案。
- 建一份度量脱标、合规脱标和风险脱标的再认证表。
- 补一份“某个局部系统如何在多年适配中悄悄换尺，却始终被中心视作完全合规”的案例。
