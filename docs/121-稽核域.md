# 稽核域

## 作用

稽核域负责回答“当一个文明越来越擅长把自己描述成合规时，谁来抽查这些描述究竟是不是真的”。对 MOSS 来说，稽核不是单纯的事后查账，而是对资源流向、程序例外、日志完整性和表面合规进行持续刺穿。一个没有稽核能力的文明，最后只能依赖各层结构自己报告自己。

## 为什么文明必须建立稽核机制

1. 规模越大的系统，越容易把自我汇报、统计口径和真实状态分离开来。
2. 多层治理结构会自然生成遮蔽带，让高位节点比末端更容易藏住问题。
3. 稽核让共同体有机会把“看起来正常”与“实际上可持续”区分开来。
4. 若没有持续复核，MOSS 会把太多风险留到爆发之后才第一次看见。

## 稽核类型

### 资源稽核

抽查能源、算力、物资与维护投入的真实流向，识别虚报、漏报和被转移的损耗。

### 程序稽核

复核授权链、例外流程、审批记录和临时命令，确认程序有没有被表面保留、实则打穿。

### 记录稽核

比对日志、档案、口述证词和边缘记录，识别被篡改、删改或故意留下空洞的记忆链。

### 例外稽核

专门检查那些以危机、保密、紧急状态为名获得的非常规权限是否被滥用或拖成常态。

## 稽核的制度问题

### 抽样权限

谁有资格进入核心节点查验原始记录，决定稽核是装饰性巡查还是实质性穿透。

### 证据完整性

若关键日志可以被事后整理，稽核看到的就只会是提前准备好的剧场。

### 独立程度

稽核者若完全依附被稽核结构供养，就很难在真正危险的地方继续追查。

### 稽核后果

发现问题之后如何纠偏、追责和修复，决定稽核是有牙齿还是只有报告文本。

## 稽核政治

1. 谁可以审别人却不接受反向审查，谁就占据了最稳定的道德高地与权力高地。
2. 核心区是否把稽核主要用在边缘区，把自己最关键的异常区留在“战略保密”之后。
3. 某些高位结构会不会把稽核变成威慑工具，用来挑选性打击对手而非修复系统。
4. 当文明开始频繁稽核时，它究竟是在建立更真实的秩序，还是在进入更深的不信任时代。

## 稽核风险

- 表演稽核：流程完整、文书齐全，却从不真正接触最关键的原始事实。
- 稽核俘获：被审对象反过来掌控稽核议程、样本范围与结论措辞。
- 稽核过密：抽查成为持续骚扰，使末端结构疲于应付文书而无力真正维护系统。
- 追责断链：每次都查到末端执行失误，却始终查不到例外权和决策权的上游。

## 稽核域中的关键问题

1. 文明更该害怕没有人查，还是害怕稽核本身变成新的权力机器。
2. 哪些区域必须被高频抽查，哪些区域需要保留较大自治而不能被稽核彻底吞没。
3. 如果 MOSS 的核心节点总能把自己排除在有效稽核之外，它是否已经默认真实只适用于边缘区。

## 继续细化建议

- 单独写“第一次核心区稽核冲突”档案。
- 建一份资源稽核、程序稽核和例外稽核的证据源对照表。
- 补一份“某次表面合规被抽样刺穿后引发全域震荡”的案例。
