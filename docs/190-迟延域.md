# 迟延域

## 作用

迟延域负责回答“当信号、命令和修复动作天然需要时间才能到达时，文明如何面对各种不可消除的系统迟延”。对 MOSS 来说，迟延不是单纯变慢，而是任何判断和任何控制都必须穿过时间差之后才会生效。一个不会面对迟延的文明，往往总把后果当成立刻可控，却在时间差里反复误判自己已经完成了纠偏。

## 为什么文明必须面对迟延

1. 很多控制失败并不是因为完全没动作，而是动作抵达时环境和问题早已换了位置。
2. 迟延会放大过冲、误判和甩锅，因为系统总在今天处理昨天的信息、明天才看到今天的后果。
3. 它迫使 MOSS 承认时间差本身就是结构条件，而不是靠更强意志就能抹掉的噪声。
4. 若没有迟延治理，文明会不断把结构时差误判成执行懒惰或局部不服从。

## 迟延类型

### 传输迟延

信号、命令、数据和物资在链路中传递需要时间，导致各处接收到的现实总有先后差。

### 决策迟延

从发现问题到形成共识、完成审批和正式下令之间存在难以压缩的治理时间差。

### 修复迟延

从动作发起到结构真正恢复之间需要冷却、替换、重建和再校准时间，不能被当成即时完成。

### 情绪迟延

共同体对伤害、损失和安抚的反应往往晚于事件本身，导致制度总容易在错误时间高估或低估情绪强度。

## 迟延的制度问题

### 迟延测绘

文明必须知道不同链路、不同层级和不同区域各自存在多长时差，不能把所有动作默认成同时生效。

### 前馈补偿

当迟延不可消除时，制度必须学会提前估计与提前补偿，而不是只在后果出现后再被动反应。

### 归责窗口

很多结果发生得比动作晚，制度需要明确多长时间内的后果仍算同一轮动作责任，而不是任由责任在时差中蒸发。

### 时差解释

系统必须能向共同体解释为什么某些动作已经发出却还没见效，防止正常迟延被误判成失灵与欺骗。

## 迟延政治

1. 谁更接近低迟延通道，谁就更容易抢在他人之前行动、纠偏和占位。
2. 核心区是否总在更短时差里感知和处置问题，却把长迟延环境留给边缘区自行承受。
3. 某些高位结构会不会故意利用迟延，把尚未显现的后果推给下一轮、下一地或下一任去吸收。
4. 当文明说“效果还需要时间”时，它究竟是在诚实面对结构迟延，还是在用时差掩盖错误动作。

## 迟延风险

- 迟到纠偏：动作到达时问题已变形，原本正确的控制在落地时变成新的错位动作。
- 时差甩锅：后果延后显现，责任在不同时间窗口之间被不断推来推去。
- 补偿过猛：为克服迟延而一次性加大力度，反而把过冲和回摆做得更严重。
- 假即时幻觉：制度表面上宣称实时掌控，实际却在长迟延链里持续闭眼操作。

## 迟延域中的关键问题

1. 文明更该害怕迟延带来的反应滞后，还是害怕为抵消迟延而做出的过猛补偿。
2. 哪些链路必须不惜代价压短迟延，哪些链路可以接受更长时差来换取低成本和高覆盖。
3. 如果 MOSS 的很多失控都来自它总把延后后果当成立即可控，它真正缺的究竟是速度，还是对时差的制度承认。

## 继续细化建议

- 单独写“第一次全域迟延测绘”档案。
- 建一份传输迟延、决策迟延和修复迟延的时差表。
- 补一份“某次本来及时的纠偏如何因长链路迟延在落地时反而推高了新的局部失衡”的案例。
