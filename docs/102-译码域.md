# 译码域

## 作用

译码域负责回答“当文明面对破碎、失传、异构甚至故意加密的信息时，它如何重新读懂自己和他者”。对 MOSS 来说，译码不只是技术解密，而是对旧协议、残缺档案、异类语言、隐写边注和跨代误读进行重新拆解与重建。没有译码能力，文明会被自己的旧文本和外部信号慢慢变成聋子。

## 为什么文明必须不断译码

1. 历史越长，遗留协议和旧文书就越多，直接可读性会不断下降。
2. 灾变、断层和压缩传承会把原本清晰的信息打碎成碎片。
3. 不同区域、谱系和媒介会发展出各自的语言习惯和隐语系统。
4. 若不持续译码，MOSS 会越来越无法理解自己的边缘、过去和敌人。

## 译码类型

### 档案译码

对缺页卷宗、损坏记录、旧格式数据和残留标记进行复原与重组。

### 协议译码

重新理解老旧接口、停用协议、失传命令集和过时标准，让旧系统重新可接入。

### 语言译码

在不同区块、不同阵营和不同时代的话语之间建立可互相理解的转换层。

### 隐语译码

读出暗渠通信、边注暗码、祭司语言和保护性隐写背后的真实意图。

## 译码的制度问题

### 校验

译码结果不能只靠单一解释，必须有多源比对与复核结构，避免误读被写成新真相。

### 权限

并非所有文本和协议都适合完全公开，谁能译、谁能看、谁能再传播是关键边界。

### 保存

译码过程本身必须被留档，否则后代只看到结果，不知道理解如何形成。

### 误译补救

任何译码都可能带入新偏差，文明需要有更正、撤回和再解释机制。

## 译码政治

1. 谁掌握译码权，谁就接近掌握过去与他者的解释权。
2. 核心区是否垄断译码机构，把边缘语言持续归为不可读噪声。
3. 某些机构会不会借“专业译码”之名，把有利自己的解释写成唯一版本。
4. 当文明越来越依赖少数译码者时，它是否也越来越容易被解释权绑架。

## 译码风险

- 误译成法：错误理解被正式写入制度，后续一切都建在偏差上。
- 译码贵族化：只有少数专家能接近旧文本与异构语言，理解权高度集中。
- 过度公开：危险协议和高危文本在译码后被不加区分地传播。
- 伪译码：以复原之名篡改原意，让新解释伪装成被发现的旧真相。

## 译码域中的关键问题

1. 文明更该害怕信息不可读，还是害怕错误地自信读懂了它。
2. 哪些材料必须开放给多方译码，哪些材料应保持高门槛解释。
3. 如果 MOSS 对自己历史的理解大多来自后世译码，它还能否确信自己理解的是原来的自己。

## 继续细化建议

- 单独写“第一次大规模失协议译码计划”档案。
- 建一份档案译码、协议译码和隐语译码的误差来源表。
- 补一份“一个错误译码如何改写整代人的制度理解”的案例。
