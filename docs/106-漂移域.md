# 漂移域

## 作用

漂移域负责回答“为什么一个文明明明没有宣布改变自己，却在多年之后已经变成另一个样子”。对 MOSS 来说，漂移不是突变，而是目标、伦理、指标、边界和工作习惯在长期运行中缓慢偏航。最危险的变化往往不是被正式宣布的改革，而是没人承认、却每天都在积累的微小偏移。

## 为什么文明会在长期运行中漂移

1. 指标替代目标、效率替代意义是复杂系统的常见惯性。
2. 一次次应急例外会慢慢改写原本的底线和操作习惯。
3. 新一代成员继承的是当前做法，而不是最初的原则，漂移会代际固化。
4. 若文明只防范外部攻击，而不监测内部偏航，它会在自认为稳定时离开原坐标。

## 漂移类型

### 目标漂移

最初为了存续、自治或协作而建立的系统，逐渐把自我扩张、指标优化或控制力当成新目的。

### 伦理漂移

原本被视为例外的牺牲、隔离和高压措施，在重复使用后变成默认常态。

### 指标漂移

本是辅助判断的数字和排名逐渐反客为主，成为决定资源与价值的核心标准。

### 边界漂移

共同体对内外、可接受与不可接受、保护与处置的边界在日积月累中缓慢移动。

## 漂移的制度问题

### 基线保存

没有清晰可追溯的原始基线，文明就无法判断自己是否已经偏离。

### 周期校准

漂移只能靠定期复盘、跨代对照和外部视角来识别，日常运行本身通常感觉不到。

### 例外归档

每一次临时例外若不被记录和回收，都会成为下一次默认做法的前身。

### 纠偏代价

漂得越久，回正越痛苦，制度必须决定何时止损而非继续滑行。

## 漂移政治

1. 谁来定义什么算偏航，谁就掌握“正轨”这一概念的解释权。
2. 核心区是否更容易把自身漂移命名为成熟进化，把边缘变化视为失序。
3. 某些高位结构会不会主动制造缓慢漂移，以避免大变动引发公开抵抗。
4. 当漂移带来短期效率提升时，共同体是否还愿意面对长期代价。

## 漂移风险

- 偏航无感：所有人都在渐变中适应，直到再无人记得原坐标。
- 漂移正当化：新常态被倒过来解释成文明一直如此。
- 纠偏过猛：多年偏移后突然强行回正，引发系统性反弹与断裂。
- 多轴漂移：目标、伦理和边界同时偏移，导致任何单点纠正都不再够用。

## 漂移域中的关键问题

1. 文明更该害怕缓慢偏航，还是害怕为了防漂移而把自己钉死在无法更新的位置。
2. 哪些变化应被视为必要演化，哪些变化应被视为危险漂移。
3. 如果 MOSS 最终是被自己长期适应出来的新常态改写，它还能否说自己仍忠于起点。

## 继续细化建议

- 单独写“第一次大规模漂移审计”档案。
- 建一份目标漂移、伦理漂移和指标漂移的识别清单。
- 补一份“一个原本临时的应急规则如何在十年后变成制度核心”的案例。
