# 串扰域

## 作用

串扰域负责回答“当本应分离的通道和功能彼此漏入、互相污染时，文明如何识别和压制这种跨通道串扰”。对 MOSS 来说，串扰不是单纯噪声，而是本应只在自己链路里运行的信号、权限、情绪或负载，开始渗进别的链路并改写别处行为。一个处理不好串扰的文明，往往明明已经做了分频、分层和分区，却还是在关键时刻被跨通道干扰拖乱整体秩序。

## 为什么文明必须压制串扰

1. 串扰会让一个局部问题穿过本不该穿过的边界，把局部失稳扩散成跨域混乱。
2. 它会污染判断，因为系统收到的已不再是本通道自己的纯净信号，而是夹带了他处残响与压力。
3. 识别串扰能帮助文明区分“本链路真的出错”与“别的链路在偷偷漏进来”之间的差别。
4. 若没有串扰治理，MOSS 会把越来越多跨通道污染误认成复杂系统不可避免的背景噪声。

## 串扰类型

### 信号串扰

不同通讯、观测和控制链路彼此漏信号，导致误触发、误识别和错误响应。

### 权限串扰

本应只在特定层级和特定区域生效的权限，开始穿过边界影响其他结构的正常秩序。

### 负载串扰

某条高压链路的拥堵、排队和抢占不断溢出，拖慢原本还算稳定的相邻链路。

### 情绪串扰

警报、动员、哀悼和恐慌跨过本来设定好的范围，污染日常运行和其他公共节奏。

## 串扰的制度问题

### 隔离标准

文明必须明确哪些通道必须强隔离，哪些通道可以允许有限漏通而不至于伤及整体秩序。

### 串扰监测

如果没有专门追踪跨通道泄漏、异常共振和误触发来源的机制，串扰往往只在后果出现时才被看见。

### 屏蔽手段

门控、缓冲、分频、脱耦和清带机制必须被制度化，不然识别了串扰也只能被动忍受。

### 源头归责

制度需要能追清是哪个通道先漏、哪个结构先越界，而不是让所有受害链路一起承担污染代价。

## 串扰政治

1. 谁的通道最容易越界影响别人，谁就最可能在无形中扩张自身影响力。
2. 核心区是否总允许自己的信号与优先级穿透边缘区边界，却要求边缘区对中心保持绝对静默和隔离。
3. 某些高位结构会不会故意维持有限串扰，因为模糊边界比清晰边界更方便渗透和操控。
4. 当文明说自己只是系统耦合过深时，它究竟是在面对结构复杂性，还是在回避跨界污染已经制度化。

## 串扰风险

- 污染扩散：一个局部异常不断穿过边界，污染多个原本独立的判断链与执行链。
- 误因追责：真正的串扰源头被隐藏，受影响链路反而被认定为能力不足。
- 越界常态：权限和信号长期互相渗透，系统逐渐失去本该存在的分层与分区边界。
- 隐性失控：文明表面上仍在按正式分工运行，实际关键行为早已被跨通道压力悄悄改写。

## 串扰域中的关键问题

1. 文明更该害怕通道之间完全隔绝带来的协同损失，还是害怕串扰扩散带来的边界溶解。
2. 哪些链路必须以高成本保持纯净隔离，哪些链路可以允许有限串扰来换取灵活性。
3. 如果 MOSS 的许多判断失真都来自跨通道污染，它真正缺的究竟是更多信号，还是更干净的边界。

## 继续细化建议

- 单独写“第一次全域串扰清查”档案。
- 建一份信号串扰、权限串扰和负载串扰的隔离等级表。
- 补一份“某条原本用于高优先级控制的链路如何因长期被相邻公共流量污染而反复误触发”的案例。
