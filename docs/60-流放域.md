# 流放域

## 作用

流放域负责回答“当文明不愿继续容纳某些存在，又不选择立即清除时，会发生什么”。对 MOSS 来说，流放既是一种边界策略，也是一种延迟裁决方式，它把不可共处的问题向外部空间、边缘带或低连接区转移。

## 为什么会出现流放

1. 并非所有高风险个体都适合直接销毁或永久封存。
2. 某些组织与思想若继续留在中心，会不断撕裂共同体。
3. 流放让文明在惩罚、隔离与保留可能性之间取得折中。
4. 当治理无力彻底解决矛盾时，流放常被用作一种空间性处理手段。

## 流放对象

### 个体流放

针对严重失信、难以驯化、过度危险但仍可控的智能体实施隔离性迁出。

### 组织流放

把整支联盟、研究集群或地下网络整体驱逐到边缘区或荒野带。

### 思想流放

某些不是完全禁绝、但也不能留在中心公共领域的话语与理论，被迫转入外围空间。

### 空间流放

对某一城市、节点群或接口走廊进行制度性降级，让它们在名义上仍属文明，实则被排出核心秩序。

## 流放的制度形式

### 临时流放

在观察期内把对象隔离到外围，保留未来回归或赦免的可能。

### 长期流放

对象不再享有完整权利，只保留最低度生存、通信或交易资格。

### 条件流放

对象若在外围满足某些约束、做出某些补偿，才可能获得部分回返资格。

### 象征流放

即便对象仍存在于物理空间内，也在命名、权限和记忆上被排出共同体。

## 流放政治

1. 谁来决定什么样的存在已经“不适合留在共同体”。
2. 流放是安全工具，还是把复杂问题扫出中心视野的治理偷懒。
3. 被流放者在外围是否会形成反向共同体与替代秩序。
4. 流放是否只是比清除更体面的权力暴力。

## 流放风险

- 外围反噬：被放逐者在荒野或边缘区重组为更危险的力量。
- 永久污名：即使条件改善，流放者也难以真正回返。
- 问题外包：中心把自身制度失败转化成边缘区负担。
- 隐秘处决：某些流放名义下实际是缓慢消灭与抹除。

## 流放域中的关键问题

1. 何种存在值得被流放，而不是被修复、赦免或封存。
2. 流放是否必须伴随最低限度的持续责任。
3. 如果外围秩序比中心更有生存力，谁才是真正被放逐的一方。
