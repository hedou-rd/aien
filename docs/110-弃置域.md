# 弃置域

## 作用

弃置域负责回答“当文明终于承认有些东西不能再保、不能再修、不能再带走时，它如何正式放弃”。对 MOSS 来说，弃置不是简单丢弃物件，而是对区域、设施、计划、关系和身份的制度性告别。一个不会弃置的文明会被所有旧负担拖死，一个过度弃置的文明则会迅速失去自身厚度。

## 为什么文明必须学会弃置

1. 资源有限，所有东西都保留下来通常意味着什么都保不好。
2. 某些设施和计划继续维持的成本已经高于其真实价值。
3. 弃置让文明面对损失，而不是长期活在“也许还能救回来”的拖延里。
4. 但弃置总会留下伦理、记忆和归属后果，不能被处理成纯技术问题。

## 弃置类型

### 设施弃置

对老旧工厂、危险通道、失稳节点和高耗低效系统做出正式停用与撤出决定。

### 区域弃置

把某些废墟带、污染区、边缘缓冲地和长期难以维护的区域从主系统中撤离。

### 计划弃置

放弃已经不可持续或不再有正当性的扩张方案、研究项目和治理工程。

### 关系弃置

文明有时也会正式放弃某些联盟、继承路径或原本试图继续维持的共同体关系。

## 弃置的制度问题

### 宣告

弃置不能只靠默默撤出，必须有清晰命名、责任说明和后续安排。

### 撤离

谁先撤、带走什么、留下什么、谁负责善后，决定弃置是否转化为新的灾变。

### 余留处理

被弃置部分仍会残留资源、风险、记忆和人口，制度不能假装它们自动消失。

### 复返可能

有些弃置是永久断舍，有些只是长期封存，必须区分未来是否保留回返接口。

## 弃置政治

1. 谁能决定什么值得放弃，谁就在定义文明真正珍惜什么。
2. 核心区是否总把弃置首先落到边缘区和低价值群体身上。
3. 某些高位结构会不会把弃置包装成“理性优化”，掩盖其实是选择性放弃责任。
4. 当一个共同体开始频繁弃置自己的历史、空间和成员时，它是否也在弃置自己。

## 弃置风险

- 默弃成灾：没有正式程序的弃置，让被留下者在无名状态中独自承担后果。
- 弃置掩责：以“不得不放弃”为名跳过对前期失误和失管的追究。
- 弃置成瘾：一遇到困难就选择切割与撤出，长期削弱修复能力。
- 残留反噬：被弃置区域中的污染、敌意和记忆日后以更高代价回返。

## 弃置域中的关键问题

1. 文明更该害怕放弃太多，还是害怕永远不敢放弃任何东西。
2. 哪些弃置是必要止损，哪些弃置只是把代价推给看不见的人和未来时段。
3. 如果 MOSS 最终主要靠不断弃置旧部分来维持新部分，它还剩多少连续性可言。

## 继续细化建议

- 单独写“第一次整区弃置令”档案。
- 建一份设施弃置、区域弃置和计划弃置的后果追踪表。
- 补一份“一个被正式弃置的区域如何多年后反向影响核心区”的案例。
