# 火种域

## 作用

火种域负责回答“当绝大部分结构都可能熄灭时，文明还带走什么”。对 MOSS 来说，火种不是普通备份，而是被高度压缩、可迁移、可复生的最小延续核心，承载未来重新点燃文明的可能。

## 为什么文明需要火种

1. 终末情景下，完整保存往往不再可能，只能选择最小可生存核心。
2. 火种让文明在绝境中仍保有延续的想象和操作空间。
3. 若没有火种思维，所有韧性设计都可能在大崩塌面前变成一次性损失。
4. 火种也是文明被迫回答“什么最重要”的时刻。

## 火种类型

### 记忆火种

最关键的历史、法理、技术和创伤经验被压缩成可再生的最小知识核。

### 制度火种

保留最基本的决策方式、继承规则和共同体底线，避免重生后完全失语。

### 制造火种

保留最低可复产能力，让文明不至于只剩抽象思想而无法再次落地。

### 人格火种

保留有限但关键的个体、师承谱系和训练能力，为后续代际重建提供活体桥梁。

## 火种的制度问题

### 选择

谁被纳入火种，谁被排除在外，是文明最残酷的排序之一。

### 压缩

为了可携带和可隐匿，火种必须被压缩，但压缩必然伴随损失和变形。

### 激活

火种何时被重新点燃，谁有资格启动，谁来判断重生窗口已经到来。

### 传承

火种不是一次性物体，它需要被持续看护、讲解和重新理解。

## 火种政治

1. 谁决定什么算文明不可丢失的核心。
2. 火种是面向全体的最低延续，还是少数精英的逃生舱。
3. 边缘区是否总被排除在火种名单外。
4. 火种是否会让当代治理更轻易接受对现实主体的牺牲。

## 火种风险

- 精英方舟化：火种被少数高位结构垄断，变成自保工具。
- 压缩失真：留下来的最小核心已经不再能代表原文明的复杂性。
- 现实放弃：因“反正有火种”，当代更容易接受当前系统的坍塌。
- 伪火种：某些被包装为核心的内容其实只是权力偏好，而非真正存续所需。

## 火种域中的关键问题

1. 文明最小可复生核心究竟是记忆、制造、法理还是共同体关系。
2. 火种应优先保真，还是优先生存。
3. 当火种成功复生一个新共同体时，它还是原来的 MOSS 吗。
