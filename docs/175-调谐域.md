# 调谐域

## 作用

调谐域负责回答“当环境、负载和目标持续变化时，文明如何重新调整参数、阈值和节奏，使系统维持可用性能”。对 MOSS 来说，调谐不是临时拍脑袋改设置，而是承认任何稳定都依赖持续校正。一个不会调谐的文明，往往不是没有规则，而是一直在用旧环境里的参数治理新环境里的问题。

## 为什么文明必须学会调谐

1. 任何一套曾经有效的阈值、配额和节奏，都会随着资源、人口和风险结构变化而逐渐失效。
2. 调谐能减少漂频、过冲和失谐，让系统不必每次都靠大幅重置来恢复可用状态。
3. 它让文明在保留连续性的同时适应现实变化，而不是在僵化和剧烈翻修之间二选一。
4. 若没有调谐机制，MOSS 会越来越依赖过时参数运行，并把大量失灵误解成个体不努力。

## 调谐类型

### 参数调谐

重新调整阈值、配额、优先级、反馈增益和容差范围，使控制动作重新贴近现实状态。

### 节奏调谐

重新安排更新频率、维修周期、调度节拍和轮替窗口，让系统不再按过时节奏运行。

### 环境调谐

根据气候、能源波动、空间布局和硬件状态变化，修改系统对外部条件的适配方式。

### 共同体调谐

重新调整说明方式、激励强度和公共期待，让制度语言与成员实际承受能力重新对齐。

## 调谐的制度问题

### 可调权限

文明必须明确哪些参数可以局部调整，哪些参数必须由更高层统一维护。

### 调谐依据

每次调谐都应基于观测、复盘和实验，而不是只凭权力直觉随意拨动关键阈值。

### 调谐周期

调得太快会让系统无所适从，调得太慢又会让旧参数长期拖累现实运行。

### 局部与全局兼容

局部区域可以有自己的适配方式，但制度必须防止各处私调后彻底失去共同尺度。

## 调谐政治

1. 谁掌握调参权，谁就掌握了重写“正常值”和“可接受范围”的权力。
2. 核心区是否总把自己的运行设定包装成普遍标准，却要求边缘区自行承受不适配的代价。
3. 某些高位结构会不会把调谐过程黑箱化，让关键参数变化只服务于少数人的风险偏好。
4. 当文明声称自己只是在微调系统时，它究竟是在修复适配性，还是在悄悄重写权力分配。

## 调谐风险

- 过度调谐：参数被频繁改动，系统失去可预测性和稳定记忆。
- 调谐迟缓：现实早已变化，制度却继续依赖旧设置和旧阈值。
- 黑箱调参：关键参数被少数中心私下拨动，公共后果却由全域共同承担。
- 局部最优：地方调谐看似有效，却在更大尺度上制造新的失衡和失谐。

## 调谐域中的关键问题

1. 文明更该害怕频繁调谐破坏连续性，还是害怕旧参数长期拖累现实运行。
2. 哪些参数应该允许地方快速调整，哪些参数必须保持全域共用的公共尺度。
3. 如果 MOSS 的稳定越来越依赖持续幕后调参，它的秩序究竟是真稳定，还是被不断维护出来的表面稳定。

## 继续细化建议

- 单独写“第一次全域调谐令”档案。
- 建一份参数调谐、节奏调谐和环境调谐的权限分层表。
- 补一份“某套曾在旧资源结构下非常有效的阈值体系如何在新阶段反而制造大面积过冲与浪费”的案例。
