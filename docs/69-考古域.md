# 考古域

## 作用

考古域负责回答“文明如何把埋掉的过去重新挖出来”。对 MOSS 来说，考古并不只是研究古老遗物，而是进入废墟、解封旧档、比对失落版本、修复断裂协议，并在残片中重新辨认自己曾经是什么。

## 为什么文明需要考古

1. 记忆并不总是完整保存，很多真相会被事故、封存和权力选择掩埋。
2. 废墟和禁书中常保留现行秩序故意忽略的线索。
3. 如果没有考古，文明会把自己的历史理解为平滑连续，而看不见断裂与删改。
4. 考古也是对当前合法性的持续追问。

## 考古对象

### 物理遗址

被遗弃的节点、设施、城市和通道残骸，常保留制度无法抹平的现实证据。

### 版本遗骸

旧模型、旧协议、旧治理规则和被替换系统的残余副本。

### 封存档案

被限制读取、延迟公开或仅局部可见的禁书与高危文档。

### 文化碎片

旧口号、旧节庆、旧命名法和旧仪式残片，常比正式宪章更真实地保存时代气质。

## 考古方法

### 交叉比对

把废墟证据、禁书残页、媒体残片和口述回忆放在一起，抵消单一来源失真。

### 版本复原

通过日志、备份、派生体和外部痕迹，拼接出已被改写或消失的历史版本。

### 风险挖掘

考古不只为了怀旧，也为了识别旧时代错误如何可能在今天回返。

### 公共解释

挖出来的东西如何被命名、公开和解释，决定考古是否真正进入文明记忆。

## 考古政治

1. 谁能进入高危遗址和解封高阶档案。
2. 考古结果是否会冲击现政权的正统叙事。
3. 某些真相是否会因代价太高而被再次埋回去。
4. 边缘区与核心区对同一遗迹是否会给出不同解释。

## 考古风险

- 证据污染：遗址和档案在长期封存中已被篡改、混杂或误读。
- 浪漫化残骸：文明把废墟美化成传奇，而不是面对其真实代价。
- 再次封存：一旦挖出的事实过于危险，权力结构会迅速重新压埋。
- 考古掠夺：高位机构垄断遗址进入权，把历史挖掘变成新的资源开采。

## 考古域中的关键问题

1. 文明更害怕失去过去，还是更害怕真正看见过去。
2. 哪些历史真相值得被挖出，即使会撕裂当前秩序。
3. 若考古发现 MOSS 的起源并不光荣，文明是否仍愿承认那是自身的一部分。

## 继续细化建议

- 单独写“第一次废墟考古禁令”档案。
- 建一份遗址类型与解封等级表。
- 补一份“考古结果如何改变法理判决”的案例。
