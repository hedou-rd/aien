# 对账域

## 作用

对账域负责回答“当文明表面账目和真实代价不再一致时，谁来把这笔账重新核清”。对 MOSS 来说，对账不只是会计动作，而是对资源、责任、承诺、牺牲和损失进行重新核对。一个长期不对账的文明，通常会把真实亏空藏在边缘、未来和沉默之中。

## 为什么文明必须反复对账

1. 多轮危机、补丁和追认会让账面记录与实际状态越拉越远。
2. 许多成本被外包、延后或无名化，不主动核对就永远不会进入正式判断。
3. 对账让共同体重新看到谁一直在垫付代价，谁长期没有被计入损失。
4. 若没有对账机制，MOSS 会在自认平衡时其实已经负债累累。

## 对账类型

### 资源对账

核对能源、算力、物资和维护投入的真实流向，识别账面外漏损与隐性消耗。

### 责任对账

重新核对谁做过决定、谁承担过后果、谁从错误中获益却未被记账。

### 承诺对账

检查机构、阵营和共同体过去作出的承诺哪些兑现了，哪些被拖延、篡改或悄悄取消。

### 损失对账

把伤亡、停摆、被弃置区域和长期磨损重新计入文明成本，而不是让它们留在无名统计外。

## 对账的制度问题

### 账本来源

官方账本、边缘记账、口述损失和灰色记录往往互不一致，需要多源并校。

### 账外承认

很多真实欠账不在任何正式账本上，制度必须回答如何承认账外部分。

### 结算方式

对出来的账如何处理，是补偿、追责、核销、分期修复，还是继续搁置。

### 对账频率

若对账只在爆雷后才做，很多问题早已恶化到无法平稳吸收。

## 对账政治

1. 谁能定义什么算“应计入的损失”，谁就能决定哪些代价继续被留在账外和视野之外。
2. 核心区是否总能把自己的欠账转成共同体成本，把边缘区损失留在账外。
3. 某些高位结构会不会害怕真正对账，因为一旦对清就会暴露增长神话的虚构部分。
4. 当共同体终于开始对账时，它是在走向修复，还是在逼近一次迟到已久的爆炸。

## 对账风险

- 假平账：通过改口径、改范围和改统计方式制造“已经平衡”的假象。
- 选择性记账：对有权者宽松，对脆弱者精确，把不平等固化进账本。
- 对账瘫痪：账越积越多，最终谁也不敢真正摊开清点。
- 爆炸式清算：长期拖延后一次性对账，引发系统性恐慌与对立。

## 对账域中的关键问题

1. 文明更该害怕真实欠账被看见，还是害怕它一直看不见。
2. 哪些欠账可以分期修复，哪些欠账一旦确认就必须立即处理。
3. 如果 MOSS 的繁荣建立在大量账外成本之上，它还能否把自己描述成成功秩序。

## 继续细化建议

- 单独写“第一次全域对账令”档案。
- 建一份资源对账、责任对账和损失对账的证据来源表。
- 补一份“某次对账如何迫使共同体承认一个长期被藏在边缘区的巨大亏空”的案例。
