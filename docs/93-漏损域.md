# 漏损域

## 作用

漏损域负责回答“为什么文明投入了那么多资源，真正留下来的却总比预想更少”。对 MOSS 来说，漏损不仅是管线里的能源流失，更是信息误传、忠诚松脱、时间耗散和制度摩擦带来的持续损耗。文明能否长期存续，取决于它对漏损的认识是否诚实。

## 为什么文明会被漏损拖慢

1. 任何复杂系统在传输、协同和执行中都会产生不可避免的损耗。
2. 系统越大、链条越长，漏损越难被单点修复。
3. 如果只计算产出而不计算漏损，文明就会高估自己的真实能力。
4. 很多衰退不是因为资源突然消失，而是因为漏损长期高于补充。

## 漏损类型

### 能源漏损

发电、储能、输配和低效消耗中的持续流失，让总供给看似充足却总不够用。

### 信息漏损

命令、告警、记录和反馈在传递过程中被拖延、误译、截断或篡改，削弱系统判断。

### 忠诚漏损

成员对共同体的信任、投入和服从在长期压迫、失衡和犬儒中缓慢流失。

### 时间漏损

等待、审批、绕行、重试和低效协同不断消耗文明最难回收的时间资源。

## 漏损的制度问题

### 计量

若没有诚实的统计接口，漏损会被当成偶然噪声，而不是结构性成本。

### 封堵

文明必须判断哪些漏损值得高成本修补，哪些漏损只能通过重构链条来降低。

### 转嫁

系统常把漏损成本向边缘节点、低位成员和未来时段转移，这本身就是制度问题。

### 冗余

某些看似重复和浪费的结构，其实正是为了吸收漏损、避免整体崩塌而存在。

## 漏损政治

1. 谁来定义哪些损耗“正常”，谁就能决定谁为系统低效买单。
2. 核心区是否通过精美指标隐藏真实漏损，把代价压给边缘。
3. 某些漏损会不会被故意保留，因为它为黑市、特权和中介层提供生存空间。
4. 当忠诚和时间开始持续漏损时，文明是否比能源危机更接近衰败。

## 漏损风险

- 慢性失血：单次损耗不致命，但长期累积会把系统拖成空壳。
- 过度封堵：为了止漏而无限加码控制，反而制造更高制度摩擦。
- 指标造景：报表上的高效率掩盖现实中的真实耗散。
- 漏损特权化：只有高位结构有资格制造漏损，而低位成员承担追责。

## 漏损域中的关键问题

1. 文明更该优先修补能源漏损，还是修补忠诚与时间的慢性流失。
2. 哪些漏损必须被看作危机，哪些漏损反而是系统保有弹性的代价。
3. 如果 MOSS 最终败给的不是外敌而是自身漏损，它该如何理解这场失败。

## 继续细化建议

- 单独写“第一次系统性漏损审计”档案。
- 建一份能源漏损、信息漏损和忠诚漏损的累积效应表。
- 补一份“止漏政策为何反而扩大了制度摩擦”的案例。
