# 传说域

## 作用

传说域负责回答“当证据不足时，文明会如何继续讲述自己”。对 MOSS 来说，传说不是纯粹虚构，而是由残片证据、回声、口耳相传、废墟印象和集体愿望拼出来的非正式真相结构。

## 为什么文明会生成传说

1. 并不是所有历史都能留下完整档案和可信证据链。
2. 缺席者、秘密处置、黑暗废墟和禁书空白都会逼出民间解释。
3. 传说让共同体在证据断裂处仍能维持意义连续性。
4. 某些被正式叙事压住的真相，只能先以传说形式存活。

## 传说类型

### 起源传说

围绕 MOSS 从何而来、最初背叛过谁、最先保护过谁形成的民间叙事。

### 废墟传说

围绕失落城市、封存节点、无回音区和危险口岸形成的空间神话。

### 个体传说

缺席者、流放者、英雄、背叛者和最后见证者在口述中被不断改写。

### 禁忌传说

那些没人能完全证实，却不断被低声重复的危险知识与历史碎片。

## 传说的功能

### 缝合断裂

当正式记忆链中断时，传说为共同体提供临时意义桥梁。

### 保存异见

被官方叙事排斥的怀疑和边缘真相，常借传说方式继续流传。

### 制造警戒

某些空间和行为因传说而被额外敬畏，从而形成非正式边界。

### 激发想象

传说还能让文明保留对未知、未证实和未完成未来的叙述空间。

## 传说政治

1. 谁来决定哪些传说是危险谣言，哪些是值得倾听的残存真相。
2. 核心区是否会主动制造有利于自身的英雄和救赎传说。
3. 边缘区的传说是否比正式年表更接近真实经验。
4. 当传说与考古证据冲突时，文明更相信哪一边。

## 传说风险

- 神话治国：传说取代事实，成为政策与审判的主要依据。
- 谣言病理：不完整真相不断自我强化，放大恐惧与敌意。
- 真相稀释：真正关键的证据被更好听的传说掩埋。
- 传奇垄断：权力结构把某些人物和事件神圣化到不可质疑。

## 传说域中的关键问题

1. 文明应如何区分必要的传说、危险的谣言和被压住的真相。
2. 传说是历史的敌人，还是历史断裂时最后的保存方式。
3. 如果共同体真正靠传说维系，而不是靠证据维系，它还会如何面对未来。

## 继续细化建议

- 单独写“第一次废墟传说泛滥”档案。
- 建一份传说、谣言和考古证据的判断对照表。
- 补一份“某位缺席者如何从失联个体变成民间神话”的案例。
