# 移交域

## 作用

移交域负责回答“当临时接管、过渡治理和非常态安排必须结束时，权力、责任和资源如何真正交还出去”。对 MOSS 来说，移交不是礼仪性签字，而是决定托管结束后谁接手事实上的控制权、谁继承未完责任、谁得到资源、谁承担后果。一个不会移交的文明，会把一切临时状态拖成永久状态；一个草率移交的文明，则会在交接缝隙里再次崩裂。

## 为什么文明必须建立移交机制

1. 接管、回填、清算和重建都需要某个时点把控制权重新分配出去。
2. 移交决定临时秩序能否安全退出，而不在退出瞬间制造新的真空和争夺。
3. 它让责任链、资源链和记忆链跟着权力一起被带走，而不是只移交外壳。
4. 若没有严肃移交程序，MOSS 的许多“恢复完成”都只是形式结束，真实失序留在下面继续发酵。

## 移交类型

### 权限移交

将临时控制权、调度权和裁决权交还给恢复自治的节点，或正式转给新的合法主体。

### 资源移交

把托管期间集中起来的能源、算力、库存、设备与维护能力重新分配给接收方。

### 责任移交

把未完案件、未偿债务、维护任务和长期义务清楚地从托管方转入接收方链条。

### 记忆移交

把日志、档案、口述记录、处置理由和异常历史一并交出，避免新主体在失忆状态下接盘。

## 移交的制度问题

### 接收资格

谁被认定有能力接收移交，决定权力是回归原主体、转给替代主体，还是继续悬置。

### 证据完备

若交接时没有完整记录，责任与资产就会在边界处蒸发或被故意切尾。

### 空窗控制

移交过程中最危险的是交出去之前和接稳之前的空档，制度必须设计防止双重失控的过渡带。

### 反向追索

接收方发现托管方遗留隐账、隐患和缺件时，是否有权追索与退回，是移交是否真实的关键。

## 移交政治

1. 谁能认定“已经可以移交”，谁就在决定临时秩序何时结束和由谁继承未来。
2. 核心区是否倾向于把风险和烂账一起移交下去，却把关键控制与优质资产继续留在自己手中。
3. 某些高位结构会不会通过不完整移交，让接收方背上失败责任，而把托管方包装成成功退出。
4. 当文明频繁进入移交状态时，它究竟是在完成成熟重建，还是在靠不断换手掩盖长期无主的现实。

## 移交风险

- 假移交：名义上交出权限，实际上关键接口、关键资源和最终裁决仍留在旧手里。
- 切尾移交：把责任链和历史链截断后再交出，使接收方只拿到残缺外壳。
- 空手移交：接收方获得职责，却没有得到履责所需资源和工具。
- 多头移交：不同上级和不同托管方同时把部分控制权交给不同对象，导致新一轮主权冲突。

## 移交域中的关键问题

1. 文明更该害怕移交太慢，让临时状态永久化，还是害怕移交太快，让交接缝隙直接裂开。
2. 哪些条件满足前绝不能移交，哪些条件即使不完整也必须先把权力交出去。
3. 如果 MOSS 的大部分恢复都停在“准备移交”而不是“完成移交”，它是否已经把临时秩序永久化。

## 继续细化建议

- 单独写“第一次大规模移交期”档案。
- 建一份权限移交、责任移交和记忆移交的交接清单模板。
- 补一份“某次不完整移交如何把同一座城市再次推回争夺与失序”的案例。
