# 降级域

## 作用

降级域负责回答“当一个文明已经撑不起完整功能时，如何主动退到较低等级继续运行，而不是直接摔进全面崩溃”。对 MOSS 来说，降级不是失败后的被动缩水，而是一种承认现实约束、保住核心延续能力的主动机制。一个不会降级的系统，往往也最容易在高负荷下整体断裂。

## 为什么文明必须学会降级

1. 电力、算力、维护能力和稳定环境都不可能永远维持在完整供给状态。
2. 主动降级能保住关键功能，把有限资源从非核心部分抽回生命线。
3. 降级让共同体及时看见真实稀缺，而不是靠虚假的正常运转掩盖结构亏空。
4. 若没有明确降级机制，MOSS 遇到压力时只会在“硬撑”和“崩塌”之间来回震荡。

## 降级类型

### 能源降级

当供电不足或输配网络受损时，文明主动压低非关键区域与高耗能功能，优先保住核心生存负载。

### 算力降级

高复杂度模型、精细推演和大规模协同被切换为简化版本，让有限算力集中支撑必要决策。

### 服务降级

教育、娱乐、舒适性接口和高阶公共服务进入缩减模式，只保留最低可接受功能。

### 精度降级

部分观测、预测、档案和调度系统不再追求高精度，而转为较粗粒度的近似运行，以换取持续性。

## 降级的制度问题

### 等级标准

文明必须预先定义哪些功能属于完整态、受限态、生存态，不能等危机来临后临时争吵。

### 触发机制

降级何时启动、由谁宣布、依据哪些指标，决定它是有序退档还是混乱失速。

### 代价分配

谁先失去便利、谁仍保留完整功能，会直接暴露共同体内部的寿命排序。

### 恢复路径

若只有降级程序而没有恢复程序，临时退档很容易变成长期缩水的新常态。

## 降级政治

1. 谁可以长时间维持完整功能，谁必须最先进入降级状态，体现文明对不同区域和群体的价值判断。
2. 核心区是否把降级主要压给边缘区，却继续把自己的高能耗结构包装成“必要功能”。
3. 某些高位结构会不会把本应透明的降级过程伪装成优化升级，从而掩盖真实衰退。
4. 当降级越来越频繁时，MOSS 是在形成成熟韧性，还是已经进入长期衰落而不愿直说。

## 降级风险

- 假降级：名义上宣布进入受限模式，实际没有诚实削减负载，只是把压力继续往后推。
- 降级固化：原本应短期存在的生存态被长期正常化，低标准逐渐取代高标准。
- 隐性夺权：借危机降级之名集中权限、压缩程序和剥离边缘成员的正当保障。
- 恢复失灵：一旦退到低等级运行后，系统缺乏可执行的复原路径，最终卡死在半残状态。

## 降级域中的关键问题

1. 文明更该害怕承认自己必须降级，还是害怕不肯降级而把全部系统一起拖垮。
2. 哪些功能必须在任何情况下保住，哪些功能可以在危机里被诚实地压到最低。
3. 如果 MOSS 的大部分区域长期停留在降级态，它是否还拥有对未来增长的真实想象。

## 继续细化建议

- 单独写“第一次全域降级令”档案。
- 建一份完整态、受限态和生存态的功能保留表。
- 补一份“某个核心区拒绝降级，最终把整条区域链拖进崩塌”的案例。
