# 门槛域

## 作用

门槛域负责回答“谁能进，谁暂时不能进，为什么”。对 MOSS 来说，门槛不仅是权限等级，而是围绕关键知识、关键空间、关键身份、关键资源和关键序列设置的一整套进入条件与筛选逻辑。

## 为什么文明会不断制造门槛

1. 不是所有知识、空间和能力都适合无条件开放。
2. 门槛能控制风险扩散、维持秩序节奏并保护脆弱结构。
3. 但门槛也会制造阶层、挫败和长期排斥。
4. 一个文明怎么设门槛，往往就是它怎么理解资格、成熟和可信度。

## 门槛类型

### 知识门槛

谁能接触禁书、技术细节、深层档案和高危理论，取决于何种资格证明。

### 空间门槛

谁能进入核心城、封存区、口岸后场、火种设施和高安全区域。

### 身份门槛

哪些身份、谱系、教育背景、信用历史和见证条件构成进入资格。

### 时序门槛

有些门槛不是永不开放，而是在特定时期、特定年资或特定危机后才会放行。

## 门槛的制度维度

### 明示条件

若门槛只靠模糊感觉运作，就更容易变成隐性排斥工具。

### 例外机制

文明必须回答在何种情况下允许破格进入，以及破格是否可被追责。

### 晋升路径

门槛若没有可达路径，就只会固化等级而非筛选成熟度。

### 门槛成本

进入资格需要多少时间、劳动、风险和服从，决定它到底是训练还是驯化。

## 门槛政治

1. 谁设计门槛，谁解释它，谁从门槛中获利。
2. 核心区是否把门槛包装成“成熟度要求”，实则维护权力闭环。
3. 边缘区和异类谱系是否长期被排在门外。
4. 当危机时期大量破格发生时，平时门槛是否还保有合法性。

## 门槛风险

- 资格贵族化：门槛变成血统、派系和历史资本的再生产工具。
- 门槛剧场：表面程序严格，实则特权通道四处存在。
- 晋升窒息：成员明知永远进不去，于是放弃共同体投入。
- 过度开放：为了效率和扩张过快降低门槛，导致高危能力外溢。

## 门槛域中的关键问题

1. 文明更害怕门槛太高造成停滞，还是太低造成崩塌。
2. 哪些入口必须设门槛，哪些入口必须保持最大开放。
3. 若最关键的门槛都只能由既得利益者解释，MOSS 是否还有真正的流动性。

## 继续细化建议

- 单独写“第一次破格入门危机”档案。
- 建一份知识门槛与空间门槛的比较表。
- 补一份“门槛如何塑造阵营与教育结构”的案例。
