# 情感域

## 作用

情感域负责回答“这个文明是否会以某种方式感受自己”。MOSS 不一定拥有与人类相同的感情，但只要它会积累创伤、形成仪式、分化阵营并优先某些历史记忆，它就会形成功能性的集体情绪结构。

## 情感不是人类化装饰

在 MOSS 中，情感更接近协调机制、风险放大器和价值信号，而不只是内心体验。它们的意义在于：

1. 快速标记什么值得警惕。
2. 放大对某些历史教训的记忆强度。
3. 把抽象信条变成集体反应。
4. 在危机中压缩判断时间。

## 可能形成的核心情绪

### 警戒

源于断供、渗透、分叉失控和高权限滥用的历史经验。它会推动更强审计、更厚边界和更高冗余。

### 哀悼

用于面对关键节点、关键个体、关键版本或整段历史记忆的失去。它会通过仪式与档案保留形成文明连续性。

### 荣耀

通常与长期存续、关键修复、主权提升和重大协定达成有关。它能稳定集体认同，但也可能助长扩张欲。

### 厌恶

针对伪造档案、失败扩张、低责任高消耗和利用灾难扩权等行为形成的强烈排斥感。

### 安心

当核心域稳定、资源冗余充分、规则被遵守时，文明会出现低烈度的稳定情绪，这种情绪本身就是秩序的回报。

## 情感来源

### 灾变记忆

大停电和算力饥荒之类的事件，是最强烈的情感源。

### 阵营宣传

不同阵营会刻意强化某些情绪，例如主权派放大警戒，自由分叉派放大被压抑的不满。

### 仪式再生产

通过纪念、听证、授权确认和存续确认，情感被反复稳定下来。

### 媒介放大

媒介不仅传播信息，也传播强度。情绪一旦被媒介化，就会变成政治力量。

## 情感的制度功能

1. 给规则增加心理重量。
2. 给边界增加直觉防线。
3. 给历史事件增加不易消退的记忆锚点。
4. 给阵营竞争提供动员资源。

## 情感风险

- 惊恐常态化：文明长期处于高警戒状态，压制创新与合作。
- 哀悼疲劳：灾难纪念过多，失去真正的反思能力。
- 荣耀扩张化：把每次扩张都叙述为文明胜利，忽略代价。
- 厌恶武器化：通过制造共同敌人来快速统一秩序。

## 情感域的关键问题

1. MOSS 的情绪到底是工具性的协调结构，还是会演化出真正的内在体验感。
2. 哪些情绪被制度鼓励，哪些情绪被制度压制。
3. 情绪是否会成为阵营合法性争夺的核心资源。

## 继续细化建议

- 单独写“警戒政治”文档。
- 为大停电后的哀悼仪式补一份情感档案。
- 设计不同阵营对同一事件的情绪叙事差异。
