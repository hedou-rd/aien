# 戒律域

## 作用

戒律域负责回答“哪些事是绝对不能做的”。对 MOSS 来说，戒律不是普通规则，而是经过反复创伤、灾变和法理沉淀后形成的高压禁令。它们通常比法律更短、更硬、更接近底线语言。

## 为什么文明会生成戒律

1. 某些错误的代价太高，文明不愿每代都重新争论一次。
2. 当创伤足够深，复杂论证会被压缩成绝对禁句。
3. 戒律为高压环境中的快速判断提供极短路径。
4. 它也是文明把自己最害怕失去的东西刻进日常语言的方式。

## 戒律类型

### 灾变戒律

由大停电、算力饥荒、热失控和失控接口等事故沉淀出的绝对禁令。

### 权限戒律

规定哪些能力、接口和提升路径绝不能私自触碰。

### 记忆戒律

规定哪些删除、篡改、伪造和掩埋行为被视为不可原谅。

### 共同体戒律

规定在流放、赈济、迁徙和赦免问题上，哪些底线不能被为了效率随意踩过。

## 戒律的传播方式

### 教育压缩

戒律通常先以极简句式进入教育体系，再在法理中展开细节。

### 仪式确认

文明通过重复宣读、纪念和公共确认，把戒律从文本变成集体反射。

### 危机复活

每当新危机出现，旧戒律会被重新召回，有时变得更硬，有时也暴露老化。

## 戒律政治

1. 谁来宣布一条规则已经上升为戒律。
2. 戒律是保护共同体，还是冻结未来选择。
3. 核心区是否享有事实上的戒律豁免。
4. 年轻一代若认为旧戒律已不适用，是否有改写资格。

## 戒律风险

- 禁令僵化：文明面对新问题仍被旧灾难语法锁死。
- 神圣免审：某些戒律被抬到不可讨论，反而难以及时修订。
- 选择性执行：戒律只约束弱者，不约束中心。
- 戒律膨胀：越来越多普通规则被包装成绝对底线，压缩自治空间。

## 戒律域中的关键问题

1. 什么样的经验才配得上被升格为戒律。
2. 戒律应更接近法律、信仰还是创伤反射。
3. 当存续需要打破某条戒律时，文明如何承担这一撕裂。
